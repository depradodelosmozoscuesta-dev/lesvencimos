Polinómica, racional e irracional

1º Bach CCSS · CyL Decreto 40/2022 · C.4 Propiedades de familias de funciones

Para situarte

Tres familias, tres dominios

Polinómica, racional sencilla e irracional sencilla no se comparan solo por el dibujo: primero se dice dónde existen y qué les pasa en el infinito o junto a un hueco.

Objetivos

  • Dar el dominio de una polinómica, de una racional sencilla y de una raíz cuadrada sencilla.
  • Leer asíntotas vertical y horizontal en una racional de grado 1 partido por grado 1.
  • Comparar las tres familias con el mismo número de prueba.

Fichas

p(x) = x² − 4, dominio ℝ. No tiene asíntotas verticales ni horizontales: cuando |x| crece, |p(x)| crece.

p es la función polinómica; x es cualquier real; 4 es el término independiente, y las raíces son x = 2 y x = −2 porque 4 = 2².

r(x) = (x + 1) / (x − 2), dominio x ≠ 2. Asíntota vertical x = 2. Asíntota horizontal y = 1.

El numerador y el denominador son de grado 1; y = 1 es el cociente de los coeficientes principales, ambos 1. x = 2 anula solo el denominador, de ahí la asíntota vertical.

q(x) = √(x − 1), dominio [1, ∞). Arranca en (1, 0) y crece sin asíntota vertical.

La raíz cuadrada real exige radicando ≥ 0, así x − 1 ≥ 0. El 1 es el extremo izquierdo del dominio, no una asíntota.

Ejemplo 1. Asíntotas de la racional

  1. Denominador cero solo en x = 2, y el numerador ahí vale 3 ≠ 0. Hay asíntota vertical x = 2. r no existe en ese punto.
  2. Grados iguales: y = 1/1 = 1 es asíntota horizontal. Para x grande, r(x) se acerca a 1 pero, en esta fórmula, no llega a valer 1: (x+1) = (x−2) implicaría 1 = −2.
  3. r(5) = 6/3 = 2. r(0) = 1/(−2) = −0,5. r no está definida en 2.

Ejemplo 2. La misma abscisa en las tres

Compara p, r y q en x = 5 y di quién no admite x = 0.

  1. p(5) = 25 − 4 = 21. p(0) = −4, existe.
  2. r(5) = 6/3 = 2. r(0) = −0,5, existe. r(2) no existe.
  3. q(5) = √4 = 2. q(0) = √(−1) no es real: 0 no está en [1, ∞).
  4. En x = 5 las tres existen y dan 21, 2 y 2. El polinomio ya va muy por encima; racional y raíz coinciden en este punto concreto, no en general.

Ejercicios

1. Dominio de una raíz

Halla el dominio de √(2x − 6).

Corrección
  1. 2x − 6 ≥ 0.
  2. 2x ≥ 6, x ≥ 3.
  3. Dominio [3, ∞).
  4. En x = 3 la raíz vale 0; en x = 2 el radicando es −2, fuera.

La raíz cuadrada real no admite radicando negativo. El extremo 3 se incluye porque √0 = 0 está definido.

2. Asíntotas

De (2x) / (x + 4), escribe dominio y asíntotas vertical y horizontal.

Corrección
  1. Denominador cero en x = −4. Dominio: x ≠ −4.
  2. El numerador en x = −4 vale −8 ≠ 0: asíntota vertical x = −4.
  3. Grados iguales y coeficientes principales 2 y 1: asíntota horizontal y = 2.
  4. No hay más huecos.

y = 2 no significa que la función valga 2 en algún sitio obligatorio. (2x) = 2(x+4) implicaría 0 = 8, así que esta curva no corta su asíntota horizontal.

3. Quién crece

Para x > 1 grande, ordena de menor a mayor el comportamiento de a(x) = 1/(x − 1), b(x) = √x y c(x) = x².

Corrección
  1. a(x) se acerca a 0 por encima y se queda pequeña.
  2. √x crece, pero más despacio que x y mucho más despacio que x².
  3. x² es la que se va a infinito más deprisa.
  4. Orden de tamaño para x grande: a(x) < b(x) < c(x).

No compares un valor suelto con el tipo de función. En x = 1, √1 = 1 y 1² = 1 empatan, y 1/(x−1) ni existe. El orden pedido es el de x grande, donde el grado manda.

4. ¿Está definida?

En x = −1 calcula, si existen, p(x) = x² − 1, r(x) = 1/(x + 1) y q(x) = √(x + 1).

Corrección
  1. p(−1) = 1 − 1 = 0.
  2. r(−1) tiene denominador 0: no existe.
  3. q(−1) = √0 = 0.
  4. Solo p y q dan número; r tiene ahí su asíntota vertical.

Que el numerador de una racional también se anule no salva el caso si, como aquí, el numerador de r es 1 y no se anula. 0/0 sería otra situación; 1/0 no es un número.

Cierre

Dominio primero, asíntotas después, comparación al final. Un polinomio existe en toda la recta; una racional sencilla falla en los ceros del denominador; una raíz cuadrada sencilla solo vive donde el radicando no es negativo.
