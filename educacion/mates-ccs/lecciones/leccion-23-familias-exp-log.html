Lección 23 · C.4 · Otras familias

Exponencial, logaritmo, periódica y a trozos

1º Bach CCSS · CyL Decreto 40/2022 · C.4 Familias de funciones

Para situarte

Cuatro modos de crecer, decrecer o repetirse

Exponencial, logaritmo, una periódica sencilla y una función a trozos cubren el resto de familias que el decreto pide comparar en 1.º.

Objetivos

  • Leer dominio, crecimiento y un punto concreto de una exponencial y de un logaritmo.
  • Usar el periodo para evaluar una función periódica fuera del intervalo modelo.
  • Evaluar una función a trozos eligiendo la fórmula del tramo correcto.

Exponencial y logaritmo

E(x) = 2x. Dominio ℝ. E(0) = 1, E(1) = 2, E(2) = 4, E(3) = 8, E(−1) = 1/2.

2 es la base, mayor que 1, así que la función crece; x es el exponente y puede ser negativo; E(x) nunca es 0 ni negativa.

L(x) = log2(x). Dominio (0, ∞). L(1) = 0, L(2) = 1, L(4) = 2, L(8) = 3.

x es el argumento, obligatorio positivo; el resultado es el exponente al que hay que elevar 2. L y E son inversas: L(E(x)) = x y E(L(x)) = x en sus dominios.

Periódica sencilla

Las ventas mensuales de un quiosco de temporada se modelan, en unidades, por

v(t) = 20 + 5·sin(π t / 6), t en meses.

t es el mes; 20 es el nivel medio; 5 es la amplitud; el seno completa un ciclo cuando su argumento avanza 2π, y π t / 6 avanza 2π cuando t avanza 12. El periodo es 12 meses.

Valores exactos útiles: sin(0) = 0, sin(π/2) = 1, sin(π) = 0, sin(3π/2) = −1. Así v(0) = 20, v(3) = 25, v(6) = 20, v(9) = 15, v(12) = 20.

A trozos

Tarifa de un taller, en euros, según las horas x > 0:

c(x) = 2x si 0 < x ≤ 3;   c(x) = x + 3 si x > 3.

x es el número de horas; 2x es el tramo inicial a 2 euros la hora; a partir de 3 horas la fórmula x + 3 continúa el precio (en x = 3 ambos expresiones valen 6) y luego sube 1 euro por hora.

Ejemplo 1. Doble y desplazamiento

  1. 2x+1 = 2·2x. No es un desplazamiento: es un estiramiento vertical de factor 2.
  2. 2x−1 = E(x − 1) sí es desplazar E una unidad a la derecha.
  3. En x = 3: 2³ = 8, 2⁴ = 16 y 2² = 4.

Ejemplo 2. Periodo y trozo

  1. v(15): 15 = 12 + 3, y el periodo es 12, así v(15) = v(3) = 25. También sin(π·15/6) = sin(5π/2) = sin(π/2) = 1, luego 20 + 5·1 = 25.
  2. c(2) usa el primer trozo porque 2 ≤ 3: c(2) = 4.
  3. c(6) usa el segundo: 6 > 3, c(6) = 6 + 3 = 9.
  4. c(3) = 2·3 = 6. La otra fórmula en el borde no se aplica, pero daría 3+3 = 6: el precio no salta.

Ejercicios

1. Tres valores de la exponencial

Calcula 2³, 23+1 y 23−1.

Corrección
  1. 2³ = 8.
  2. 2⁴ = 16, el doble de 8.
  3. 2² = 4, la mitad de 8.
  4. El +1 en el exponente duplica; no suma 1 al resultado.

Sumar 1 en el exponente multiplica por la base. Sumar 1 al resultado sería otra función, 2x + 1, que en x = 3 vale 9.

2. Logaritmo en base 3

Calcula log3(1), log3(9) y log3(1/3). Di el dominio.

Corrección
  1. log3(1) = 0 porque 3⁰ = 1.
  2. log3(9) = 2 porque 3² = 9.
  3. log3(1/3) = −1 porque 3−1 = 1/3.
  4. Dominio (0, ∞). El 0 y los negativos no entran.

El logaritmo puede dar negativo, como −1, pero su argumento no puede serlo. 1/3 es positivo y por eso es válido.

3. Dentro de dos años de temporada

Con v(t) = 20 + 5·sin(π t / 6), calcula v(15) y v(9).

Corrección
  1. Periodo 12. 15 − 12 = 3, y v(3) = 25, luego v(15) = 25.
  2. sin(π·9/6) = sin(3π/2) = −1.
  3. v(9) = 20 + 5·(−1) = 15.
  4. 15 es el mínimo del modelo; 25 es el máximo.

Restar el periodo no cambia el seno. Esos argumentos del seno valen 0, 1, 0 y −1; no hace falta aproximar.

4. Elegir el trozo

Con la tarifa c de la lección, calcula c(3) y c(5).

Corrección
  1. x = 3 entra en el primer trozo (≤ 3): c(3) = 6.
  2. x = 5 > 3: c(5) = 5 + 3 = 8.
  3. No se usa 2·5 = 10: esa fórmula ya no rige.
  4. El salto de precio por hora pasa de 2 euros a 1 euro después de la tercera hora.

En una función a trozos la primera decisión es el intervalo, no la aritmética. Aplicar la fórmula vecina cambia el resultado: 10 no es el precio de 5 horas.

Cierre

La exponencial nunca corta el eje horizontal; el logaritmo no existe en los no positivos; la periódica se evalúa reduciendo al periodo; la función a trozos obliga a mirar la condición antes de sustituir.
