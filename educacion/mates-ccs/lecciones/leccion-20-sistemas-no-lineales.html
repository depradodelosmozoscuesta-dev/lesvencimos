Sistemas no lineales e inecuaciones

1º Bach CCSS · CyL Decreto 40/2022 · C.3 Sistemas no lineales e inecuaciones lineales

Para situarte

Una curva y una recta, o varias rectas a la vez

Los sistemas no lineales sencillos de este curso se reducen a una ecuación de segundo grado. Un sistema de inecuaciones lineales no da un punto: da una región del plano.

Objetivos

  • Resolver sistemas no lineales sencillos por sustitución y quedarse solo con las parejas que cumplen todas las ecuaciones.
  • Representar la región solución de un sistema de inecuaciones lineales y hallar sus vértices.
  • Decidir si un punto concreto es interior, frontera o exterior.

Sustitución

Si una ecuación despeja y con facilidad, se lleva a la otra. Cada solución de la ecuación en una variable se devuelve a la despejada y se comprueba en las dos ecuaciones. Puede haber dos parejas, una, o ninguna.

De x + y = s y xy = p sale t² − s t + p = 0.

s es la suma conocida; p es el producto conocido; t representa tanto a x como a y, que son las dos raíces de esa cuadrática.

Ejemplo 1. Suma 5 y producto 6

  1. y = 5 − x. Entonces x(5 − x) = 6.
  2. 5x − x² = 6 → x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0.
  3. x = 2 da y = 3. x = 3 da y = 2.
  4. Comprobación: 2+3=5 y 2·3=6; lo mismo al revés.

Parejas: (2, 3) y (3, 2).

Ejemplo 2. Circunferencia y recta, enteros

x² + y² = 25, x + y = 7.

  1. y = 7 − x. Sustitución: x² + (7 − x)² = 25.
  2. x² + 49 − 14x + x² = 25 → 2x² − 14x + 24 = 0 → x² − 7x + 12 = 0.
  3. (x − 3)(x − 4) = 0. Parejas: (3, 4) y (4, 3).
  4. 3²+4²=9+16=25 y 3+4=7. Igual la otra pareja.

x² + (7 − x)² = 25.

x es la abscisa; 7 − x es la ordenada que impone la recta; 25 es el cuadrado del radio, no el radio. El radio es 5.

Región plana

Sistema: x ≥ 0, y ≥ 0, x + y ≤ 4, y ≤ 2. Cada desigualdad es un semiplano. La solución es la intersección. Los vértices salen al cruzar las fronteras de dos en dos y comprobar que cumplen el resto.

  • (0, 0): ejes. Cumple todo.
  • (4, 0): x + y = 4 con y = 0. Además y = 0 ≤ 2.
  • (2, 2): x + y = 4 con y = 2.
  • (0, 2): x = 0 con y = 2. Y 0+2 ≤ 4.

El punto (4, 2) no entra: 4+2=6 > 4. El polígono es (0,0), (4,0), (2,2), (0,2).

x ≥ 0, y ≥ 0, x + y ≤ 4, y ≤ 2.

x e y son las coordenadas del plano; 4 es el tope de la suma; 2 es el tope de y; 0 es el borde de cada eje que se incluye.

Ejercicios

1. Suma y producto

Resuelve x + y = 6, xy = 8.

Corrección
  1. t² − 6t + 8 = 0.
  2. (t − 2)(t − 4) = 0.
  3. Parejas (2, 4) y (4, 2).
  4. Comprobación: 2+4=6, 2·4=8.

Las dos parejas son distintas porque x e y intercambian papeles. Las dos cumplen las dos ecuaciones.

2. Circunferencia y bisectriz

Resuelve x² + y² = 10, y = x. Deja el resultado exacto.

Corrección
  1. x² + x² = 10, 2x² = 10, x² = 5.
  2. x = √5 o x = −√5, e y toma el mismo signo.
  3. Parejas (√5, √5) y (−√5, −√5).
  4. (√5)² + (√5)² = 5 + 5 = 10. No hace falta un decimal.

y = x obliga a que las dos coordenadas sean iguales. Las soluciones con signos opuestos cumplirían y = −x, que no es esta recta.

3. Triángulo en el primer cuadrante

Describe la región x ≥ 0, y ≥ 0, 2x + y ≤ 4 y da sus vértices.

Corrección
  1. Cruce de x = 0 e y = 0: (0, 0), y 0 ≤ 4.
  2. Cruce de y = 0 y 2x + y = 4: x = 2, vértice (2, 0).
  3. Cruce de x = 0 y 2x + y = 4: y = 4, vértice (0, 4).
  4. Región: triángulo de vértices (0,0), (2,0) y (0,4). El punto (1,1) cumple 2+1=3 ≤ 4.

Tres desigualdades de frontera dan como mucho un triángulo. (2, 2) no entra: 4 + 2 = 6 > 4.

4. Sin soluciones reales

Estudia x² + y² = 1, x + y = 3.

Corrección
  1. y = 3 − x.
  2. x² + (3 − x)² = 1 → 2x² − 6x + 9 = 1 → 2x² − 6x + 8 = 0.
  3. x² − 3x + 4 = 0. Discriminante 9 − 16 = −7 < 0.
  4. No hay soluciones reales. La recta no corta a la circunferencia de radio 1.

En la circunferencia unidad, el mayor valor de x + y es √2, aproximadamente 1,41, menor que 3. El discriminante negativo es la cuenta que lo demuestra sin aproximar.

Cierre

En un sistema no lineal, cada pareja se comprueba en todas las ecuaciones. En un sistema de inecuaciones, la respuesta es la región: vértices, lados incluidos o no, y un punto de prueba.
