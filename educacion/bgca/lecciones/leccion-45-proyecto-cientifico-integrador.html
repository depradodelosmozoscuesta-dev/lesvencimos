Lección 45 · A · Proyecto científico

Proyecto científico integrador

1º Bachillerato Biología, Geología y Ciencias Ambientales · CyL Decreto 40/2022 · bloque A

Objetivos

  1. Cerrar un proyecto completo: pregunta, hipótesis falsable, predicción, controles y lectura honesta.
  2. Marcar como «datos de ejemplo» todo número didáctico que no sea una medida tuya.
  3. Usar la placa solo para temperatura o humedad, nunca como medidor de «calidad» a secas.
  4. Integrar un saber de bloques previos sin inventar un bloque nuevo.

Explicación

El bloque A no se acaba en la lección 01: se aplica a un problema que ya sabes enmarcar (ecosistema, suelo, fisiología vegetal, microorganismos…). Un proyecto de 1º de Bachillerato exige mecanismo, contraste y límites; no un póster de opiniones.

Piezas obligatorias

  1. Pregunta investigable.
  2. Hipótesis con mecanismo (no conjetura vaga).
  3. Predicción observable y falsador declarado de antemano.
  4. Controles: qué dejas igual (temperatura de incubación, volumen, tiempo) y qué varías (una variable independiente).
  5. Datos: los tuyos, o «datos de ejemplo» etiquetados si aún no has medido.
  6. Lectura: compatible / no compatible / insuficiente; nunca «demostrado para siempre».

Caso de las lentejas: 25 % frente a 55 % de humedad relativa

La pregunta se queda en las lentejas de bandeja: ¿la germinación a cinco días depende de la humedad relativa del armario? No se pregunta por «la calidad» del armario. Se pregunta por una variable que el DHT22 puede registrar, el porcentaje de humedad del aire, frente a una respuesta que se cuenta: semillas germinadas.

La hipótesis nombra el mecanismo. A humedad demasiado baja el embrión pierde agua más deprisa de la que puede reponer desde el sustrato, y por eso germina una fracción menor. No es que el armario seco sea «peor» en abstracto. Es la desecación.

La predicción es contable. Con la misma temperatura, la misma luz y el mismo riego inicial, un armario cuya media sea del 25 % de humedad relativa debe dar menos germinación que otro al 55 %. Si los dos porcentajes salen iguales, esa hipótesis no se sostiene para esta diferencia.

El control deja quieto todo lo que no es la humedad del aire: misma especie, mismo lote, mismo número por bandeja, mismo sustrato. El dato que se usa para enseñar la lectura, y que hay que marcar como dato de ejemplo, es 8 de 20 germinadas al 25 % frente a 16 de 20 al 55 %, a los cinco días. El límite va en el ejemplo resuelto: compatible no es demostrado, y una bandeja por condición no es una réplica.

Medir con placa

En este proyecto la placa registra temperatura o humedad relativa del lugar del ensayo. No mide «la calidad» del aire ni del agua como un índice único: mide una variable física concreta. La medición con placa se ve al entrar. El sketch no se ejecuta en esta página y no enlaza a ninguna librería en línea.

Opción A · DHT22 (temperatura y humedad): VCC a 5 V (o 3,3 V), GND a tierra y DATA al pin digital 2, con resistencia de 10 kΩ entre DATA y VCC si el módulo no la trae. No leer más de una vez cada 2 s. Opción B · DS18B20 (solo temperatura): bus 1-Wire al pin 2 con resistencia de 4,7 kΩ entre DATA y VCC. En la Raspberry Pi no se usa una librería de pines aquí: se lee el CSV por el USB del Arduino con pyserial. Puerto habitual /dev/ttyACM0; con adaptador CH340 suele ser /dev/ttyUSB0. Esta página no descarga nada.

Arduino · DHT22

// DHT22 en el pin digital 2.
// Librería DHT de Adafruit, instalada en el IDE (no se descarga aquí).
#include <DHT.h>

#define PIN_DATOS 2
#define TIPO DHT22

DHT dht(PIN_DATOS, TIPO);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  delay(2000);
  float t = dht.readTemperature(); // grados Celsius
  float h = dht.readHumidity();    // porcentaje
  if (isnan(t) || isnan(h)) {
    Serial.println("error");
    return;
  }
  Serial.print(t, 1);
  Serial.print(",");
  Serial.println(h, 1);
}

Arduino · DS18B20 (alternativa)

// DS18B20 en pin 2, resistencia 4,7 kΩ a VCC.
// Librerías OneWire y DallasTemperature en el IDE local.
#include <OneWire.h>
#include <DallasTemperature.h>

OneWire oneWire(2);
DallasTemperature sensores(&oneWire);

void setup() {
  Serial.begin(9600);
  sensores.begin();
}

void loop() {
  sensores.requestTemperatures();
  float t = sensores.getTempCByIndex(0);
  if (t == DEVICE_DISCONNECTED_C) {
    Serial.println("error");
  } else {
    Serial.println(t, 2);
  }
  delay(2000);
}

Raspberry Pi · lectura por serial USB

# Lee líneas que envía el Arduino (CSV o un solo número).
# Al abrir el puerto la placa se reinicia: se descartan vacías.
import serial

with serial.Serial("/dev/ttyACM0", 9600, timeout=3) as puerto:
    linea = ""
    for _ in range(5):
        linea = puerto.readline().decode("utf-8", errors="replace").strip()
        if linea and linea != "error":
            break

print(linea)
# Ejemplo de interpretación:
# "22.4,47.1" → temperatura °C, humedad %
# "22.41"     → solo temperatura (DS18B20)

Esas lecturas son de tu montaje. Si las copias al informe, son medidas de ese ensayo, no un valor típico de Castilla y León. Una sola lectura no es una réplica. Temperatura o humedad no equivalen solas a «calidad ambiental».

Glosas de esta lección

  • Variable independiente. la que manipulas a propósito
  • Variable dependiente. la que mides como respuesta
  • Control. condición que mantiene iguales los factores que no estudias
  • Réplica. repetición independiente del ensayo
  • Datos de ejemplo. números didácticos; no son un informe oficial
  • Falsador. resultado que te obligaría a retirar la hipótesis

Ejemplo resuelto

El caso de las lentejas, escrito como se entrega: un paso por apartado. Los conteos son datos de ejemplo.

Hipótesis. Si la humedad relativa del armario baja, el embrión de la lenteja pierde agua hacia el aire más deprisa de la que toma del sustrato. A los cinco días, esa desecación deja sin germinar a una parte de las semillas que en aire más húmedo sí germinarían. El mecanismo es la pérdida de agua del embrión, no una etiqueta del armario.

Predicción. El DHT22 del armario seco marca una media del 25 % de humedad relativa y el del armario húmedo, del 55 %, con la misma temperatura, la misma luz y el mismo riego inicial. Entonces el porcentaje de germinación a cinco días será menor en el seco. Si los dos porcentajes salen iguales, o si germina más en el seco sin otro cambio, la hipótesis de la desecación por esa diferencia no se sostiene. Ese resultado contrario es el falsador, y se declara antes de mirar los datos.

Control. Misma especie, mismo lote y misma edad de semilla, mismo número por bandeja, mismo sustrato y mismo volumen de riego al empezar. La única variable que se cambia a propósito es la humedad relativa del aire. La temperatura se anota con el mismo DHT22, o con un DS18B20, para comprobar que no se ha colado como segunda causa. Si un armario está además más frío, ya no se sabe qué movió la germinación.

Dato de ejemplo. A los cinco días se cuentan 8 de 20 semillas germinadas al 25 % de humedad relativa y 16 de 20 al 55 %. Estas cifras no salen de un censo del centro ni de una cosecha: son datos de ejemplo, puestos para enseñar cómo se lee el contraste. En un informe de medidas reales se sustituyen por el conteo de ese ensayo y se dice de qué montaje salen.

Límite. El contraste es compatible con la hipótesis y no demuestra cómo se deseca el embrión por dentro: no se ha medido el agua de la semilla, solo la humedad del aire. Una bandeja por condición no es una réplica independiente. Una semilla mala, un rincón más frío o un riego desigual mueven el conteo sin que la humedad sea la causa. La lectura queda provisional hasta repetir el ensayo entero.

En la vida real

Informe corto, no teatro

Un buen informe de instituto parece al del ejemplo: pregunta, controles, sensor que mide lo que dice medir, y humildad ante un solo ensayo. Decir que el DHT22 midió «la calidad del aula» es un error de concepto: midió temperatura y humedad.

Comprueba

1. ¿Basta con decir que la placa midió «la calidad»?

Respuesta. No. Debe decir qué variable: temperatura, humedad u otra magnitud definida.

Por qué: Calidad no nombra una magnitud ni una unidad. El DHT22 devuelve grados Celsius y un porcentaje de humedad relativa; el DS18B20 devuelve solo temperatura. Si el informe dice que se midió la calidad del aula, nadie puede repetir el ensayo ni saber qué número falsaría la hipótesis, porque no hay procedimiento. La placa mide la variable que el sensor tiene definida, y el proyecto tiene que llamarla por ese nombre.

2. ¿Los 8/20 y 16/20 del caso son un censo oficial?

Respuesta. No: están marcados como datos de ejemplo.

Por qué: Ocho de veinte y dieciséis de veinte son un resultado puesto para enseñar cómo se lee un contraste, y por eso van marcados como datos de ejemplo. No salen de un censo del centro ni de una cuenca. Presentarlos como informe oficial atribuiría a un lugar real un conteo que no se ha hecho, y el lector no podría distinguir lo medido de lo inventado para el ejemplo.

3. ¿Qué falta si solo tienes una bandeja por condición?

Respuesta. Réplicas independientes y, a menudo, más tiempo o más sensores calibrados; la lectura queda provisional.

Por qué: Una bandeja por condición confunde el tratamiento con el azar de esas semillas. Una semilla en mal estado, un rincón más frío o un riego desigual cambian el conteo sin que la humedad relativa sea la causa. La réplica independiente repite el ensayo entero, no cuenta dos veces las mismas plantas. Con un solo contraste la lectura puede ser compatible con la hipótesis y seguir siendo provisional.

Dibuja el flujo pregunta→hipótesis→predicción→controles→datos→lectura, y anota qué mide tu sensor.
