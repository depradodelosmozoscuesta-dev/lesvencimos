El teorema del coseno

Sentido de la medida: resolución de triángulos mediante el teorema del coseno, y el caso rectángulo en el que la fórmula devuelve el teorema de Pitágoras. Decreto 40/2022, Castilla y León.

Objetivos

  • Aplicar c2 = a2 + b2 − 2ab cos C cuando se conocen dos lados y el ángulo comprendido.
  • Hacer la cuenta de los lados 5 y 7 con 60° y dejar el lado opuesto como √39.
  • Ver que, si el ángulo es 90°, el teorema se reduce a Pitágoras porque el coseno es 0.

Explicación

El teorema del coseno cierra el caso en el que se conocen dos lados y el ángulo que forman, el SAS, y también sirve para hallar un ángulo cuando se conocen los tres lados. La forma que usa esta lección es c2 = a2 + b2 − 2ab cos C. El ángulo C tiene que ser el comprendido entre los lados a y b. El lado c es el opuesto, el que no toca a C en el otro extremo de los dos lados. Si se mete en la fórmula el ángulo que no está entre a y b, el resultado es otro triángulo.

El signo menos

El término −2ab cos C corrige a Pitágoras. Si C es agudo, el coseno es positivo y ese término se resta: el lado opuesto es más corto que en el rectángulo de catetos a y b. Si C es obtuso, el coseno es negativo y −2ab por un negativo se suma. Esta lección calcula un agudo de 60° y un recto de 90°, que ya se puede contrastar con otra herramienta.

Coseno de 60° y de 90°

cos 60° = 1/2
1/2 = 0,5, exacto. No es una aproximación de la calculadora. cos 90° = 0. Por eso, si C = 90°, la fórmula queda c2 = a2 + b2 − 2ab · 0 = a2 + b2. El teorema del coseno contiene a Pitágoras; no lo contradice.

Despejar el coseno, si hiciera falta

Si se conocen los tres lados, cos C = (a2 + b2 − c2) / (2ab). En el ejemplo del ángulo recto se usa esta lectura al revés: si el numerador sale 0, el coseno es 0 y el ángulo es 90°, siempre que a y b no sean cero.

Glosa de los símbolos de esta lección

c2 = a2 + b2 − 2ab cos C
Teorema del coseno. C es el ángulo comprendido entre los lados a y b; c es el lado opuesto.
cos C
Coseno del ángulo comprendido. En esta lección, 1/2 si C = 60° y 0 si C = 90°.
√
Raíz principal del lado, cuando el cuadrado no es un cuadrado perfecto. √39 no se simplifica, porque 39 = 3 · 13.

Ejemplo 1, paso a paso: 5, 7 y 60°

a = 5, b = 7, C = 60°, hallar c

  1. c2 = 52 + 72 − 2 · 5 · 7 · cos 60°.
  2. 52 = 25 y 72 = 49. Suma: 25 + 49 = 74.
  3. cos 60° = 1/2
    1/2 = 0,5.
  4. 2 · 5 = 10
    10 · 7 = 70
    70 · 0,5 = 35. El término que se resta es 35, no 70.
  5. c2 = 74 − 35
    74 − 35 = 39. También se puede leer de un golpe: 25 + 49 = 74
    2 · 5 = 10
    10 · 7 = 70
    70 · 0,5 = 35
    74 − 35 = 39.
  6. c = √39. 39 no es un cuadrado perfecto: 62 = 36 y 72 = 49. Factorización 39 = 3 · 13, sin pareja de primos, así que la raíz no se saca del signo.

Resultado: c = √39. No se sustituye √39 por un decimal.

Ejemplo 2, paso a paso: el ángulo recto

a = 6, b = 8, C = 90°

  1. c2 = 36 + 64 − 2 · 6 · 8 · cos 90°.
  2. cos 90° = 0, luego el último término es 0.
  3. c2 = 100 y c = 10, porque el lado es una longitud positiva.
  4. Es el triángulo 6-8-10, múltiplo de 3-4-5: 36 + 64 = 100.
  5. Lectura inversa: 36 + 64 = 100
    100 − 100 = 0
    2 · 6 = 12
    12 · 8 = 96
    0 / 96 = 0
    cos C = 0, que confirma 90°.

Resultado: c = 10. Con ángulo recto, el teorema del coseno es Pitágoras.

Error típico, corregido

En el ejemplo de 60° se olvida el coseno y se resta 2 · 5 = 10
10 · 7 = 70. Entonces 74 − 70 = 4 y el lado saldría 2. Esa cuenta es la de un ángulo de 0°, no la de 60°, porque cos 0° = 1 y el término completo sería 70. Para 60° el factor es 0,5 y se restan 35. 74 − 35 = 39, no 4.

El otro descuido es escribir c2 = a2 + b2 + 2ab cos C con el signo más siempre. En el agudo el término se resta. El signo más aparecería, de hecho, al mover un coseno negativo de un obtuso, no por cambiar la fórmula a mano.

Figura: lados 5 y 7 con 60° entre ellos

El lado de abajo mide 7 unidades de dibujo, el inclinado mide 5 y el ángulo entre ellos es 60°. El lado que cierra, enfrente del ángulo, es √39, más corto que 7 y más largo que 6, porque 36 < 39 < 49.

Escala 36 px por unidad. El lado 7 va de x = 70 a x = 322 (252 px). El lado 5, a 60°, avanza 2,5 unidades en horizontal (90 px) y sube (5√3)/2 unidades, redondeadas a 156 px: de y = 210 a y = 54. 156/90 = 1,733, el redondeo de √3 que deja el ángulo en 60°. El lado ámbar no se mide en píxeles: su cuadrado es 39.

En la vida real

Cerrar un triángulo del que se ve el ángulo

Dos tramos medidos, 5 y 7 unidades, con un ángulo de 60° entre ellos, determinan el tramo que falta. No se suma 5 + 7 ni se aplica Pitágoras, porque el ángulo no es recto. El cuadrado de ese tramo es 39. Si el ángulo medido hubiera sido 90°, la misma fórmula, con coseno 0, habría dado el teorema de Pitágoras y un lado entero.

Comprueba

Con lados 5 y 7 y ángulo comprendido 60°, ¿cuánto vale c2?

Respuesta:
25 + 49 = 74
74 − 35 = 39, y el lado es √39.

Por qué: 2 · 5 = 10
10 · 7 = 70
70 · 0,5 = 35, no 70. 74 − 35 = 39. 39 no es un cuadrado perfecto, así que el lado se deja como raíz.

Con lados 6 y 8 y ángulo comprendido 90°, ¿cuánto mide el lado opuesto?

Respuesta: 10.

Por qué: el coseno de 90° es 0, el término con el doble producto desaparece y queda 36 + 64 = 100. La raíz positiva de 100 es 10.

¿Qué queda de la fórmula si el ángulo comprendido es 90°?

Respuesta: c2 = a2 + b2, el teorema de Pitágoras.

Por qué: cos 90° = 0, y restar 2ab · 0 no cambia la suma de cuadrados. El coseno no es un adorno opcional: cuando vale cero, la fórmula lo dice ella sola.
