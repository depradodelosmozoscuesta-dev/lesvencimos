Lección 28 · Sentido algebraico

Elegir qué clase de función modeliza la situación

1º Bachillerato Matemáticas I · Ciencias y Tecnología

Saberes (Decreto 40/2022): relaciones cuantitativas en situaciones sencillas; identificar la clase de funciones que puede modelizarlas (sentido algebraico).

Objetivos

  1. Elegir qué clase de función modeliza una situación sencilla: lineal, cuadrática, proporcionalidad inversa, exponencial o logarítmica.
  2. Justificar la elección con el tipo de crecimiento, no con un ajuste estadístico.
  3. Comprobar la elección con números declarados en la lección.

Explicación

Los números de abajo son ejemplos fijados en la lección para que se vea la clase de función. No son datos medidos ni una muestra estadística.

Cómo se elige

  • Lineal (recta): en cada paso igual se suma la misma cantidad. Puede no pasar por el origen: V(t) = 10 + 4t.
  • Cuadrática: aparece un producto de dos cantidades que dependen de la misma variable, como un área x·x = x2.
  • Proporcionalidad inversa: el producto de las dos magnitudes es constante, como un reparto 12/n.
  • Exponencial: cada paso multiplica por el mismo número, como 2n.
  • Logarítmica: se pregunta el exponente, la inversa de la exponencial. log2(16) responde «cuántas veces hay que duplicar», no «cuánta cantidad hay».

Cuatro situaciones

1. Lineal. Un depósito tiene ya 10 L y recibe 4 L cada minuto. V(t) = 10 + 4t. Razón: el aumento por minuto es fijo. No es inversa (al crecer t, V crece) ni exponencial (no se multiplica el contenido por 4; se le suman 4 L).

2. Cuadrática. El área de un cuadrado de lado x cm es A(x) = x2. Razón: el área es lado por lado. De x = 1 a x = 2 el área pasa de 1 a 4 (sube 3); de 2 a 3 pasa de 4 a 9 (sube 5). No es lineal.

3. Inversa. Se reparten 12 €, cifra fijada aquí, a partes iguales entre n personas (n entero ≥ 1). Cada una recibe 12/n. Razón: n · (12/n) = 12. Si n se duplica, la parte se reduce a la mitad. No es lineal.

4. Exponencial, y el logaritmo como pregunta inversa. Una cantidad de ejemplo empieza en 1 y se duplica cada hora: P(n) = 2n. Razón: el paso es multiplicar por 2, no sumar una cantidad fija. La pregunta «¿cuántas horas para llegar a 16?» no se modeliza con otra exponencial: se modeliza con el logaritmo, porque se busca el exponente. log2(16) = 4, ya que 24 = 16.

Glosas de esta lección

V(t), A(x), P(n) La letra de la función nombra la magnitud; la letra entre paréntesis es la variable.

x2 Cuadrática de este ejemplo: el lado elevado a 2.

12/n Proporcionalidad inversa: el producto de n y del resultado es 12.

2n y log2 Exponencial de base 2 y su inversa. log2(2n) = n.

Ejemplo 1 · Lineal contra cuadrática, con números

Depósito: V(t) = 10 + 4t.

  1. t = 0 → 10. t = 1 → 14. t = 2 → 18. t = 3 → 22.
  2. Diferencias:
    14−10 = 4
    18−14 = 4
    22−18 = 4.

Área: A(1) = 1, A(2) = 4, A(3) = 9, A(4) = 16.

  1. Diferencias: 3, 5, 7. No son constantes: se rechaza un modelo lineal.
  2. A(3) = 3·3
    3·3 = 9, que encaja con x2.

Ejemplo 2 · Inversa, exponencial y logaritmo

  1. Reparto: n = 2 → 12/2 = 6; n = 3 → 12/3 = 4; n = 4 → 12/4 = 3; n = 6 → 12/6 = 2.
  2. Producto siempre 12: 2·6 = 12, 3·4 = 12, 4·3 = 12, 6·2 = 12. Al pasar de 3 a 6 personas, la parte pasa de 4 € a 2 €: la mitad.
  3. Duplicaciones: P(0) = 1, P(1) = 2, P(2) = 4, P(3) = 8, P(4) = 16. Cada término es el doble del anterior, no «cuatro más».
  4. Horas para llegar a 16: 2n = 16 = 24, luego n = 4. Eso es log2(16) = 4. El logaritmo modeliza el exponente; P(n) modeliza la cantidad.

Error típico

Ver que «crece cada vez más deprisa» y elegir siempre una cuadrática, o ver un reparto y escribir 12n.

Corrección: el área x2 crece más deprisa y es cuadrática; la duplicación 1, 2, 4, 8, 16 también crece más deprisa, pero cada paso multiplica por 2: es exponencial. Y 12n sería proporcionalidad directa (n = 2 daría 24 €), no un reparto: el reparto es 12/n, y 2·6 = 12, no 24.

Comprueba

Comprueba · V(3) = 22

Por qué: 4 · 3 = 12
10 + 12 = 22, y 22 − 18 = 4. El paso sigue siendo el mismo: modelo lineal.

Comprueba · 4 personas y 6 personas

Por qué: 12/4 = 3 y 12/6 = 2. No es 12·4 = 48. El producto 4·3 = 12 se conserva: proporcionalidad inversa.

Comprueba · log2(16)

Por qué: 24 = 16, así que el exponente es 4. La cantidad se modeliza con 2n; el número de pasos, con el logaritmo.

Cierre

Se elige la clase mirando si se suma algo fijo, si hay un cuadrado, si el producto es constante, si se multiplica, o si la pregunta pide el exponente. Los números de la lección solo ilustran esa elección.
