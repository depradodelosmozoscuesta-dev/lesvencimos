Lección 29 · Sentido algebraico

Ecuaciones, inecuaciones y sistemas como modelo

1º Bachillerato Matemáticas I · Ciencias y Tecnología

Saberes (Decreto 40/2022): ecuaciones, inecuaciones y sistemas como modelización de situaciones (sentido algebraico).

Objetivos

  1. Traducir un enunciado a una ecuación, una inecuación o un sistema.
  2. Dejar el método general para las lecciones siguientes y, aun así, comprobar la solución en el enunciado.
  3. Descartar la solución que no tiene sentido en el contexto.

Explicación

Primero el modelo

Modelizar es escribir la relación, no todavía dominar todos los métodos. Una frase del tipo «en total», «como máximo» o «uno es 4 más que el otro» se convierte en igualdad o desigualdad. Después se mira si el número obtenido puede ser una longitud, un número de libros o una edad.

Ecuación

En la balda de arriba hay x libros. En la de abajo hay 5 más: x + 5. Entre las dos hay 27: x + (x + 5) = 27.

Inecuación

Hacen falta al menos 18 sillas. Si n es el número de sillas, n ≥ 18, y n es entero. No hace falta aún la tabla de signos de una inecuación polinómica: el enunciado ya es la desigualdad. n = 18 cumple; n = 17 no, porque 17 ≥ 18 es falso.

Sistema

Dos números suman 10 y el primero es 4 más que el segundo: x + y = 10, x = y + 4. Sustituir aquí es solo para comprobar el sentido; el método general de sistemas viene después.

Glosas de esta lección

= Igualdad del modelo: lo que el enunciado dice que coincide.

≥ «Al menos» o «como mínimo». > sería «más que», sin incluir el igual.

Descartar Tirar una solución del álgebra que no cabe en el contexto (una longitud negativa, un número de personas que no es entero, un valor fuera de rango).

Ejemplo 1 · De la frase a la ecuación

  1. x + (x + 5) = 27.
  2. 2x + 5 = 27.
  3. 2x = 22.
  4. x = 11. La balda de abajo: 11 + 5 = 16.
  5. Comprobación: 11 + 16 = 27 y 16 − 11 = 5. Los dos números son enteros positivos: tienen sentido como libros.

Ejemplo 2 · Dos soluciones algebraicas y una que no vale

La longitud en metros de un lado cumple x2 = 16, y una longitud es positiva. Números fijados en el enunciado.

  1. x2 = 16 da x = 4 y x = −4, porque 42 = 16 y (−4)2 = 16.
  2. En el contexto se descarta −4: no es una longitud.
  3. Se acepta 4. Comprueba: 42 = 16.

El sistema de los dos números, para cerrar el modelo: y + 4 + y = 10, 2y = 6, y = 3, x = 7. Comprueba: 7 + 3 = 10 y 7 = 3 + 4. Los dos tienen sentido como números reales; si el enunciado hablara de personas, también valdrían.

Error típico

«Cinco más que x» escrito como 5x, o aceptar x = −4 como longitud.

Corrección: cinco más es x + 5. Con x = 11, 5·11 = 55, que no es 16, y 11 + 55 no es 27. Y (−4)2 = 16 en el álgebra, pero una longitud del enunciado tiene que ser positiva: se queda x = 4.

Práctica

La figura marca las dos raíces de x2 = 16. Pulsa cada una y escribe por qué se acepta o se tira.

Modelo de umbral, con el número 400 fijado en este ejemplo (una entrada analógica de 10 bits va de 0 a 1023). La frase «la salida se enciende si la lectura es al menos 400» es la inecuación lectura ≥ 400. El valor 400 tiene sentido; 1200 no cabe en ese rango y se descartaría aunque alguien lo escribiera.

void setup() { pinMode(8, OUTPUT); }
void loop() {
  int lectura = analogRead(A0);
  if (lectura >= 400) digitalWrite(8, HIGH);
  else digitalWrite(8, LOW);
}

Comprueba

Comprueba · 11 y 16 libros

Por qué: 11 + 16 = 27 y 16 = 11 + 5. Cada igualdad es una frase del enunciado, no una cuenta suelta. «Entre las dos baldas hay 27» es la ecuación x + (x + 5) = 27, que con x = 11 queda 11 + 16 = 27. «En la de abajo hay 5 más» es la otra, 16 = 11 + 5. Las dos frases se cumplen a la vez. Si solo cuadrara la suma y fallara el «cinco más», el modelo estaría a medias: una ecuación sin la frase que le corresponde no traduce el enunciado.

Comprueba · la longitud

Por qué: 42 = 16 y (−4)2 = 16, pero solo 4 es una longitud. Se descarta −4 por el contexto, no porque falle el cuadrado.

Comprueba · 7 y 3

Por qué: 7 + 3 = 10 y 7 − 3 = 4. El sistema traducido se cumple y los dos números tienen sentido.

Cierre

Traducir es elegir igualdad o desigualdad y nombrar las incógnitas. Resolver del todo vendrá después. Hoy basta con que la solución vuelva al enunciado y se tire la que no puede darse en ese contexto.
