Lección 07 · A · Sentido numérico

Los complejos como raíces

Sentido numérico: los números complejos como soluciones de ecuaciones polinómicas que carecen de raíces reales, en forma binómica, con conjugado y módulo. Decreto 40/2022, Castilla y León.

Objetivos

  • Ver que x2 + 1 = 0 no tiene solución real y sí tiene dos soluciones complejas.
  • Escribir un complejo en forma binómica a + bi.
  • Calcular el conjugado y el módulo, y comprobar el módulo con un cuadrado perfecto.

Explicación

El sentido numérico presenta los complejos como soluciones de ecuaciones polinómicas que no tienen raíces reales. El caso mínimo es x2 + 1 = 0. No hace falta más maquinaria: con la forma binómica, el conjugado y el módulo ya se puede comprobar una raíz sustituyendo.

La ecuación que no cabe en los reales

x2 + 1 = 0 equivale a x2 = −1. Ningún real tiene cuadrado negativo, porque el cuadrado de un positivo es positivo, el de un negativo también, y el de cero es cero. Se llama i a un número cuyo cuadrado es −1: i2 = −1. Entonces (i)2 + 1 = 0 y también (−i)2 + 1 = 0, porque (−i)2 = i2 = −1. Las dos soluciones son i y −i.

Factorización: (x − i)(x + i) = x2 − (i)2 = x2 − (−1) = x2 + 1. El polinomio que no tenía raíces reales se abre en cuanto se admite i.

Forma binómica

Todo complejo de esta lección se escribe a + bi, con a y b reales. a es la parte real y b la parte imaginaria. Ojo: la parte imaginaria es el real b, no el producto bi. Así 3 + 4i tiene parte real 3 y parte imaginaria 4. Un real es un complejo con b = 0. Un imaginario puro tiene a = 0, como 2i o −i.

Conjugado y módulo

El conjugado de z = a + bi es z̄ = a − bi. Solo cambia el signo de la parte imaginaria. El módulo es |z| = √(a2 + b2), la distancia al origen en el plano donde el eje horizontal es la parte real y el vertical la imaginaria. Ejemplo de cierre perfecto: |3 + 4i| = √(9 + 16) = √25 = 5. El conjugado 3 − 4i tiene el mismo módulo, porque (−4)2 = 16.

Otra ecuación de segundo grado

x2 + 2x + 2 = 0. El discriminante es 4 − 8 = −4, negativo: no hay raíces reales. La fórmula da x = (−2 ± √(−4)) / 2. Como √(−4) = √(4 · −1) = 2i en este contexto, x = (−2 ± 2i) / 2 = −1 ± i. Sustitución de −1 + i: (−1 + i)2 + 2(−1 + i) + 2 = (1 − 2i + i2) + (−2 + 2i) + 2 = (1 − 2i − 1 − 2 + 2i + 2). Los reales: 1 − 1 − 2 + 2 = 0. Los imaginarios: −2i + 2i = 0. Cuadra. La otra raíz, −1 − i, es su conjugada y también anula el polinomio, porque los coeficientes son reales.

Glosa de los símbolos de esta lección

i
Unidad imaginaria: i2 = −1. No es un real.
a + bi
Forma binómica. a y b son reales; a es la parte real y b la parte imaginaria.
z̄
Conjugado de z = a + bi: a − bi.
|z|
Módulo: √(a2 + b2). No es |a| + |b|.
ℂ
Conjunto de los complejos a + bi.

Ejemplo 1, paso a paso

Raíces de x2 + 1 = 0 y módulo de 3 + 4i

  1. x2 = −1. En reales, imposible.
  2. i2 = −1 y (−i)2 = −1. Soluciones: i y −i.
  3. (x − i)(x + i) = x2 + 1, porque −i2 = 1.
  4. Para z = 3 + 4i, el conjugado es 3 − 4i.
  5. |z| = √(9 + 16) = √25 = 5.

Resultados: raíces ±i, conjugado 3 − 4i, módulo 5.

Ejemplo 2, paso a paso

x2 + 2x + 2 = 0

  1. Discriminante: 22 − 4 · 1 · 2 = 4 − 8 = −4.
  2. x = (−2 ± √(−4)) / 2 = (−2 ± 2i) / 2.
  3. Se divide: −2/2 ± 2i/2 = −1 ± i.
  4. Sustituye −1 + i. Cuadrado: 1 − 2i + i2 = 1 − 2i − 1 = −2i.
  5. Doble del número: 2(−1 + i) = −2 + 2i. Suma total: −2i + (−2 + 2i) + 2 = 0.

Resultado: −1 + i y −1 − i. El módulo de cada una es √(1 + 1) = √2.

Error típico, corregido

Se calcula |3 + 4i| como 3 + 4 = 7. El módulo no suma los valores absolutos de las partes. Suma sus cuadrados y luego hace la raíz: √(9 + 16) = 5. El 7 no es la distancia al origen; es la suma de los catetos, que es más larga que la hipotenusa.

Otro error: decir que x2 + 1 = 0 «no tiene solución». No tiene solución real. En complejos tiene dos, i y −i, y las dos se comprueban al sustituir.

Figura: 3 + 4i en el plano

Eje horizontal, parte real; eje vertical, parte imaginaria. Origen en (160, 150) y 30 px por unidad: 3 + 4i cae en (250, 30) porque 160 + 90 = 250 y 150 − 120 = 30. El conjugado cae en (250, 270). El triángulo 3-4-5 da el módulo: 9 + 16 = 25.

En la vida real

Una ecuación que el enunciado no tacha

En un problema, «no tiene solución» solo es válido si se dice en qué conjunto. x2 + 1 = 0 no corta el eje real y sí tiene dos raíces en el plano complejo. Decir el conjunto forma parte de la respuesta, igual que decir las unidades en un resultado de medida.

Comprueba

¿Cuáles son las soluciones de x2 + 1 = 0?

Respuesta: i y −i.

Por qué: las dos tienen cuadrado −1, así que al sumar 1 se obtiene 0. En los reales no hay ninguna.

Calcula el módulo de 3 − 4i.

Respuesta: √(9 + 16) = 5.

Por qué: el signo de la parte imaginaria desaparece al elevar al cuadrado. Es el mismo módulo que el de 3 + 4i.

¿Cuál es el conjugado de 1 + i y cuánto vale el producto de los dos?

Respuesta: el conjugado es 1 − i y el producto es 2.

Por qué: (1 + i)(1 − i) = 1 − (i)2 = 1 − (−1) = 2, que es 12 + 12, el cuadrado del módulo.
