Generalizar un patrón en una situación sencilla

1º Bachillerato Matemáticas I · Ciencias y Tecnología

Saberes (Decreto 40/2022): generalización de patrones en situaciones sencillas (sentido algebraico).

Objetivos

  1. Pasar de los primeros términos de una sucesión a un término general an.
  2. Reconocer un patrón lineal (se suma siempre lo mismo) y uno cuadrático (aparece n2).
  3. Comprobar el término general sustituyendo los primeros naturales.

Explicación

Qué es generalizar

Un patrón en una situación sencilla es una lista cuyos primeros términos se ven, y se busca una regla que valga para el lugar n (n = 1, 2, 3, …). Esa regla es el término general. No basta con adivinar el siguiente número: hay que comprobar varios términos y decir la fórmula.

Lineal: se suma siempre lo mismo

Si la primera diferencia es constante, el término general es de primer grado: an = dn + b. Aquí la diferencia constante es 3 y el primer término, para n = 1, es 5. Entonces an = 3n + 2, porque 3·1 + 2 = 5.

Cuadrático: no se suma siempre lo mismo

Los cuadrados 1, 4, 9, 16, 25 tienen término general bn = n2. Las primeras diferencias son 3, 5, 7, 9: crecen, no son constantes. Por eso «sumar siempre lo mismo» no sirve. Las segundas diferencias son 2, 2, 2, y eso encaja con un término que lleva n2.

Glosas de esta lección

an Término que ocupa el lugar n. n empieza en 1.

n2 n al cuadrado: n·n. No es 2n.

Primera diferencia an+1 − an. Si no cambia, el patrón es lineal.

Segunda diferencia Diferencia de las primeras diferencias. Constante y no nula avisa de un término con n2.

Ejemplo 1 · Patrón lineal

Situación sencilla, números fijados: el día n se anotan 3n + 2 marcas. Los primeros términos deberían ser 5, 8, 11, 14, 17.

  1. n = 1: 3·1 + 2 = 5.
  2. n = 2: 3·2 + 2 = 8.
  3. n = 3: 3·3 + 2 = 11.
  4. n = 4: 3·4 + 2 = 14.
  5. n = 5: 3·5 + 2 = 17.
  6. Diferencias: 8−5 = 3, 11−8 = 3, 14−11 = 3, 17−14 = 3. Siempre 3. El término general lineal queda comprobado en los cinco primeros.

Ejemplo 2 · Patrón cuadrático n2

Una cuadrícula de n por n casillas tiene 1, 4, 9, 16, 25 casillas. El término general propuesto es bn = n2.

  1. 12 = 1, 22 = 4, 32 = 9, 42 = 16, 52 = 25. Coinciden los cinco primeros.
  2. Primeras diferencias: 4−1 = 3, 9−4 = 5, 16−9 = 7, 25−16 = 9. No son iguales.
  3. Segundas: 5−3 = 2, 7−5 = 2, 9−7 = 2.
  4. Un candidato lineal que pase por los dos primeros, bn = 3n − 2, da para n = 3 el valor 7, y 7 ≠ 9. Se descarta.

Error típico

Ver 1, 4, 9 y decir «voy sumando 3, luego 5, luego 7…» como si eso ya fuera el término general, o forzar an = 3n − 2 para toda la lista.

Corrección: la regla verbal «suma 2 más que la vez anterior» no dice cuánto vale el término 100. n2 sí: el término 100 es 10 000. Y 3·3 − 2 = 7 no es 9, así que esa fórmula lineal no es el patrón.

Práctica

El control n enseña las dos listas a la vez. Escribe el término general de cada una y comprueba n = 4 a mano.

Si tienes una placa (opcional)

Un bucle corto imprime las dos sucesiones de la lección (números del modelo, no una medición). La primera columna suma 3 cada vez; la segunda es n·n.

void setup() { Serial.begin(9600); }
void loop() {
  for (int n = 1; n <= 5; n++) {
    Serial.print(3 * n + 2);
    Serial.print(" ");
    Serial.println(n * n);
  }
  delay(2000);
}

En una Raspberry Pi el mismo bucle es for n in range(1, 6): print(3*n+2, n*n). La salida tiene que ser 5 1, 8 4, 11 9, 14 16, 17 25.

Comprueba

Comprueba · a4 del patrón lineal

Por qué: 3·4 + 2 = 12 + 2 = 14, y 14 − 11 = 3, la misma diferencia de siempre. En este patrón lineal el término general sí se puede leer como «el anterior más la diferencia», porque la primera diferencia es constante. Cuando el patrón es n² eso deja de valer: la diferencia primera no es constante (3, 5, 7, 9) y la segunda sí, siempre 2. Por eso el término general de los cuadrados es n², no «el anterior más 3». Una diferencia que cambia no es una regla para el lugar n.

Comprueba · b4 = 42

Por qué: 4·4 = 16. La diferencia con 9 es 7, no 3: no se suma siempre lo mismo. El término general no es «el anterior más la diferencia» cuando el patrón es n², porque la diferencia primera no es constante; la segunda sí, y vale 2. Esa segunda diferencia constante avisa de un término con n². Sumar siempre la primera diferencia del principio no reproduce 16 ni los cuadrados siguientes: el salto crece, y n² es la regla que sí se puede comprobar en el lugar n.

Comprueba · por qué falla 3n − 2

Por qué: en n = 1 y n = 2 da 1 y 4, pero en n = 3 da 7 y el cuadrado es 9. Un patrón que falla en el tercer término no es el término general.

Cierre

Generalizar es escribir an y comprobarlo. Diferencia constante: patrón lineal. Diferencias que crecen de dos en dos, como en n2: patrón cuadrático. No todo se arregla sumando siempre lo mismo.

Reto

El término 10

Calcula a10 = 3·10 + 2 y b10 = 102. Di cuánto habrías fallado si, desde b1 = 1, hubieras sumado siempre 3 hasta el lugar 10 (eso daría 1 + 9·3).
