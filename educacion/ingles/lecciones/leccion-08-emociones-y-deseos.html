Emociones y deseos

1º Bachillerato Inglés I · CyL Decreto 40/2022 · bloque A, Comunicación · emociones y deseos de ahora: feel más adjetivo, would like to, wish y if only con pasado simple

Objetivos

  1. Decir el estado con feel más adjetivo, sin adverbio y sin copiar el me del español.
  2. Pedir o desear con would like to más infinitivo, y reservar I like para el gusto general.
  3. Expresar un deseo sobre el presente con wish más pasado simple: I wish I had more time significa que ahora no lo tienes.
  4. Decir el mismo deseo de ahora con if only más pasado simple, sin mezclarlo con would have ni con el condicional III.

Trabajas la competencia de producir y de interactuar. El calendario de ayer no se usa para este deseo.

Explicación

Decir cómo te sientes y qué deseas no es copiar el español palabra por palabra. Feel va con un adjetivo, no con un adverbio y no con un me de más. Would like to pide o desea con cortesía, y no es lo mismo que I like, el gusto de siempre. Wish más pasado simple, y if only más pasado simple, dicen un deseo sobre el ahora: lo que quieres no es verdad en este momento. Ese pasado no es un relato de ayer ni el condicional III. El III lamenta un pasado con would have. Aquí no entra.

Feel más adjetivo

Feel aquí va seguido de adjetivo: I feel nervous. She feels tired. We feel ready. El adjetivo no cambia a adverbio. Incorrecto: I feel nervously. I feel tiredly. Tampoco se copia el «me» del español ni se dobla el verbo. Incorrecto: I feel myself nervous. I am feel tired. I feel am sad. Correcto: I feel nervous before the oral. I don't feel ready yet. La negativa es don't / doesn't feel más el adjetivo, no feel not. Si quieres decir que algo te produce esa emoción, puedes cambiar el sujeto: The oral makes me nervous, pero la fórmula de esta lección, la que describe tu estado, sigue siendo I feel más adjetivo.

Would like to, distinto de I like

Would like to más infinitivo es un deseo o una petición cortés, de ahora, hacia algo concreto. I would like to visit Zamora. I'd like to ask a question. I like es el gusto general, y suele ir con nombre o con -ing: I like museums. I like walking. No intercambies. Incorrecto: I would like visiting Zamora cuando quieres el deseo cortés de esta lección (la forma enseñada es would like to más infinitivo). Incorrecto: I like to visit Zamora tomorrow para un deseo de un día concreto: like no fecha el deseo. Correcto: I like old towns. I would like to visit Zamora this term. Would no lleva -s: no she would likes.

Wish más pasado simple: el deseo de ahora

I wish más pasado simple dice que ahora la realidad es la contraria. I wish I had more time significa que no lo tienes. I wish I knew the answer significa que no la sabes. I wish I were taller usa were con I, como en el consejo hipotético, porque el deseo no es real. No es un pasado de ayer: el verbo va en pasado y el sentido es presente. Incorrecto para este deseo: I wish I have more time (presente, y suena a que sí lo tienes o a una forma que no es la de wish). Incorrecto: I wish I would have more time como si el deseo de ahora llevara would have. Ese would have pertenece al condicional III, el lamento de un pasado cerrado, y esta lección no lo usa.

If only más pasado simple, al lado de wish

If only más el mismo pasado simple dice el mismo deseo de ahora, a menudo con más ganas. If only I had more time. If only I knew the answer. If only I were taller. Puedes ponerlo al lado de wish: I wish I had more time. If only I had more time. Las dos miran el reloj de ahora, no el calendario tachado. No llevan would en el deseo de esta lección, y no llevan past perfect. Incorrecto si lo que quieres es un deseo de ahora: If only I had had more time yesterday. If only I would have studied. If only I have more time. La primera y la segunda se van al pasado cerrado, al lado del condicional III (would have), y aquí ese calendario está tachado a propósito. No las mezcles con If only I had more time, que es presente irreal: had es pasado simple de have, no had had.

Cómo no confundir las formas de have. I wish I had more time / If only I had more time: un solo had, pasado simple, sentido de ahora. If only I had had more time: dos had, past perfect, sentido de pasado. Esa segunda no se enseña como herramienta de esta lección. Si la escribes queriendo decir que ahora te falta tiempo, el oyente entiende un ayer. El dibujo tachado está para eso.

Estado: feel más adjetivo. Petición cortés: would like to más infinitivo. Gusto de siempre: like más nombre o -ing. Deseo de ahora: wish o if only más pasado simple, were con be. Si aparece would have o un segundo had, te has ido al pasado cerrado, y esa no es la herramienta de hoy.

Texto trabajado 1 — Nota de diario

Texto de clase, no es un diario real:

I feel nervous about the oral, but I feel ready for the written part. I like quiet rooms. I would like to practise with a partner tomorrow. I wish I had more time tonight. If only I knew the first question. I wish I were calmer. I don't feel tired yet.

Paso 1. Feel nervous, feel ready, don't feel tired: adjetivos, no adverbios. Nervously no describe el estado. Like quiet rooms es gusto general, nombre. Would like to practise es el deseo concreto de mañana, con to más infinitivo, no would like practising como fórmula de esta lección.

Paso 2. I wish I had more time tonight: esta noche no lo tiene; had es pasado simple y el sentido es ahora. If only I knew the first question: no la sabe ahora; knew es el pasado de know, no know ni had known. I wish I were calmer: were, no I wish I am calmer.

Paso 3. Nada en la nota abre el calendario de ayer. No hay would have ni had had. Incorrecto al lado, si el deseo es de ahora: If only I had had more time last night. I wish I would have known. Esas frases lamentan un pasado y aquí no se piden. Correcto: las tres de deseo del diario, todas con pasado simple y sentido presente.

Glosa de las palabras de este ejemplo. Nervous: nervioso; adjetivo detrás de feel. Oral: la prueba oral. Written part: la parte escrita. Ready: preparado. Quiet rooms: salas en calma; objeto de like. Practise: practicar; infinitivo detrás de would like to. Partner: compañero de práctica. Knew: pasado de know, en el deseo. Calmer: más tranquilo. Yet: todavía, en don't feel tired yet.

Texto trabajado 2 — Diálogo corto

Texto de clase:

Mateo: You look worried. Do you feel ill?
Inés: I don't feel ill. I feel unsure. I would like to start again.
Mateo: I like your idea. I wish we had another hour. If only the room were quieter.
Inés: If only I had slept more last night… No. That is a past regret. If only I had more sleep now. That's the wish.

Paso 1. Do you feel ill? y I don't feel ill / I feel unsure: adjetivos, pregunta con do, no Do you feel yourself ill? Would like to start es la petición. I like your idea es gusto sobre algo que ya está, no un deseo con to de cortesía.

Paso 2. I wish we had another hour y If only the room were quieter son deseos de ahora: no tenemos esa hora, la sala no está más en calma. Were con the room. No If only the room would have been quieter, que abre el III.

Paso 3. Inés se corrige en voz alta: If only I had slept more last night es el lamento de pasado (past perfect de sentido, un ayer), y ella lo aparta. El deseo de ahora que sí vale es If only I had more sleep now, un solo had, pasado simple, con now que ancla el reloj. El diálogo enseña el contraste para que no los copies juntos como si fueran la misma herramienta.

Glosa de las palabras de este ejemplo. Worried: preocupado; look worried describe la cara, feel describe el estado por dentro. Ill: enfermo. Unsure: inseguro, sin certeza. Start again: empezar otra vez. Another hour: una hora más, la que no tienen. Quieter: más silenciosa. Slept: participio o pasado de sleep; en had slept se va al ayer y por eso Inés lo rechaza. Now: ahora; fija el deseo en el presente.

Error típico, marcado

Incorrecto: I feel nervously. I would like visiting the town. I wish I have time. If only I would have had time yesterday. Correcto: I feel nervous. I would like to visit the town. I wish I had time. If only I had time. El último par es un deseo de ahora. El would have y el ayer se quedan en el calendario tachado.

Glosas de esta lección

  • Feel + adjetivo. I feel nervous. No nervously, no I am feel.
  • Would like to + infinitivo. deseo o petición cortés.
  • Like + nombre / -ing. gusto general.
  • Wish + pasado simple. deseo de ahora. I wish I had time = no lo tengo.
  • If only + pasado simple. el mismo deseo de ahora. If only I were…
  • Would have / had had. pasado cerrado, condicional III o lamento. No es el deseo de esta lección.

Ejemplos resueltos

El diario y el diálogo ya separan el ahora del ayer. Aquí solo were.

Ejemplo 3 — Were

Paso 1. El deseo es sobre el presente: no estás más tranquilo.

Paso 2. I wish I were calmer. If only I were calmer.

Paso 3. No escribas I wish I am ni If only I would have been para ese mismo deseo de ahora.

En la vida real

Castilla y León

  • Antes de una oral en Valladolid, I feel nervous es el estado. I would like to practise tomorrow es el deseo concreto, no I like practising tomorrow.
  • I wish I had more time tonight y If only I had more time dicen lo mismo: ahora no hay ese tiempo. Un solo had.
  • En Soria, If only the room were quieter es un deseo de ahora. If only I had slept more last night es otro patrón, de pasado, y en esta lección se aparta.

Comprueba

Tres preguntas. Ábrelas cuando hayas contestado, no antes.

No tienes tiempo ahora. ¿Qué par wish / if only lo dice, y qué forma no vale?

I wish I had more time. If only I had more time. No vale If only I would have had more time.

Por qué: Wish e if only, con un solo pasado simple, miran el ahora: la realidad es que no tienes ese tiempo. Would have abre el condicional III, un pasado cerrado, y el calendario de ayer de esta lección está tachado a propósito.

¿Qué diferencia hay entre I like quiet rooms y I would like to practise tomorrow?

La primera es un gusto general. La segunda es un deseo concreto, con to más infinitivo.

Por qué: Like con nombre no fecha una petición. Would like to sí señala lo que quieres hacer, aquí mañana, y no se escribe would like practising ni she would likes. Feel, al lado, sigue siendo adjetivo: I feel nervous, no nervously.

¿Por qué If only I had slept more last night no es el deseo de esta lección?

Porque had slept y last night miran un ayer. El deseo de ahora es If only I had more time, con un solo had y sin fecha pasada.

Por qué: Had más participio, o would have, lamenta un pasado y se acerca al condicional III. Esta lección solo enseña if only más pasado simple para un deseo presente, al lado de wish, sin abrir ese otro patrón.

Mini cierre

Feel + adjetivo. Would like to + infinitivo para el deseo concreto; like para el gusto. Wish y if only + pasado simple: deseo de ahora (I wish I had…, If only I were…). Would have y el pasado cerrado no son esta herramienta.
