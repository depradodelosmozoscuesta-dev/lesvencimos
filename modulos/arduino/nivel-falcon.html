Falcon · AP-FAL-01

Temperatura y humedad en LCD

Objetivo

Al terminar, el LCD 16x2 enseña la temperatura en grados Celsius y la humedad relativa que mide el DHT11, renovadas cada dos segundos con millis para no congelar el programa. La misma lectura sale por el monitor serie, así que compruebas el sensor aunque el contraste de la pantalla todavía esté mal ajustado. Queda un medidor ambiente estable, listo para leer sin pulsar nada.

// AP-FAL-01 Temperatura y humedad en LCD
// Pines: DHT D2, LCD RS D7, E D8, D4 D9, D5 D10, D6 D11, D7 D12
#include <DHT.h>
#include <LiquidCrystal.h>

const int PIN_DHT = 2;
const int PIN_RS = 7;
const int PIN_E = 8;
const int PIN_D4 = 9;
const int PIN_D5 = 10;
const int PIN_D6 = 11;
const int PIN_D7 = 12;
const unsigned long PERIODO_MS = 2000;

DHT dht(PIN_DHT, DHT11);
LiquidCrystal lcd(PIN_RS, PIN_E, PIN_D4, PIN_D5, PIN_D6, PIN_D7);

void setup() {
  Serial.begin(9600);
  dht.begin();
  lcd.begin(16, 2);
  lcd.print("Leyendo DHT11");
  Serial.println("AP-FAL-01 listo");
}

void loop() {
  static unsigned long anterior = 0;
  unsigned long ahora = millis();
  if (ahora - anterior < PERIODO_MS) {
    return;
  }
  anterior = ahora;

  float t = dht.readTemperature();
  float h = dht.readHumidity();
  lcd.clear();
  if (isnan(t) || isnan(h)) {
    lcd.print("Sensor no lee");
    Serial.println("Lectura no valida");
    return;
  }

  lcd.setCursor(0, 0);
  lcd.print("T: ");
  lcd.print(t, 1);
  lcd.print(" C");
  lcd.setCursor(0, 1);
  lcd.print("H: ");
  lcd.print(h, 1);
  lcd.print(" %");

  Serial.print("T ");
  Serial.print(t, 1);
  Serial.print(" C  H ");
  Serial.println(h, 1);
}

Pasos

  1. Elige la Uno R3 o la Uno CH340, no las dos a la vez, y en el IDE selecciona la placa Arduino Uno y el puerto correcto.
  2. Conecta el DHT11: datos a D2, alimentacion a 5 V y GND comun. Respeta la serigrafia del modulo para no invertirlo.
  3. Conecta el LCD en 4 bits: RS a D7, E a D8, D4 a D9, D5 a D10, D6 a D11, D7 a D12 y RW a GND.
  4. Instala la libreria DHT sensor library desde el gestor de librerias del IDE. LiquidCrystal ya viene con el nucleo.
  5. Copia el sketch, compilalo y subelo. Abre el monitor serie a 9600 baudios.
  6. Espera el primer refresco de dos segundos y comprueba que temperatura y humedad coinciden en el LCD y en el serie.
  7. Si la pantalla queda en blanco o en cuadros negros, gira el contraste del propio modulo hasta que se lean las letras.

Variantes

  • Cambia el periodo a cinco segundos si quieres menos ruido en un sensor lento, sin tocar el cableado.
  • Muestra solo la temperatura en la linea 1 y un aviso de humedad alta en la linea 2 cuando pases de un umbral que elijas.
  • Sustituye el DHT11 por un DHT22 si mas adelante cambias el tipo en el constructor, manteniendo el mismo pin D2.

Depuración

  • Si el serie imprime lectura no valida, revisa DATA en D2, la masa comun y que el modulo no este alimentado al reves.
  • Si el LCD no muestra nada y el serie si, el fallo es de pantalla: RW a GND, pines D7 a D12 y el contraste.
  • Si los numeros se quedan clavados, no estas dejando pasar el tiempo entre lecturas: el DHT11 necesita cerca de dos segundos.
  • Si al subir el sketch la placa se reinicia sin parar, hay un corto entre 5 V y GND en el LCD o en el sensor. Quita alimentacion y revisa.

Distancia en LCD

Objetivo

Al terminar, el LCD muestra la distancia en centimetros que mide el HC-SR04 y el monitor serie repite la misma cifra. Si el eco no vuelve a tiempo, la pantalla dice que estas fuera de rango en lugar de inventar un numero. El disparo del trigger y la lectura se repiten varias veces por segundo, asi que al mover la mano ves el valor cambiar sin pulsar nada.

// AP-FAL-02 Distancia en LCD
// Pines: TRIG D2, ECHO D3, LCD RS D7, E D8, D4 D9, D5 D10, D6 D11, D7 D12
#include <LiquidCrystal.h>

const int PIN_TRIG = 2;
const int PIN_ECHO = 3;
const int PIN_RS = 7;
const int PIN_E = 8;
const int PIN_D4 = 9;
const int PIN_D5 = 10;
const int PIN_D6 = 11;
const int PIN_D7 = 12;

LiquidCrystal lcd(PIN_RS, PIN_E, PIN_D4, PIN_D5, PIN_D6, PIN_D7);

float medirCm() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  unsigned long us = pulseIn(PIN_ECHO, HIGH, 30000UL);
  if (us == 0) {
    return -1.0;
  }
  return us / 58.0;
}

void setup() {
  Serial.begin(9600);
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  digitalWrite(PIN_TRIG, LOW);
  lcd.begin(16, 2);
  lcd.print("Distancia");
  Serial.println("AP-FAL-02 listo");
}

void loop() {
  static unsigned long anterior = 0;
  unsigned long ahora = millis();
  if (ahora - anterior < 200) {
    return;
  }
  anterior = ahora;

  float cm = medirCm();
  lcd.setCursor(0, 0);
  lcd.print("Distancia      ");
  lcd.setCursor(0, 1);
  if (cm < 0) {
    lcd.print("Fuera de rango ");
    Serial.println("Fuera de rango");
  } else {
    lcd.print(cm, 1);
    lcd.print(" cm        ");
    Serial.print(cm, 1);
    Serial.println(" cm");
  }
}

Pasos

  1. Monta una sola placa, Uno R3 o Uno CH340, y selecciona Arduino Uno en el IDE.
  2. Conecta TRIG del HC-SR04 a D2, ECHO a D3, VCC a 5 V y GND a masa.
  3. Conecta el LCD: RS D7, E D8, D4 D9, D5 D10, D6 D11, D7 D12 y RW a GND.
  4. Copia el sketch, compilalo y subelo. LiquidCrystal forma parte del nucleo, no hace falta instalarla.
  5. Abre el monitor serie a 9600 y apunta el sensor a una pared cercana, entre 5 y 100 cm.
  6. Comprueba que el LCD y el serie marcan centimetros parecidos y que al tapar el sensor sale fuera de rango.
  7. Ajusta el contraste si la pantalla enciende pero no se leen los numeros.

Variantes

  • Cambia el umbral de actualizacion de 200 ms si quieres una lectura mas tranquila en el serie.
  • Anade una tercera linea logica: si la distancia baja de 15 cm, enciende un modulo de led en un pin libre como D4.
  • Fija el sensor en un lateral y usa el valor para saber si una caja esta en su sitio, sin mover el codigo de medicion.

Depuración

  • Si siempre sale fuera de rango, TRIG y ECHO estan cruzados o el eco no llega a D3.
  • Si el numero oscila mucho, apunta a una superficie plana y perpendicular, no a una tela o a un canto.
  • Si el LCD va en blanco y el serie responde, revisa RW a GND y el orden RS, E y D4 a D7.
  • Si la placa se reinicia al medir, el modulo esta en corto o el eco se ha metido en 5 V. Quita alimentacion y revisa.

Cerradura con PIN en teclado 4×4

Objetivo

Al terminar, la cerradura de juguete se abre solo si tecleas el PIN de cuatro cifras que vive en el propio sketch. No hay servidor, ni clave en la red, ni nada fuera de la placa: el teclado se lee por filas y columnas, el rele se activa unos segundos y luego vuelve a cerrar. La carga del rele es de 5 a 12 V en corriente continua. No se conmuta la red.

// AP-FAL-03 Cerradura con PIN en teclado 4x4
// Pines: filas D2 D3 D4 D5, columnas D6 D7 D8 D9, rele D10, zumbador D11, led D12
// El PIN vive en este sketch. No hay servidor.
// Carga del rele: 5 a 12 V. No se conmuta la red.

const char PIN_SECRETO[] = "1234";
const byte pinesFila[4] = {2, 3, 4, 5};
const byte pinesCol[4] = {6, 7, 8, 9};
const int PIN_RELE = 10;
const int PIN_ZUM = 11;
const int PIN_LED = 12;
const byte RELE_ON = LOW;
const byte RELE_OFF = HIGH;
const unsigned long ABIERTA_MS = 5000;
const unsigned long ERROR_MS = 800;

const char teclas[4][4] = {
  {'1', '2', '3', 'A'},
  {'4', '5', '6', 'B'},
  {'7', '8', '9', 'C'},
  {'*', '0', '#', 'D'}
};

char entrada[5];
byte nEntrada = 0;
bool abierta = false;
unsigned long tEstado = 0;
unsigned long tError = 0;

char leerTecla() {
  for (byte c = 0; c < 4; c++) {
    digitalWrite(pinesCol[c], LOW);
    delayMicroseconds(50);
    for (byte f = 0; f < 4; f++) {
      if (digitalRead(pinesFila[f]) == LOW) {
        digitalWrite(pinesCol[c], HIGH);
        return teclas[f][c];
      }
    }
    digitalWrite(pinesCol[c], HIGH);
  }
  return 0;
}

void cerrar() {
  abierta = false;
  digitalWrite(PIN_RELE, RELE_OFF);
  digitalWrite(PIN_LED, LOW);
}

void setup() {
  Serial.begin(9600);
  for (byte f = 0; f < 4; f++) {
    pinMode(pinesFila[f], INPUT_PULLUP);
  }
  for (byte c = 0; c < 4; c++) {
    pinMode(pinesCol[c], OUTPUT);
    digitalWrite(pinesCol[c], HIGH);
  }
  pinMode(PIN_RELE, OUTPUT);
  pinMode(PIN_ZUM, OUTPUT);
  pinMode(PIN_LED, OUTPUT);
  digitalWrite(PIN_ZUM, LOW);
  cerrar();
  Serial.println("Cerradura local lista. PIN en el sketch, sin servidor.");
}

void loop() {
  unsigned long ahora = millis();
  if (tError != 0 && ahora - tError >= ERROR_MS) {
    digitalWrite(PIN_ZUM, LOW);
    tError = 0;
  }
  if (abierta && ahora - tEstado >= ABIERTA_MS) {
    cerrar();
    nEntrada = 0;
    entrada[0] = 0;
    Serial.println("Cerrada");
  }

  static char previa = 0;
  char tecla = leerTecla();
  if (tecla == 0) {
    previa = 0;
    return;
  }
  if (tecla == previa) {
    return;
  }
  previa = tecla;
  if (abierta) {
    return;
  }
  if (tecla == '*') {
    nEntrada = 0;
    entrada[0] = 0;
    Serial.println("Borrado");
    return;
  }
  if (tecla < '0' || tecla > '9') {
    return;
  }
  if (nEntrada < 4) {
    entrada[nEntrada++] = tecla;
    entrada[nEntrada] = 0;
    Serial.println(entrada);
  }
  if (nEntrada < 4) {
    return;
  }
  if (strcmp(entrada, PIN_SECRETO) == 0) {
    abierta = true;
    tEstado = ahora;
    digitalWrite(PIN_RELE, RELE_ON);
    digitalWrite(PIN_LED, HIGH);
    Serial.println("PIN correcto, abierta");
  } else {
    digitalWrite(PIN_ZUM, HIGH);
    tError = ahora;
    Serial.println("PIN incorrecto");
  }
  nEntrada = 0;
  entrada[0] = 0;
}

Pasos

  1. Monta una sola placa y selecciona Arduino Uno. El PIN por defecto del sketch es 1234 y solo existe dentro del programa.
  2. Conecta las cuatro filas del teclado a D2, D3, D4 y D5, y las cuatro columnas a D6, D7, D8 y D9.
  3. Conecta el IN del rele a D10, el zumbador a D11 y el led a D12, con las masas a GND y VCC de cada modulo a 5 V si el modulo lo trae.
  4. En los contactos del rele pon solo una cerradura o solenoide de 5 a 12 V con su fuente. No se conmuta la red.
  5. Sube el sketch y abre el monitor serie a 9600. Teclea 1234 y comprueba que el led se enciende y el rele cambia unos cinco segundos.
  6. Teclea otro numero de cuatro cifras y comprueba el pitido de error y que la cerradura no se abre.
  7. Pulsa asterisco a mitad de la clave y confirma en el serie que el buffer se borra antes de volver a probar.

Variantes

  • Cambia PIN_SECRETO por otras cuatro cifras y vuelve a subir el sketch: la clave sigue estando solo en la placa.
  • Alarga ABIERTA_MS si el solenoide de juguete necesita mas tiempo para retirar el pestillo.
  • Invierte RELE_ON y RELE_OFF solo si tu modulo enciende la bobina con nivel alto en vez de nivel bajo.

Depuración

  • Si ninguna tecla responde, las filas y las columnas estan cambiadas de grupo o una columna no sale de D6 a D9.
  • Si una fila entera repite la misma tecla, esa columna se ha quedado en bajo porque el pin no esta como salida.
  • Si el PIN es correcto en el serie pero el rele no clica, prueba a invertir el nivel activo y revisa VCC y GND del modulo.
  • Si intentas usar tension de la red en COM o NO, paras el montaje: esta practica solo admite carga de 5 a 12 V.

Alarma de puerta con retardo

Objetivo

Al terminar, la alarma no suena en cuanto alimentas la placa: primero cuenta un retardo de armado para que cierres la puerta, y despues, si el reed detecta que se abre, espera un segundo retardo corto antes de activar el zumbador. Si vuelves a cerrar a tiempo, el aviso se cancela. El conteo entero sale de millis, con un filtrado sencillo del contacto para que un rebote no dispare la sirena.

// AP-FAL-04 Alarma de puerta con retardo
// Pines: reed D2, led armado D4, zumbador D8
const int PIN_REED = 2;
const int PIN_LED = 4;
const int PIN_ZUM = 8;
const unsigned long ARMADO_MS = 15000;
const unsigned long GRACIA_MS = 3000;
const unsigned long FILTRO_MS = 40;

unsigned long arranque;
bool armada = false;
bool puertaAbierta = false;
unsigned long cambioPuerta = 0;
unsigned long abiertaDesde = 0;
bool sonando = false;

bool leerAbiertaFiltrada(unsigned long ahora) {
  bool lecturaAbierta = digitalRead(PIN_REED) == HIGH;
  if (lecturaAbierta != puertaAbierta) {
    if (ahora - cambioPuerta >= FILTRO_MS) {
      puertaAbierta = lecturaAbierta;
    }
  } else {
    cambioPuerta = ahora;
  }
  return puertaAbierta;
}

void setup() {
  Serial.begin(9600);
  pinMode(PIN_REED, INPUT_PULLUP);
  pinMode(PIN_LED, OUTPUT);
  pinMode(PIN_ZUM, OUTPUT);
  digitalWrite(PIN_LED, LOW);
  digitalWrite(PIN_ZUM, LOW);
  arranque = millis();
  cambioPuerta = arranque;
  Serial.println("Retardo de armado. Cierra la puerta.");
}

void loop() {
  unsigned long ahora = millis();
  bool abierta = leerAbiertaFiltrada(ahora);

  if (!armada) {
    digitalWrite(PIN_LED, LOW);
    digitalWrite(PIN_ZUM, LOW);
    if (ahora - arranque >= ARMADO_MS) {
      armada = true;
      abiertaDesde = 0;
      Serial.println("Alarma armada");
    }
    return;
  }

  digitalWrite(PIN_LED, HIGH);
  if (!abierta) {
    abiertaDesde = 0;
    if (sonando) {
      sonando = false;
      digitalWrite(PIN_ZUM, LOW);
      Serial.println("Puerta cerrada, silencio");
    }
    return;
  }

  if (abiertaDesde == 0) {
    abiertaDesde = ahora;
    Serial.println("Puerta abierta, empieza la gracia");
  }
  if (!sonando && ahora - abiertaDesde >= GRACIA_MS) {
    sonando = true;
    digitalWrite(PIN_ZUM, HIGH);
    Serial.println("Alarma");
  }
}

Pasos

  1. Monta una sola placa, selecciona Arduino Uno y conecta la salida del reed a D2 y su GND a masa.
  2. Si el reed es un modulo con VCC, alimentalo a 5 V. Si es un contacto seco, no pongas 5 V: basta D2 y GND.
  3. Coloca el iman de forma que, con la puerta cerrada, el serie acabe viendo el contacto en bajo.
  4. Conecta el led de armado a D4 y el zumbador a D8, ambos con su masa a GND.
  5. Sube el sketch y abre el monitor serie a 9600. Durante quince segundos la alarma no debe sonar aunque abras.
  6. Pasado el armado, abre la puerta: el zumbador espera tres segundos y solo entonces suena. Cierrala y debe callar.
  7. Vuelve a abrir y cierra antes de tres segundos para comprobar que la gracia cancela el aviso.

Variantes

  • Acorta ARMADO_MS a cinco segundos mientras pruebas, y dejalo en quince cuando lo montes en la puerta.
  • Anade un pulsador a un pin libre para desarmar sin cortar la alimentacion, reutilizando el mismo filtro de tiempo.
  • Cambia el led de armado por un parpadeo lento con millis si no quieres una luz fija junto al marco.

Depuración

  • Si suena con la puerta cerrada, el iman no actua o la logica esta al reves: acerca el iman y mira si D2 pasa a LOW.
  • Si nunca arma, estas reiniciando la placa al abrir el serie o el retardo todavia no ha vencido.
  • Si el zumbador entra y sale a golpes, el reed rebota y el filtro es corto: sube FILTRO_MS a 80.
  • Si el modulo de zumbador suena al reves, invierte el nivel en las dos escrituras de PIN_ZUM.

Objetivo

Al terminar, la placa lee la humedad del suelo por A0 y, si la tierra esta seca por encima del umbral que calibres, activa el rele el tiempo justo para regar y luego lo corta aunque el sensor tarde en reaccionar. // AP-FAL-05 Riego segun humedad del suelo

// Muchos modulos dan un numero ALTO con la tierra seca. Calibralo.
const int UMBRAL_SECO = 650;
const unsigned long PERIODO_MS = 1000;
const unsigned long RIEGO_MS = 8000;

// AP-FAL-07 Semaforo con presencia
// Pines: rojo D2, ambar D3, verde D4, TRIG D7, ECHO D8
const int PIN_ROJO = 2;
const int PIN_AMBAR = 3;
const int PIN_VERDE = 4;
const int PIN_TRIG = 7;
const int PIN_ECHO = 8;

enum Fase { VERDE, AMBAR, ROJO };
Fase fase = VERDE;
unsigned long inicioFase = 0;

const unsigned long T_VERDE = 5000;
const unsigned long T_AMBAR = 2000;
const unsigned long T_ROJO_MIN = 2000;
const unsigned long T_ROJO_MAX = 8000;
const float CERCA_CM = 40.0;

float medirCm() {
  digitalWrite(PIN_TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(PIN_TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(PIN_TRIG, LOW);
  unsigned long us = pulseIn(PIN_ECHO, HIGH, 30000UL);
  if (us == 0) {
    return -1.0;
  }
  return us / 58.0;
}

void pintar() {
  digitalWrite(PIN_VERDE, fase == VERDE ? HIGH : LOW);
  digitalWrite(PIN_AMBAR, fase == AMBAR ? HIGH : LOW);
  digitalWrite(PIN_ROJO, fase == ROJO ? HIGH : LOW);
}

void cambiar(Fase nueva, unsigned long ahora) {
  fase = nueva;
  inicioFase = ahora;
  pintar();
  if (fase == VERDE) Serial.println("Fase verde");
  if (fase == AMBAR) Serial.println("Fase ambar");
  if (fase == ROJO) Serial.println("Fase rojo");
}

void setup() {
  Serial.begin(9600);
  pinMode(PIN_ROJO, OUTPUT);
  pinMode(PIN_AMBAR, OUTPUT);
  pinMode(PIN_VERDE, OUTPUT);
  pinMode(PIN_TRIG, OUTPUT);
  pinMode(PIN_ECHO, INPUT);
  cambiar(VERDE, millis());
}

void loop() {
  unsigned long ahora = millis();
  unsigned long lleva = ahora - inicioFase;

  if (fase == VERDE && lleva >= T_VERDE) {
    cambiar(AMBAR, ahora);
    return;
  }
  if (fase == AMBAR && lleva >= T_AMBAR) {
    cambiar(ROJO, ahora);
    return;
  }
  if (fase == ROJO) {
    float cm = medirCm();
    bool presencia = (cm > 2.0 && cm < CERCA_CM);
    if (lleva >= T_ROJO_MAX || (presencia && lleva >= T_ROJO_MIN)) {
      cambiar(VERDE, ahora);
    }
  }
}

  6. Comprueba que en el primer instante del rojo la presencia no lo salta: el minimo de dos segundos se respeta.

const int PIN_SIG = 3;

const int PIN_D5 = 10;

Vista vista = NAVEGA;

  static unsigned long cambio[20];
  static byte estable[20];
  static byte previo[20];
  static bool listo = false;
  if (!listo) {
    for (byte i = 0; i < 20; i++) {
      estable[i] = HIGH;
      previo[i] = HIGH;
      cambio[i] = 0;

    listo = true;

// AP-FAL-12 Voltimetro con divisor resistivo
// Pines: A0 es el nudo entre dos resistencias de 10 kOhm.
// La entrada del pin no debe pasar de 5 V.
const int PIN_MEDIDA = A0;
const float VREF = 5.0;
const float R_ALTA = 10000.0; // 10 kOhm
const float R_BAJA = 10000.0; // 10 kOhm
const unsigned long PERIODO_MS = 400;

void setup() {
  Serial.begin(9600);
  Serial.println("Voltimetro listo. Entrada A0 maximo 5 V.");
}

void loop() {
  static unsigned long anterior = 0;
  unsigned long ahora = millis();
  if (ahora - anterior < PERIODO_MS) {
    return;
  }
  anterior = ahora;

  int adc = analogRead(PIN_MEDIDA);
  float vPin = adc * (VREF / 1023.0);
  float vExt = vPin * (R_ALTA + R_BAJA) / R_BAJA;

  Serial.print("ADC ");
  Serial.print(adc);
  Serial.print("  Vpin ");
  Serial.print(vPin, 2);
  Serial.print(" V  Vext ");
  Serial.print(vExt, 2);
  Serial.println(" V");

  if (vPin > 4.8) {
    Serial.println("Casi al tope: no subas mas la tension exterior.");
  }
}

  3. Une la masa de la fuente que vas a medir con el GND de la placa. Sin esa masa comun la lectura no vale.

Variantes

// Pines: LDR en A0 con 10 kOhm a GND, LED PWM en D9
const int PIN_LDR = A0;
const int PIN_LED = 9;
const unsigned long PERIODO_MS = 50;

void setup() {
  Serial.begin(9600);
  pinMode(PIN_LED, OUTPUT);
  analogWrite(PIN_LED, 0);
  Serial.println("Brillo proporcional listo");
}

void loop() {
  static unsigned long anterior = 0;
  unsigned long ahora = millis();
  if (ahora - anterior < PERIODO_MS) {
    return;
  }
  anterior = ahora;

  int luz = analogRead(PIN_LDR);
  int brillo = map(luz, 0, 1023, 0, 255);
  brillo = constrain(brillo, 0, 255);

  Serial.print(luz);
  Serial.print("  PWM ");

// AP-FAL-14 Cafetera de juguete
// Pines: boton D2, calor D3, lista D4, servir D5, zumbador D6
// Maquina de estados con enum y switch. Sin esperas bloqueantes.
const int PIN_BOTON = 2;
const int PIN_CALOR = 3;
const int PIN_LISTA = 4;
const int PIN_SERVIR = 5;
const int PIN_ZUM = 6;

enum Estado { REPOSO, CALENTANDO, LISTA, SIRVIENDO };
Estado estado = REPOSO;

const unsigned long T_CALENTAR = 8000;
const unsigned long T_SERVIR = 4000;
const unsigned long T_PITIDO = 150;

unsigned long tFase = 0;
unsigned long finPitido = 0;
bool pitido = false;
bool botonAntes = HIGH;

void leds(bool calor, bool lista, bool servir) {
  digitalWrite(PIN_CALOR, calor ? HIGH : LOW);
  digitalWrite(PIN_LISTA, lista ? HIGH : LOW);
  digitalWrite(PIN_SERVIR, servir ? HIGH : LOW);
}

void entrar(Estado nuevo, unsigned long ahora) {
  estado = nuevo;
  tFase = ahora;
  if (nuevo == LISTA) {
    pitido = true;
    finPitido = ahora + T_PITIDO;
  }
  Serial.println(
    nuevo == REPOSO ? "REPOSO" :
    nuevo == CALENTANDO ? "CALENTANDO" :
    nuevo == LISTA ? "LISTA" : "SIRVIENDO");
}

bool pulsado() {
  bool ahoraBtn = digitalRead(PIN_BOTON);
  bool flanco = (botonAntes == HIGH && ahoraBtn == LOW);
  botonAntes = ahoraBtn;
  return flanco;
}

void setup() {
  Serial.begin(9600);
  pinMode(PIN_BOTON, INPUT_PULLUP);
  pinMode(PIN_CALOR, OUTPUT);
  pinMode(PIN_LISTA, OUTPUT);
  pinMode(PIN_SERVIR, OUTPUT);
  pinMode(PIN_ZUM, OUTPUT);
  digitalWrite(PIN_ZUM, LOW);
  leds(false, false, false);
  entrar(REPOSO, millis());
}

void loop() {
  unsigned long ahora = millis();
  if (pitido) {
    digitalWrite(PIN_ZUM, HIGH);
    if (ahora >= finPitido) {
      pitido = false;
      digitalWrite(PIN_ZUM, LOW);
    }
  }

  bool clic = pulsado();
  switch (estado) {
    case REPOSO:
      leds(false, false, false);
      if (clic) {
        entrar(CALENTANDO, ahora);
      }
      break;
    case CALENTANDO:
      leds(true, false, false);
      if (ahora - tFase >= T_CALENTAR) {
        entrar(LISTA, ahora);
      }
      break;
    case LISTA:
      leds(false, true, false);
      if (clic) {
        entrar(SIRVIENDO, ahora);
      }
      break;
    case SIRVIENDO:
      leds(false, false, true);
      if (ahora - tFase >= T_SERVIR) {
        entrar(REPOSO, ahora);
      }
      break;
    default:
      entrar(REPOSO, ahora);
      break;
  }
}

  1. Monta una sola placa y selecciona Arduino Uno. Conecta el pulsador entre D2 y GND.
  2. Conecta el led de calor a D3, el de lista a D4, el de servicio a D5 y el zumbador a D6, con las masas a GND.
  3. Sube el sketch y abre el serie a 9600. Debe quedar en REPOSO con los tres leds apagados.
  4. Pulsa una vez. Tiene que pasar a CALENTANDO y encender solo el led de D3 durante unos ocho segundos, mientras el serie sigue vivo.
  5. Al cumplir el tiempo suena un pitido corto y queda LISTA. Pulsa otra vez para SIRVIENDO y espera a que vuelva solo a REPOSO.
  6. Durante CALENTANDO no hace falta pulsar: la transicion la hace el tiempo. Comprueba que la placa no se queda congelada.
  7. Recorre el ciclo dos veces seguidas para ver que el enum vuelve a REPOSO sin reiniciar.

// Pines: potenciometro A0, pulsador D2, LED PWM D9
// Libreria EEPROM.h del nucleo. Direccion 0.
#include <EEPROM.h>

const int PIN_POT = A0;
const int PIN_BOTON = 2;
const int PIN_LED = 9;
const int DIR = 0;
const unsigned long VENTANA_MS = 40;

byte brilloGuardado = 0;
bool seguirPot = false;
int potAlArrancar = 0;
bool estable = HIGH;
bool previo = HIGH;
unsigned long cambioBtn = 0;

void aplicar(byte brillo) {
  analogWrite(PIN_LED, brillo);
}

bool flancoGuardar() {
  bool lectura = digitalRead(PIN_BOTON);
  unsigned long ahora = millis();
  if (lectura != estable) {
    if (ahora - cambioBtn >= VENTANA_MS) {
      estable = lectura;
    }
  } else {
    cambioBtn = ahora;
  }
  bool pulso = (previo == HIGH && estable == LOW);
  previo = estable;
  return pulso;
}

  pinMode(PIN_BOTON, INPUT_PULLUP);
  pinMode(PIN_LED, OUTPUT);

  Serial.println(brilloGuardado);
}

  byte propuesto = lectura / 4;

    aplicar(brilloGuardado);

    brilloGuardado = propuesto;
    seguirPot = false;
    potAlArrancar = lectura;
    aplicar(brilloGuardado);
    Serial.print("Guardado en EEPROM ");
    Serial.println(propuesto);
  }
}

const byte PIN_BTN[4] = {A0, A1, A2, A3};
const char *NOMBRE[4] = {"Luz 12V", "Bomba", "Ventilador", "Cerradura"};
const byte RELE_ON = LOW;
const byte RELE_OFF = HIGH;
const unsigned long VENTANA_MS = 40;

bool activo[4] = {false, false, false, false};
byte estable[4] = {HIGH, HIGH, HIGH, HIGH};
byte previo[4] = {HIGH, HIGH, HIGH, HIGH};
unsigned long cambio[4] = {0, 0, 0, 0};

LiquidCrystal lcd(12, 11, 10, 9, 8, 7);

void aplicar(byte i) {
  digitalWrite(PIN_RELE[i], activo[i] ? RELE_ON : RELE_OFF);
}

bool flanco(byte i) {
  byte lectura = digitalRead(PIN_BTN[i]);
  unsigned long ahora = millis();
  if (lectura != estable[i]) {
    if (ahora - cambio[i] >= VENTANA_MS) {
      estable[i] = lectura;
    }
  } else {
    cambio[i] = ahora;
  }
  bool pulso = (previo[i] == HIGH && estable[i] == LOW);
  previo[i] = estable[i];
  return pulso;
}

void escribirLinea(byte fila, const char *txt) {
  lcd.setCursor(0, fila);
  byte n = 0;
  while (txt[n] != 0 && n < 16) {
    lcd.print(txt[n]);
    n++;
  }
  while (n < 16) {
    lcd.print(' ');
    n++;
  }
}

void pintar(unsigned long ahora) {
  static byte cual = 0;
  static unsigned long anterior = 0;
  if (ahora - anterior >= 1500) {
    anterior = ahora;
    cual = (cual + 1) % 4;
  }
  escribirLinea(0, NOMBRE[cual]);
  escribirLinea(1, activo[cual] ? "ON  5-12 V" : "OFF 5-12 V");
}

void setup() {
  Serial.begin(9600);
  lcd.begin(16, 2);
  for (byte i = 0; i < 4; i++) {
    pinMode(PIN_RELE[i], OUTPUT);
    pinMode(PIN_BTN[i], INPUT_PULLUP);
    aplicar(i);
  }
  Serial.println("Cuatro reles. No se conmuta la red.");
  pintar(millis());
}

void loop() {
  unsigned long ahora = millis();
  for (byte i = 0; i < 4; i++) {
    if (flanco(i)) {
      activo[i] = !activo[i];
      aplicar(i);
      Serial.print(NOMBRE[i]);
      Serial.println(activo[i] ? " ON" : " OFF");
    }
  }
  pintar(ahora);
}

Pasos

  1. Monta una sola placa y selecciona Arduino Uno. Conecta los IN de los cuatro reles a D2, D3, D4 y D5, con VCC de bobina a 5 V y GND comun.
  2. Conecta los pulsadores a A0, A1, A2 y A3, cada uno con el otro extremo a GND.
  3. Conecta el LCD: RS D12, E D11, D4 D10, D5 D9, D6 D8, D7 D7 y RW a GND.
  4. Sube el sketch sin cargas en los contactos. Abre el serie a 9600 y pulsa cada boton: el nombre correcto tiene que cambiar de OFF a ON y oirse el clic.
  5. Mira el LCD: cada segundo y medio rota el nombre y el estado, siempre con el aviso 5-12 V.
  6. Solo entonces conecta en cada COM y NO una carga de 5 a 12 V con su fuente. No se conmuta la red.
  7. Recorre los cuatro nombres y comprueba que apagar en el pulsador devuelve ese rele a reposo sin tocar los otros tres.

Variantes

  • Cambia los textos de NOMBRE por los de tu maqueta, manteniendo cuatro canales y los mismos pines.
  • Fija el LCD en un solo canal, sin rotar, si prefieres ver siempre la cerradura y usar el serie para el resto.
  • Invierte RELE_ON solo en el canal cuyo modulo encienda con nivel alto, dejando el resto en nivel bajo.

Depuración

  • Si pulsas A0 y cambia otro nombre en el serie, el orden de PIN_BTN no sigue A0, A1, A2, A3.
  • Si el rele clica al reves del ON del LCD, ese modulo es activo a nivel alto: invierte sus constantes.
  • Si el LCD muestra basura, RW no esta a GND o el constructor no coincide con D12, D11, D10, D9, D8 y D7.
  • Si la carga que quieres mover es de la red electrica, no la conectes: cada canal es de 5 a 12 V y no se conmuta la red.
