Birdie · AP-BIR-01

TMP36: temperatura en el monitor serie

Objetivo

Vas a leer un TMP36 por A0 y pasar la tensión a grados Celsius con la fórmula (analogRead * 5.0 / 1023.0 - 0.5) * 100. Esa cuenta supone la referencia de 5 V de la Uno, así que no la cambies por 3,3 V. El número sale en el monitor serie a 9600 baudios y debe subir si calientas el encapsulado con el dedo.

// AP-BIR-01 TMP36 en A0. Referencia 5 V. Monitor serie 9600.
const int pinTmp = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(pinTmp);
  // (analogRead * 5.0 / 1023.0 - 0.5) * 100
  float tempC = (lectura * 5.0 / 1023.0 - 0.5) * 100.0;
  Serial.print("Temperatura C: ");
  Serial.println(tempC, 1);
  delay(500);
}

Pasos

  1. Mira el TMP36 con la cara plana hacia ti: izquierda Vs, centro Vout y derecha GND.
  2. Une Vs a 5 V y la patilla derecha al GND de la placa.
  3. Une el centro, Vout, al pin A0. Este sensor no lleva resistencia.
  4. En el IDE elige Arduino Uno, tanto si usas la R3 como el clon CH340.
  5. Carga el programa y abre el monitor serie a 9600 baudios.
  6. Anota la cifra de ambiente y apoya un dedo en el plástico, sin puentear patillas: el valor tiene que subir.

Variantes

  • Imprime también la lectura cruda de 0 a 1023 para ver la tensión antes de convertirla.
  • Haz la media de ocho lecturas seguidas si el último decimal baila demasiado.
  • Compara el número con un termómetro de ambiente y anota el desfase, sin tocar la fórmula.

Depuración

  • Patillas cambiadas: si Vs y GND van al revés el encapsulado se calienta y la cifra no tiene sentido. Corta la alimentación y revisa la cara plana.
  • Vout suelto o en otro pin analógico: A0 flota y ves números que saltan de un extremo a otro.
  • Fórmula con 3,3 V o con 1024 cuando la placa mide respecto a 5 V: el resultado queda varios grados fuera. Usa (lectura * 5.0 / 1023.0 - 0.5) * 100.
  • Monitor serie a otra velocidad, o abierto antes de cargar: salen símbolos raros o la primera línea se pierde. Déjalo en 9600 y pulsa reset.

DHT11: temperatura y humedad

Objetivo

Vas a medir temperatura y humedad con un DHT11 y la librería DHT, llamando a readTemperature y a readHumidity. El pin de datos, D2, lleva una resistencia de pull-up de 10k hacia 5 V porque el sensor suelta la línea entre bits. Las dos cifras salen por el monitor serie a 9600 baudios, con unos dos segundos entre muestras.

Código

// AP-BIR-02 DHT11 en D2 con pull-up de 10k a 5 V.
// Librería DHT: instálala en el gestor del IDE. No lleva URL.
#include <DHT.h>

const int pinDht = 2;
DHT dht(pinDht, DHT11);

void setup() {
  Serial.begin(9600);
  dht.begin();
  delay(2000);
}

void loop() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (isnan(t) || isnan(h)) {
    Serial.println("Lectura no valida: revisa DATA, la pull-up y el tipo DHT11");
  } else {
    Serial.print("Temperatura C: ");
    Serial.print(t, 1);
    Serial.print("  Humedad %: ");
    Serial.println(h, 1);
  }
  delay(2000);
}

Pasos

  1. Instala la librería DHT desde el gestor de librerías del IDE y reinicia el IDE si no aparece la cabecera.
  2. Alimenta el DHT11 entre 5 V y GND.
  3. Une DATA a D2 y coloca 10k entre DATA y 5 V. Si tu módulo ya trae esa resistencia, no añadas otra.
  4. Elige la placa Arduino Uno (R3 o CH340) y carga el programa.
  5. Abre el monitor serie a 9600 baudios y espera el primer par de segundos.
  6. Sopla suave cerca del sensor: la humedad relativa debe moverse, la temperatura casi no.

Variantes

  • Cambia el texto de salida para imprimir solo un decimal, que es la resolución real del DHT11.
  • Guarda la última humedad válida y no borres la cifra cuando una muestra falle.
  • Añade un LED en otro pin que se encienda si la humedad pasa un umbral que tú elijas.

Depuración

  • Sin pull-up de 10k a 5 V la línea de datos se queda flotando y readTemperature o readHumidity devuelven NaN.
  • Leer más rápido que cada dos segundos satura al DHT11: parece un fallo del cable y es el ritmo.
  • Constructor con DHT22 en un sensor DHT11: los números salen disparados o siempre no válidos. El segundo argumento tiene que ser DHT11.
  • DATA en un pin que no es el 2, o VCC en 3,3 V en un módulo que no regula: el programa compila igual y no mide.

Vas a medir una distancia en centímetros con el HC-SR04 sin librería. Generas un pulso corto de disparo en el trig por D9 y mides cuánto dura el eco en D8 con pulseIn. Ese tiempo se pasa a centímetros y se imprime en el monitor serie a 9600 baudios.

// AP-BIR-03 HC-SR04 sin librería. Trig en D9, echo en D8.
const int pinTrig = 9;
const int pinEcho = 8;

void setup() {
  Serial.begin(9600);
  pinMode(pinTrig, OUTPUT);
  pinMode(pinEcho, INPUT);
  digitalWrite(pinTrig, LOW);
}

void loop() {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);

  long duracion = pulseIn(pinEcho, HIGH, 30000UL);
  float cm = duracion * 0.0343 / 2.0;
  if (duracion == 0) {
    Serial.println("Sin eco: fuera de alcance o trig y echo cruzados");
  } else {
    Serial.print("Distancia cm: ");
    Serial.println(cm, 1);
  }
  delay(200);
}

Pasos

  1. Alimenta el HC-SR04 con 5 V y GND.
  2. Une trig a D9 y echo a D8. Déjalos escritos en un papel porque se cruzan con facilidad.
  3. Apunta el sensor a una pared o a un libro, no a una tela ni al aire libre de la habitación.
  4. Carga el programa en la Uno (R3 o CH340).
  5. Abre el monitor serie a 9600 baudios.
  6. Acerca y aleja el obstáculo entre unos 5 y 80 cm y comprueba que los centímetros siguen el movimiento.

Variantes

  • Imprime también la duración en microsegundos para ver el eco antes de convertir.
  • Fija un umbral y enciende el LED de la placa (D13) si el objeto está a menos de 15 cm.
  • Haz tres medidas y quédate con la mediana si una lectura suelta se dispara.

Depuración

  • Trig y echo intercambiados: pulseIn vuelve siempre con cero porque nadie escucha el pin correcto.
  • Objeto a menos de 2 o 3 cm, o demasiado lejos: el módulo no garantiza eco y verás ceros o saltos.
  • Superficie blanda o en ángulo: el ultrasonido no rebota hacia el receptor y parece que el sensor ha muerto.
  • El disparo no vuelve a nivel bajo, o pulseIn sin tope de tiempo: el programa se queda esperando y el monitor serie no avanza.

Servo que barre 0–180

Objetivo

Vas a hacer que un servo recorra de 0 a 180 grados y vuelva, sin potenciómetro. El pulso lo genera la cabecera Servo.h que ya trae el núcleo del IDE: no instales otra librería. Verás el barrido completo y el tope mecánico del engranaje, que no siempre llega al número que escribes.

Código

// AP-BIR-04 Barrido 0 a 180 con Servo.h del núcleo. Señal en D9.
#include <Servo.h>

Servo barrido;
const int pinServo = 9;

void setup() {
  barrido.attach(pinServo);
}

void loop() {
  for (int ang = 0; ang <= 180; ang += 1) {
    barrido.write(ang);
    delay(15);
  }
  for (int ang = 180; ang >= 0; ang -= 1) {
    barrido.write(ang);
    delay(15);
  }
}

Pasos

  1. Identifica los tres cables del servo: alimentación, masa y señal. En el SG90 suelen ser rojo, marrón y naranja.
  2. Une alimentación a 5 V, masa a GND y señal a D9.
  3. Deja el cuerno libre de chocar con la mesa en ambos extremos.
  4. Comprueba que el programa incluye Servo.h del núcleo, sin librerías añadidas.
  5. Carga el programa en la Uno (R3 o CH340).
  6. Observa un viaje de 0 a 180 y la vuelta. Si la placa se reinicia al arrancar, el servo pide más corriente de la que da el USB.

Variantes

  • Recorre solo de 30 a 150 grados para no forzar el tope mecánico del SG90.
  • Para dos segundos en 0, 90 y 180 y así marcas el centro.
  • Cambia el retardo de 15 ms y compara un barrido lento con uno más nervioso.

Depuración

  • Señal en un pin que no es el 9, o attach a otro número: el servo no se mueve y el programa no avisa.
  • Masa y alimentación cruzadas: el servo no gira y puede calentarse. Corta la alimentación antes de insistir.
  • El USB no aguanta el pico de corriente y la Uno se reinicia a mitad del barrido. Un servo, o 5 V externos con la masa unida.
  • Pides 0 y 180 y el brazo no llega porque el mecanismo interno ya hace tope: no es un fallo del pulso.

  • El servo tiembla en reposo por un potenciómetro ruidoso o por falta de masa común. Revisa GND antes de culpar a la librería.

// AP-BIR-06 Un dígito, cátodo común.
// Segmentos a b c d e f g en D2 D3 D4 D5 D6 D7 D8.
const uint8_t pinSeg[7] = {2, 3, 4, 5, 6, 7, 8};
const uint8_t DIGITO = 5; // cámbialo por 0..9
const uint8_t mascaraDigito[10] = {
  0b00111111, // 0
  0b00000110, // 1
  0b01011011, // 2
  0b01001111, // 3
  0b01100110, // 4
  0b01101101, // 5
  0b01111101, // 6
  0b00000111, // 7
  0b01111111, // 8
  0b01101111  // 9
};

void mostrar(uint8_t mascara) {
  for (uint8_t i = 0; i < 7; i++) {
    if (mascara & (1 << i)) {
      digitalWrite(pinSeg[i], HIGH);
    } else {
      digitalWrite(pinSeg[i], LOW);
    }
  }
}

void setup() {
  for (uint8_t i = 0; i < 7; i++) {
    pinMode(pinSeg[i], OUTPUT);
  }
  mostrar(mascaraDigito[DIGITO]);
}

void loop() {
  // El dígito se queda fijo. Cambia DIGITO y vuelve a cargar.
}

Pasos

  1. Identifica el cátodo común del display con la hoja del fabricante o el polímetro, y únelo a GND.
  2. Pon una resistencia en serie con cada segmento a, b, c, d, e, f y g.
  3. Lleva esos segmentos a D2, D3, D4, D5, D6, D7 y D8, en ese orden.
  4. Deja el punto decimal sin conectar.
  5. Carga el programa en la Uno R3 o CH340. Debe mostrarse un 5.
  6. Cambia la constante DIGITO, vuelve a cargar y comprueba que la figura coincide con el número.

Variantes

  • Muestra solo la barra g para comprobar que D8 es el segmento central y no otro.
  • Dibuja la letra A con una máscara propia, fuera de la tabla 0 a 9.
  • Si tu display es de ánodo común, invierte HIGH y LOW y pasa el común a 5 V.

Depuración

  • Cátodo común llevado a 5 V, o display de ánodo común tratado como cátodo: no luce, o lucen los segmentos contrarios.
  • Segmento sin resistencia: ese trazo se ve más fuerte y puedes dañar el LED o el pin. Para y pon la resistencia.
  • El orden a-g no sigue D2 a D8: el número parece roto aunque la máscara sea la de un 5.
  • Un pin sin pinMode OUTPUT se queda en entrada y ese segmento nunca enciende.

Contador 0–9 en 7 segmentos

Objetivo

Vas a contar de 0 a 9 en el display de 7 segmentos de cátodo común, con los mismos pines D2 a D8 de la práctica del dígito fijo. El cambio de cifra lo marca millis, así el programa sigue libre para otra tarea y no se queda dormido en un retardo. Al pasar de 9 la cuenta vuelve a 0.

// AP-BIR-07 Contador 0 a 9. Cátodo común. Segmentos en D2..D8.
// El ritmo lo lleva millis, no un delay que bloquee el bucle.
const uint8_t pinSeg[7] = {2, 3, 4, 5, 6, 7, 8};
const uint8_t mascaraDigito[10] = {
  0b00111111, 0b00000110, 0b01011011, 0b01001111, 0b01100110,
  0b01101101, 0b01111101, 0b00000111, 0b01111111, 0b01101111
};
const unsigned long intervalo = 700;
unsigned long marca = 0;
uint8_t n = 0;

void mostrar(uint8_t mascara) {
  for (uint8_t i = 0; i < 7; i++) {
    digitalWrite(pinSeg[i], (mascara & (1 << i)) ? HIGH : LOW);
  }
}

void setup() {
  for (uint8_t i = 0; i < 7; i++) {
    pinMode(pinSeg[i], OUTPUT);
  }
  mostrar(mascaraDigito[0]);
  marca = millis();
}

void loop() {
  unsigned long ahora = millis();
  if (ahora - marca >= intervalo) {
    marca = ahora;
    n++;
    if (n > 9) {
      n = 0;
    }
    mostrar(mascaraDigito[n]);
  }
}

Pasos

  1. Reutiliza el cableado del dígito fijo: cátodo común a GND y segmentos a D2-D8 con resistencia.
  2. Revisa que el orden sigue siendo a, b, c, d, e, f, g.
  3. Carga el programa en la Uno R3 o CH340.
  4. Comprueba que arranca en 0 y que cada cifra dura algo menos de un segundo.
  5. Sigue la serie hasta el 9 y confirma que vuelve a 0, no a un segmento suelto.
  6. Cambia la constante intervalo, carga de nuevo y mira si el ritmo sigue a millis.

Variantes

  • Cuenta hacia atrás desde 9 hasta 0 cambiando el sentido de n.
  • Alarga el intervalo a dos segundos para dictar las cifras en voz alta mientras avanzan.
  • Enciende el punto decimal en los números pares con un octavo pin y su resistencia.

Depuración

  • Usas delay largo además de millis y el periodo se alarga el doble: deja un solo reloj.
  • La máscara del 1 o del 4 no coincide con tu orden de pines y esas cifras salen irreconocibles.
  • Olvidas poner n a 0 al pasar de 9 y el índice se sale de la tabla: segmentos caóticos, no un dígito.
  • Ánodo común con niveles pensados para cátodo: parece que cuenta, pero las cifras son el negativo de las buenas.

// AP-BIR-16 Relé en D8. Solo conmuta 5 a 12 V.
// No se toca la red de casa. Carga de prueba: LED con resistencia en NO.
// Módulo típico activo a nivel bajo: HIGH = suelto, LOW = armado.
const int pinRele = 8;

void setup() {
  pinMode(pinRele, OUTPUT);
  digitalWrite(pinRele, HIGH);
}

void loop() {
  digitalWrite(pinRele, LOW);
  delay(1000);
  digitalWrite(pinRele, HIGH);
  delay(1000);
}

  • VCC del módulo suelto o el puente de la bobina quitado: el pin cambia y no oyes nada. La bobina también necesita 5 V y masa.

// AP-BIR-17 RGB cátodo común. PWM en D3 rojo, D5 verde, D6 azul.
const int pinR = 3;
const int pinG = 5;
const int pinB = 6;

void color(int r, int g, int b) {
  analogWrite(pinR, r);
  analogWrite(pinG, g);
  analogWrite(pinB, b);
}

void setup() {
  pinMode(pinR, OUTPUT);
  pinMode(pinG, OUTPUT);
  pinMode(pinB, OUTPUT);
  color(0, 0, 0);
}

void loop() {
  color(255, 0, 0);
  delay(600);
  color(0, 255, 0);
  delay(600);

  delay(600);

  delay(600);
  color(0, 0, 0);
  delay(400);

Depuración

  • Ánodo común cableado como cátodo: no luce, o lo hace muy débil. La patilla común de esta práctica va a GND.
  • Un canal sin resistencia se come el color y puede dañar el LED o el pin. Para y pon las tres.

  • D3, D5 o D6 intercambiados: el ciclo no sigue rojo-verde-azul. El programa no adivina el color de cada patilla.

// AP-BIR-18 Joystick: VRx A0, VRy A1, SW D2 con INPUT_PULLUP.
const int pinX = A0;
const int pinY = A1;
const int pinSw = 2;

void setup() {
  pinMode(pinSw, INPUT_PULLUP);
  Serial.begin(9600);
}

void loop() {
  int x = analogRead(pinX);
  int y = analogRead(pinY);
  int sw = digitalRead(pinSw);
  Serial.print("X=");
  Serial.print(x);
  Serial.print(" Y=");
  Serial.print(y);
  Serial.print(" SW=");
  Serial.println(sw == LOW ? "pulsado" : "suelto");
  delay(150);
}

  5. Empuja a los lados y luego arriba y abajo, y anota qué eje se mueve cada vez.

  • Monitor serie a otra velocidad, o un eje leído en otro pin: números quietos o caracteres rotos. Este programa usa A0, A1 y 9600.

// AP-BIR-20 Una línea por muestra: millis, TMP36 en A0, potenciómetro en A1.
// Monitor serie a 9600. Separador ';' para copiar la columna.
const int pinTmp = A0;
const int pinPot = A1;
unsigned long ultima = 0;

void setup() {
  Serial.begin(9600);
  Serial.println("ms;tempC;pot");
}

void loop() {
  unsigned long ahora = millis();
  if (ahora - ultima >= 500) {
    ultima = ahora;
    int cruda = analogRead(pinTmp);
    float tempC = (cruda * 5.0 / 1023.0 - 0.5) * 100.0;
    int pot = analogRead(pinPot);
    Serial.print(ahora);
    Serial.print(';');
    Serial.print(tempC, 1);
    Serial.print(';');
    Serial.println(pot);
  }
}

Pasos

  1. Cablea el TMP36: Vs a 5 V, GND a masa, Vout a A0.
  2. Cablea el potenciómetro: extremos a 5 V y GND, cursor a A1, no a A0.
  3. Carga el programa en la Uno R3 o CH340.
  4. Abre el monitor serie a 9600 baudios y espera la cabecera ms;tempC;pot.
  5. Comprueba que cada muestra ocupa una sola línea, con dos separadores.
  6. Gira el potenciómetro y calienta el TMP36: solo debe cambiar su campo, sin partir la línea.

Variantes

  • Acorta el periodo a 200 ms o alárgalo a 2 s cambiando la comparación con millis.
  • Añade un cuarto campo con la lectura cruda del TMP36, sin dejar de cerrar la muestra con println.
  • Sustituye el punto decimal por una coma solo en el texto, si tu hoja de cálculo es de España.

  • Usas println en cada campo: una muestra queda en varias líneas y ya no puedes seguir una fila. Solo el último print cierra la línea.

  • Fórmula distinta de (lectura * 5.0 / 1023.0 - 0.5) * 100: la columna de temperatura no coincide con la práctica del TMP36.
  • Monitor serie a otra velocidad, o la resta de millis hecha con enteros con signo: líneas ilegibles o un periodo que se estira.
