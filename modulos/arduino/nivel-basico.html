Parpadeo de un LED

Objetivo

El LED externo de D2 queda parpadeando solo, medio segundo encendido y medio segundo apagado, con una resistencia de 220 Ω en serie. Este es el único montaje del bloque que usa delay a propósito: cada espera detiene el programa por completo y no puede atender otra cosa mientras tanto. Cuando lo cargas, el parpadeo sigue sin que pulses nada.

Código

// Cableado: D2 LED, GND, 5V.
// Parpadeo con delay. El programa se queda parado
// 500 ms encendido y 500 ms apagado. No usa millis.
// Resistencia de 220 ohmios en serie con el anodo.
const int pinLed = 2;

void setup() {
  pinMode(pinLed, OUTPUT);
}

void loop() {
  digitalWrite(pinLed, HIGH);
  delay(500);
  digitalWrite(pinLed, LOW);
  delay(500);
}

Pasos

  1. Clava la Uno en la protoboard o deja la placa al lado y lleva los hilos hasta ella.
  2. Pon el LED rojo con el ánodo hacia la resistencia y el cátodo, la pata corta, hacia el carril azul de GND.
  3. Coloca la resistencia de 220 Ω entre el pin D2 y el ánodo del LED.
  4. Une el cátodo al carril GND y ese carril al pin GND de la placa.
  5. El carril rojo puede ir a 5 V, pero no lo conectes al LED: la corriente tiene que entrar por D2.
  6. Carga el sketch, espera el reinicio y comprueba que el LED cambia de estado cada medio segundo sin pulsar nada.

Variantes

  • Cambia los dos delay a 200 y a 800 para un destello corto y una pausa larga.
  • Sustituye el LED rojo por uno verde y deja la misma resistencia de 220 Ω.
  • Mueve el LED a D4 y cambia el número del pin en el sketch para que coincida.

Depuración

  • Si el LED no enciende, el cátodo no está en el carril GND o ese carril no llega al pin GND.
  • Sin la resistencia de 220 Ω el LED se fuerza y el pin D2 puede dañarse: no la quites.
  • Si el LED está al revés, con el cátodo hacia D2, no luce aunque el sketch sea correcto.
  • Si escribiste el pin 13 en el sketch y el cable está en D2, parpadea el testigo de la placa y no tu LED.

// Cableado: D2 LED, D7 pulsador, GND, 5V.
// LED encendido solo mientras D7 esta a GND.
// La muestra se toma cada 20 ms con millis.
const int pinLed = 2;
const int pinBtn = 7;
unsigned long marca = 0;

void setup() {
  pinMode(pinLed, OUTPUT);
  pinMode(pinBtn, INPUT_PULLUP);
  digitalWrite(pinLed, LOW);
}

void loop() {
  unsigned long ahora = millis();
  if (ahora - marca >= 20) {
    marca = ahora;
    if (digitalRead(pinBtn) == LOW) {
      digitalWrite(pinLed, HIGH);
    } else {
      digitalWrite(pinLed, LOW);
    }
  }
}

Pasos

  1. Monta el LED rojo en D2 con la resistencia de 220 Ω en serie y el cátodo al carril GND.
  2. Conecta un terminal del pulsador a D7 y el otro terminal al mismo carril GND.
  3. No pongas resistencia en el pulsador: el sketch activa INPUT_PULLUP en D7.
  4. Deja el carril de 5 V unido a la placa, pero no lo uses en el botón.
  5. Carga el sketch y mantén el pulsador: el LED debe quedarse encendido solo durante la pulsación.
  6. Suelta el botón y comprueba que el LED se apaga al momento, sin quedarse enganchado.

Variantes

  • Invierte la lógica para que el LED esté encendido en reposo y se apague al pulsar.
  • Pasa el pulsador a D8 y el LED a D4, y cambia esos dos números en el sketch.
  • Añade un segundo LED en D3 que haga siempre lo contrario que el de D2.

Depuración

  • Si el LED no responde, el cátodo o el pulsador se han quedado sin el hilo de GND.
  • Si falta la resistencia de 220 Ω, el LED luce demasiado y el pin sufre.
  • Con pinMode INPUT, sin INPUT_PULLUP, D7 flota y el LED parpadea aunque no pulses.
  • Si el pulsador va a 5 V en vez de a GND, INPUT_PULLUP lo deja siempre en alto y el LED no se enciende.

Semáforo de tres luces

Objetivo

El semáforo de coches queda ciclando solo: verde en D4, ámbar en D3, rojo en D2 y un tramo con rojo y ámbar a la vez antes de volver al verde. Cada fase dura un tiempo medido con millis, así el programa no se bloquea entre un color y el siguiente. No hay pulsador: al cargar el sketch la secuencia empieza en verde y se repite.

Cableado

Código

// Cableado: D2 LED, D3 LED, D4 LED, GND, 5V.
// Rojo D2, ambar D3, verde D4.
// Fase 0 verde 5 s, fase 1 ambar 1,5 s,
// fase 2 rojo 5 s, fase 3 rojo y ambar 2 s.
const unsigned long tiempos[4] = {5000, 1500, 5000, 2000};
int fase = 0;
unsigned long marca = 0;

void luces(int f) {
  digitalWrite(2, (f == 2 || f == 3) ? HIGH : LOW);
  digitalWrite(3, (f == 1 || f == 3) ? HIGH : LOW);
  digitalWrite(4, (f == 0) ? HIGH : LOW);
}

void setup() {
  pinMode(2, OUTPUT);
  pinMode(3, OUTPUT);
  pinMode(4, OUTPUT);
  luces(0);
  marca = millis();
}

void loop() {
  unsigned long ahora = millis();
  if (ahora - marca >= tiempos[fase]) {
    marca = ahora;
    fase = (fase + 1) % 4;
    luces(fase);
  }
}

Pasos

  1. Coloca el LED rojo en D2, el ámbar en D3 y el verde en D4.
  2. Pon una resistencia de 220 Ω en serie con cada ánodo, antes del LED.
  3. Lleva los tres cátodos al carril GND y ese carril al pin GND.
  4. No juntes los ánodos entre sí: cada color tiene su pin.
  5. Carga el sketch y mira el verde: debe aguantar unos cinco segundos.
  6. Después verás ámbar solo, luego rojo solo, y luego rojo con ámbar antes de repetir el verde.
  7. Si un color no aparece, cambia solo ese LED de pata: el cátodo es el que va a GND.

Variantes

  • Alarga el verde a ocho segundos cambiando el primer valor del array de tiempos.
  • Quita la fase de rojo con ámbar y deja solo verde, ámbar y rojo.
  • Haz que el ámbar parpadee tres veces antes del rojo, contando esos destellos con millis.

Depuración

  • Si los tres LED quedan apagados, el carril de cátodos no llega a GND.
  • Si falta una resistencia de 220 Ω, ese color luce de más o el pin se calienta.
  • Si rojo y verde están cruzados, la secuencia parece invertida: rojo es D2 y verde es D4.
  • Si cambias un tiempo con una espera bloqueante, el ciclo se vuelve torpe y no puedes añadir luego un pulsador.

Antirrebote de un pulsador

Objetivo

Cada pulsación limpia en D7 cambia el LED de D2: una vez lo enciende y la siguiente lo apaga. El antirrebote espera 30 ms con millis antes de aceptar el cambio, así un solo clic no cuenta como varios. El pulsador va a GND con INPUT_PULLUP y solo se mira el flanco de bajada, no el tiempo que lo dejes hundido.

// Cableado: D2 LED, D7 pulsador, GND, 5V.
// Antirrebote de 30 ms. Cada flanco a LOW conmuta el LED.
const int pinLed = 2;
const int pinBtn = 7;
bool estable = true;
bool ultimo = true;
bool ledOn = false;
unsigned long marcaBtn = 0;

void setup() {
  pinMode(pinLed, OUTPUT);
  pinMode(pinBtn, INPUT_PULLUP);
  digitalWrite(pinLed, LOW);
}

void loop() {
  unsigned long ahora = millis();
  bool lectura = digitalRead(pinBtn);
  if (lectura != ultimo) {
    ultimo = lectura;
    marcaBtn = ahora;
  }
  if (ahora - marcaBtn >= 30 && lectura != estable) {
    estable = lectura;
    if (estable == LOW) {
      ledOn = !ledOn;
      digitalWrite(pinLed, ledOn ? HIGH : LOW);
    }
  }
}

Pasos

  1. Monta el LED verde en D2 con 220 Ω y el cátodo a GND.
  2. Une un terminal del pulsador a D7 y el otro a GND.
  3. Confirma en el sketch que D7 está en INPUT_PULLUP, no en INPUT.
  4. Carga el programa y da un clic corto: el LED debe cambiar una sola vez.
  5. Mantén el botón hundido un segundo y comprueba que no sigue conmutando.
  6. Suelta y vuelve a pulsar: el segundo clic devuelve el LED al estado anterior.
  7. Si al pulsar una vez el LED titila varias veces, sube la espera de 30 ms a 50 ms.

Variantes

  • Haz que solo cuente el flanco de subida, al soltar, en lugar del flanco al pulsar.
  • Añade otro LED en D3 que quede siempre al revés que el de D2.
  • Tras cinco conmutaciones, deja el LED fijo encendido hasta un reinicio.

Depuración

  • Sin el hilo de GND del pulsador, D7 nunca baja y el LED no cambia.
  • Si omites la resistencia de 220 Ω del LED, el brillo es excesivo y el pin queda desprotegido.
  • Si usas INPUT en vez de INPUT_PULLUP, el pin flota y una sola pulsación parece un tren de clics.
  • Si el botón va a 5 V, el pull-up interno no ve la bajada y el antirrebote no tiene flanco que contar.

Dos pulsadores, un LED

Objetivo

// Cableado: D2 LED, D7 pulsador, D8 pulsador, GND, 5V.
// D7 enciende, D8 apaga. Antirrebote de 30 ms en cada uno.
const int pinLed = 2;
const int pinOn = 7;
const int pinOff = 8;
bool estOn = true;
bool ultOn = true;
bool estOff = true;
bool ultOff = true;
unsigned long marcaOn = 0;
unsigned long marcaOff = 0;
bool ledOn = false;

void setup() {
  pinMode(pinLed, OUTPUT);
  pinMode(pinOn, INPUT_PULLUP);
  pinMode(pinOff, INPUT_PULLUP);
  digitalWrite(pinLed, LOW);
}

void loop() {
  unsigned long ahora = millis();
  bool lecOn = digitalRead(pinOn);
  bool lecOff = digitalRead(pinOff);
  bool flancoOn = false;
  bool flancoOff = false;

  if (lecOn != ultOn) {
    ultOn = lecOn;
    marcaOn = ahora;
  }
  if (ahora - marcaOn >= 30 && lecOn != estOn) {
    estOn = lecOn;
    if (estOn == LOW) flancoOn = true;
  }

  if (lecOff != ultOff) {
    ultOff = lecOff;
    marcaOff = ahora;
  }
  if (ahora - marcaOff >= 30 && lecOff != estOff) {
    estOff = lecOff;
    if (estOff == LOW) flancoOff = true;
  }

  if (flancoOff) ledOn = false;
  else if (flancoOn) ledOn = true;
  digitalWrite(pinLed, ledOn ? HIGH : LOW);
}

Pasos

  1. Monta el LED en D2 con su resistencia de 220 Ω y el cátodo a GND.
  2. Conecta el primer pulsador entre D7 y GND: será el de encender.
  3. Conecta el segundo pulsador entre D8 y GND: será el de apagar.
  4. Carga el sketch y pulsa D7: el LED se enciende y se queda así al soltar.
  5. Pulsa D8: el LED se apaga y no vuelve hasta un nuevo clic en D7.
  6. Mantén D7 hundido y comprueba que no parpadea: solo cuenta el flanco.
  7. Pulsa los dos a la vez: debe imponerse el de apagar.

Variantes

  • Cambia el papel de los pines para que D8 encienda y D7 apague.
  • Haz que D8, en vez de apagar, conmute el LED como un tercer modo.
  • Añade un LED en D3 que indique cuál fue el último pulsador usado.

Depuración

  • Si ningún botón responde, el carril GND no está unido al pin GND de la placa.
  • Sin la resistencia de 220 Ω el LED queda sin límite de corriente.
  • Si uno de los pines está en INPUT y no en INPUT_PULLUP, ese botón parece pulsarse solo.
  • Si cruzas los hilos y D7 va al botón de apagar, la leyenda física no coincide con lo que hace el LED.

// Cableado: D2 LED, D3 LED, D4 LED, D5 LED, GND, 5V.
// Un solo LED encendido. Rebote en los extremos cada 200 ms.
const int leds[4] = {2, 3, 4, 5};
int indice = 0;
int paso = 1;
unsigned long marca = 0;

void setup() {
  for (int i = 0; i < 4; i++) {
    pinMode(leds[i], OUTPUT);
    digitalWrite(leds[i], LOW);
  }
  digitalWrite(leds[0], HIGH);
  marca = millis();
}

void loop() {
  unsigned long ahora = millis();
  if (ahora - marca >= 200) {
    marca = ahora;
    digitalWrite(leds[indice], LOW);
    indice += paso;
    if (indice == 0 || indice == 3) {
      paso = -paso;
    }
    digitalWrite(leds[indice], HIGH);
  }
}

  • Si el recorrido salta un hueco, ese pin está cableado en otro LED.
  • Si usas D7 para un LED de esta fila, pierdes un pin pensado para pulsadores y el orden del sketch deja de coincidir.

// Cableado: D2 LED, D3 LED, D4 LED, D5 LED, D6 LED, D11 LED, D7 pulsador, GND, 5V.
// El numero de LED encendidos es la tirada. Monitor a 9600.
const int leds[6] = {2, 3, 4, 5, 6, 11};
const int pinBtn = 7;
int estado = 0;
unsigned long inicio = 0;
unsigned long marcoPaso = 0;
unsigned long marcaBtn = 0;
bool estable = true;
bool ultimo = true;

void mostrar(int n) {
  for (int i = 0; i < 6; i++) {
    digitalWrite(leds[i], i < n ? HIGH : LOW);
  }
}

bool flanco(unsigned long ahora) {
  bool lectura = digitalRead(pinBtn);
  if (lectura != ultimo) {
    ultimo = lectura;
    marcaBtn = ahora;
  }
  if (ahora - marcaBtn >= 30 && lectura != estable) {
    estable = lectura;
    if (estable == LOW) return true;
  }
  return false;
}

void setup() {
  for (int i = 0; i < 6; i++) pinMode(leds[i], OUTPUT);
  pinMode(pinBtn, INPUT_PULLUP);
  Serial.begin(9600);
  randomSeed(millis());
  mostrar(0);
  Serial.println("Pulsa para tirar. Se encienden tantas luces como el valor.");
}

void loop() {
  unsigned long ahora = millis();
  bool pulsado = flanco(ahora);
  if (estado == 0 && pulsado) {
    estado = 1;
    inicio = ahora;

El semáforo de coches espera en verde, en D4, hasta que pides paso con el pulsador de D7. Entonces pasa a ámbar en D3, luego a rojo en D2 durante cinco segundos para cruzar, y vuelve al verde. Los tiempos los lleva millis y el botón tiene antirrebote, así que una sola petición basta aunque lo pulses durante el rojo. Rojo, ámbar y verde están en D2, D3 y D4.

// Cableado: D2 LED, D3 LED, D4 LED, D7 pulsador, GND, 5V.
// Rojo D2, ambar D3, verde D4, peaton en D7 a GND.
// Verde en reposo. Tras la peticion: ambar 2 s y rojo 5 s.
const int pinRojo = 2;
const int pinAmbar = 3;
const int pinVerde = 4;
const int pinPeaton = 7;
int fase = 0;
bool peticion = false;
bool estable = true;
bool ultimo = true;
unsigned long marca = 0;
unsigned long marcaBtn = 0;

void poner(int f) {
  digitalWrite(pinRojo, f == 2 ? HIGH : LOW);
  digitalWrite(pinAmbar, f == 1 ? HIGH : LOW);
  digitalWrite(pinVerde, f == 0 ? HIGH : LOW);
}

void setup() {
  pinMode(pinRojo, OUTPUT);
  pinMode(pinAmbar, OUTPUT);
  pinMode(pinVerde, OUTPUT);
  pinMode(pinPeaton, INPUT_PULLUP);
  poner(0);
  marca = millis();
}

void loop() {
  unsigned long ahora = millis();
  bool lectura = digitalRead(pinPeaton);
  if (lectura != ultimo) {
    ultimo = lectura;
    marcaBtn = ahora;
  }
  if (ahora - marcaBtn >= 30 && lectura != estable) {
    estable = lectura;
    if (estable == LOW) peticion = true;
  }

  if (fase == 0 && peticion && ahora - marca >= 3000) {
    fase = 1;
    marca = ahora;
    poner(fase);
  } else if (fase == 1 && ahora - marca >= 2000) {
    fase = 2;
    marca = ahora;
    peticion = false;
    poner(fase);
  } else if (fase == 2 && ahora - marca >= 5000) {
    fase = 0;
    marca = ahora;
    poner(fase);
  }
}

Pasos

  1. Monta rojo en D2, ámbar en D3 y verde en D4, cada uno con 220 Ω al ánodo.
  2. Une los cátodos y un terminal del pulsador de peatón al carril GND.
  3. Lleva el otro terminal del pulsador a D7.
  4. Carga el sketch: debe quedarse en verde, sin cambiar solo.
  5. Pulsa una vez. Si el verde lleva menos de tres segundos, espera ese mínimo y verás el ámbar.
  6. El ámbar dura dos segundos y después se queda el rojo unos cinco segundos: ese es el cruce.
  7. Al volver el verde, pulsa durante el rojo de una segunda prueba y comprueba que la petición se guarda.

Variantes

  • Acorta el rojo de cruce a tres segundos en una calle poco ancha.
  • Haz parpadear el ámbar durante su fase en vez de dejarlo fijo.
  • Añade un LED blanco en D5 que se encienda solo durante el rojo de los coches.

Depuración

  • Si nunca sale del verde, el pulsador no baja a GND o D7 no usa INPUT_PULLUP.
  • Si falta la resistencia de un color, esa luz queda desprotegida o no se distingue.
  • Si rojo y verde están cruzados, el cruce ocurre con el verde encendido: D2 es el rojo.
  • Si el cátodo común no llega a GND, las tres luces parecen apagadas aunque la petición se acepte.

// Cableado: D2 LED, D7 pulsador, GND, 5V.
// Espera aleatoria, luego cronometro hasta el clic.
// Anticiparse anula la ronda. Monitor a 9600.
const int pinLed = 2;
const int pinBtn = 7;
unsigned long marca = 0;
unsigned long inicio = 0;
unsigned long espera = 2000;
int estado = 0;
bool estable = true;
bool ultimo = true;
unsigned long marcaBtn = 0;

bool flanco(unsigned long ahora) {
  bool lectura = digitalRead(pinBtn);
  if (lectura != ultimo) {
    ultimo = lectura;
    marcaBtn = ahora;
  }
  if (ahora - marcaBtn >= 30 && lectura != estable) {
    estable = lectura;
    if (estable == LOW) return true;
  }
  return false;
}

void setup() {
  pinMode(pinLed, OUTPUT);
  pinMode(pinBtn, INPUT_PULLUP);
  Serial.begin(9600);
  randomSeed(millis());
  Serial.println("Pulsa solo cuando el LED se encienda.");
  marca = millis();
}

void loop() {
  unsigned long ahora = millis();
  bool pulsado = flanco(ahora);

  if (estado == 0) {
    digitalWrite(pinLed, LOW);
    if (ahora - marca >= 1200) {
      espera = (unsigned long)random(1500, 4000);
      marca = ahora;
      estado = 1;
      Serial.println("Espera el LED...");
    }
  } else if (estado == 1) {
    if (pulsado) {
      Serial.println("Demasiado pronto. Nueva ronda.");
      marca = ahora;
      estado = 0;
    } else if (ahora - marca >= espera) {
      digitalWrite(pinLed, HIGH);
      inicio = ahora;
      estado = 2;
    }
  } else if (estado == 2) {
    if (pulsado) {
      unsigned long reaccion = ahora - inicio;
      digitalWrite(pinLed, LOW);
      Serial.print("Reflejo: ");
      Serial.print(reaccion);
      Serial.println(" ms");
      marca = ahora;
      estado = 3;
    } else if (ahora - inicio >= 3000) {
      digitalWrite(pinLed, LOW);
      Serial.println("Tiempo agotado.");
      marca = ahora;
      estado = 3;
    }
  } else if (estado == 3 && ahora - marca >= 1800) {
    marca = ahora;
    estado = 0;
  }
}

  1. Monta el LED en D2 con 220 Ω y el cátodo a GND.
  2. Conecta el pulsador entre D7 y GND.
  3. Abre el monitor serie a 9600 baudios y lee la frase de inicio.
  4. No pulses durante el mensaje Espera el LED: si lo haces, la ronda se anula.
  5. Cuando el LED se encienda, pulsa lo antes que puedas.
  6. Lee la línea Reflejo y los milisegundos. Luego espera la siguiente ronda, que llega sola.
  7. Prueba a dejar pasar el LED: a los tres segundos debe decir que el tiempo se agotó.

Variantes

  • Estrecha la espera aleatoria entre 800 ms y 1500 ms para un juego más nervioso.
  • Guarda el mejor tiempo y escríbelo solo cuando lo superes.
  • Añade un segundo LED en D3 que se encienda si te anticipas.

Depuración

  • Si siempre dice que te anticipas, D7 flota porque falta INPUT_PULLUP o el hilo de GND.
  • Sin la resistencia de 220 Ω el estímulo luminoso fuerza el pin D2.
  • Con el monitor fuera de 9600 baudios no lees el tiempo, solo caracteres rotos.
  • Si el cátodo del LED no va a GND, el cronómetro corre pero no ves cuándo empezar.

// Cableado: D2 LED, D3 LED, D4 LED, D7 pulsador, D8 pulsador, D9 pulsador, D10 zumbador, GND, 5V.
// Simon de tres colores. Monitor a 9600. Antirrebote 30 ms.
const int leds[3] = {2, 3, 4};
const int btns[3] = {7, 8, 9};
const int zumb = 10;
const int TOPE = 6;
int secuencia[6];
int ronda = 1;
int iPlay = 0;
int iJug = 0;
int estado = 0;
unsigned long marca = 0;
bool estable[3] = {true, true, true};
bool ultimo[3] = {true, true, true};
unsigned long marcaBtn[3] = {0, 0, 0};

void apagar() {
  digitalWrite(2, LOW);
  digitalWrite(3, LOW);
  digitalWrite(4, LOW);
}

void colorOn(int c) {
  apagar();
  digitalWrite(leds[c], HIGH);
}

int flanco(unsigned long ahora) {
  int cual = -1;
  for (int i = 0; i < 3; i++) {
    bool lectura = digitalRead(btns[i]);
    if (lectura != ultimo[i]) {
      ultimo[i] = lectura;
      marcaBtn[i] = ahora;
    }
    if (ahora - marcaBtn[i] >= 30 && lectura != estable[i]) {
      estable[i] = lectura;
      if (estable[i] == LOW && cual < 0) cual = i;
    }
  }
  return cual;
}

void nuevaPartida() {
  ronda = 1;
  secuencia[0] = random(0, 3);
  iPlay = 0;
  iJug = 0;
  estado = 0;
  apagar();
  noTone(zumb);
  marca = millis();
}

void setup() {
  for (int i = 0; i < 3; i++) {
    pinMode(leds[i], OUTPUT);
    pinMode(btns[i], INPUT_PULLUP);
  }
  pinMode(zumb, OUTPUT);
  Serial.begin(9600);
  randomSeed(millis());
  Serial.println("Repite la secuencia. D7 rojo, D8 ambar, D9 verde.");
  nuevaPartida();
}

void loop() {
  unsigned long ahora = millis();
  int pulsado = flanco(ahora);

  if (estado == 0) {
    if (ahora - marca >= 280) {
      colorOn(secuencia[iPlay]);
      tone(zumb, 420 + secuencia[iPlay] * 180, 160);
      marca = ahora;
      estado = 1;
    }
  } else if (estado == 1) {
    if (ahora - marca >= 420) {
      apagar();
      noTone(zumb);
      iPlay++;
      marca = ahora;
      if (iPlay >= ronda) {
        iPlay = 0;
        iJug = 0;
        estado = 2;
        Serial.println("Te toca.");
      } else {
        estado = 0;
      }
    }
  } else if (estado == 2) {
    if (pulsado >= 0) {
      colorOn(pulsado);
      marca = ahora;
      if (pulsado == secuencia[iJug]) {
        tone(zumb, 520 + pulsado * 160, 120);
        iJug++;
        estado = 4;
      } else {
        tone(zumb, 180, 400);
        Serial.println("Fallo. Empezamos de nuevo.");
        estado = 3;
      }
    } else if (ahora - marca >= 8000) {
      Serial.println("Tiempo agotado.");
      marca = ahora;
      estado = 3;
    }
  } else if (estado == 4) {
    if (ahora - marca >= 220) {
      apagar();
      noTone(zumb);
      if (iJug >= ronda) {
        Serial.println("Ronda correcta.");
        if (ronda < TOPE) {
          secuencia[ronda] = random(0, 3);
          ronda++;
        } else {
          Serial.println("Has llegado a seis. Nueva partida.");
          ronda = 1;
          secuencia[0] = random(0, 3);
        }
        iPlay = 0;
        estado = 5;
      } else {
        estado = 2;
      }
      marca = ahora;
    }
  } else if (estado == 5) {
    if (ahora - marca >= 600) {
      estado = 0;
      marca = ahora;
    }
  } else if (estado == 3) {
    if (((ahora / 150) % 2) == 0) {
      digitalWrite(2, HIGH);
      digitalWrite(3, HIGH);
      digitalWrite(4, HIGH);
    } else {
      apagar();
    }
    if (ahora - marca >= 1200) {
      nuevaPartida();
    }
  }
}

  1. Monta el LED rojo en D2, el ámbar en D3 y el verde en D4, cada uno con 220 Ω.
  2. Pon el pulsador de D7 junto al rojo, el de D8 junto al ámbar y el de D9 junto al verde, todos a GND.
  3. Conecta el zumbador pasivo entre D10 y GND.
  4. Abre el monitor serie a 9600 baudios y espera a que suene y se encienda el primer color.
  5. Cuando leas Te toca, pulsa el botón de ese mismo color.
  6. Si aciertas, la siguiente vuelta añade un color más al final de la serie.
  7. Si fallas, los tres LED parpadean juntos y la partida vuelve a un solo paso.

Variantes

  • Quita el zumbador y deja solo las luces si quieres jugar en silencio.
  • Acorta la pausa entre colores para una reproducción más rápida.
  • Añade un cuarto color más adelante en D5 y D6 cuando domines los tres.

Depuración

  • Si un color no suena ni se pulsa, ese pulsador no está a GND o no usa INPUT_PULLUP.
  • Si falta la resistencia de 220 Ω de un LED, ese color queda más brillante y desprotegido.
  • Un zumbador activo no sigue la nota de tone: tiene que ser el pasivo, con una pata a GND.
  • Con el monitor fuera de 9600 baudios no ves el aviso Te toca y juegas a ciegas.

// Cableado: D3 LED, A0 LDR, 5V, GND.
// LDR a 5V, 10 kiloohmios a GND. Mucha luz = lectura alta = LED apagado.
// Brillo PWM en D3. Monitor a 9600. Muestra cada 80 ms.
const int pinLed = 3;
const int pinLuz = A0;
unsigned long marca = 0;

void setup() {
  pinMode(pinLed, OUTPUT);
  Serial.begin(9600);
  analogWrite(pinLed, 0);
  Serial.println("Luz nocturna. Tapa la LDR para subir el brillo.");
}

void loop() {
  unsigned long ahora = millis();
  if (ahora - marca >= 80) {
    marca = ahora;
    int lectura = analogRead(pinLuz);
    int brillo = 0;
    if (lectura < 800) {
      brillo = map(lectura, 800, 150, 0, 255);
      brillo = constrain(brillo, 0, 255);
    }
    analogWrite(pinLed, brillo);
    Serial.println(lectura);
  }
}

  • Si cruzas la LDR y la resistencia, la noche apaga el LED en vez de encenderlo.
  • Un monitor que no esté a 9600 baudios no te deja calibrar el 800 con números legibles.

// Cableado: D2 LED, D3 LED, D7 pulsador, GND, 5V.
// Un clic arranca el alternado cada 350 ms. Otro clic lo para.
// Antirrebote de 30 ms con millis.
const int pinA = 2;
const int pinB = 3;
const int pinBtn = 7;
bool activo = false;
bool lado = false;
bool estable = true;
bool ultimo = true;
unsigned long marcaBtn = 0;
unsigned long marca = 0;

void setup() {
  pinMode(pinA, OUTPUT);
  pinMode(pinB, OUTPUT);
  pinMode(pinBtn, INPUT_PULLUP);
  digitalWrite(pinA, LOW);
  digitalWrite(pinB, LOW);
}

void loop() {
  unsigned long ahora = millis();
  bool lectura = digitalRead(pinBtn);
  if (lectura != ultimo) {
    ultimo = lectura;
    marcaBtn = ahora;
  }
  if (ahora - marcaBtn >= 30 && lectura != estable) {
    estable = lectura;
    if (estable == LOW) {
      activo = !activo;
      if (!activo) {
        digitalWrite(pinA, LOW);
        digitalWrite(pinB, LOW);
      }
      marca = ahora;
      lado = false;
    }
  }
  if (activo && ahora - marca >= 350) {
    marca = ahora;
    lado = !lado;
    digitalWrite(pinA, lado ? HIGH : LOW);
    digitalWrite(pinB, lado ? LOW : HIGH);
  }
}

  1. Monta dos LED ámbar en D2 y D3, cada uno con su resistencia de 220 Ω.
  2. Lleva los dos cátodos y un terminal del pulsador a GND.
  3. Une el otro terminal del pulsador a D7.
  4. Carga el sketch y comprueba que al empezar los dos LED están apagados.
  5. Pulsa una vez: deben alternarse, uno encendido y el otro apagado.
  6. Pulsa otra vez y confirma que los dos se quedan apagados.
  7. Mantén el botón: no debe entrar y salir del modo muchas veces por un solo apoyo.

  • Haz que en emergencia los dos LED se enciendan y se apaguen juntos, en fase.

// Cableado: D3 LED, D7 pulsador, D8 pulsador, D9 pulsador, GND, 5V.
// D7 brillo 40, D8 brillo 140, D9 brillo 255. D3 es PWM.
// Antirrebote de 30 ms con millis. Arranque apagado.
const int pinLed = 3;
const int pines[3] = {7, 8, 9};
const int brillos[3] = {40, 140, 255};
bool estable[3] = {true, true, true};
bool ultimo[3] = {true, true, true};
unsigned long marcaBtn[3] = {0, 0, 0};

void setup() {
  pinMode(pinLed, OUTPUT);
  for (int i = 0; i < 3; i++) pinMode(pines[i], INPUT_PULLUP);
  analogWrite(pinLed, 0);
}

void loop() {
  unsigned long ahora = millis();
  for (int i = 0; i < 3; i++) {
    bool lectura = digitalRead(pines[i]);
    if (lectura != ultimo[i]) {
      ultimo[i] = lectura;
      marcaBtn[i] = ahora;
    }
    if (ahora - marcaBtn[i] >= 30 && lectura != estable[i]) {
      estable[i] = lectura;
      if (estable[i] == LOW) {
        analogWrite(pinLed, brillos[i]);
      }
    }
  }
}

Pasos

  1. Monta el LED en D3 con la resistencia de 220 Ω y el cátodo a GND.
  2. No lo pongas en D2: ese pin no hace PWM y los tres brillos se verían iguales.
  3. Conecta tres pulsadores a GND desde D7, D8 y D9.
  4. Carga el sketch y comprueba que el LED arranca apagado.
  5. Pulsa D7: debe quedar un brillo bajo y mantenerse al soltar.
  6. Pulsa D8 y luego D9: el brillo sube a medio y después a pleno.
  7. Vuelve a D7 para confirmar que puedes bajar de nivel sin reiniciar la placa.

Variantes

  • Cambia los tres niveles a 20, 90 y 180 si el alto deslumbra.
  • Haz que una segunda pulsación en el mismo botón apague el LED.
  • Añade un LED fijo en D2 que indique que ya has elegido algún nivel.

Depuración

  • Si los tres botones encienden el LED al mismo brillo, estás en un pin sin PWM y no en D3.
  • Sin la resistencia de 220 Ω el nivel alto fuerza el LED.
  • Si un pulsador no responde, su hilo de GND falta o ese pin no está en INPUT_PULLUP.
  • Si un botón va a 5 V en vez de a GND, ese nivel no llega a cargarse nunca.

// Cableado: D13 testigo, GND, 5V.
// El testigo de la placa parpadea cada 500 ms con millis.
// El monitor a 9600 devuelve la linea con el prefijo Eco.
const int pinTestigo = 13;
char linea[40];
int n = 0;
unsigned long marca = 0;
bool encendido = false;

void setup() {
  pinMode(pinTestigo, OUTPUT);
  Serial.begin(9600);
  Serial.println("Escribe y pulsa retorno. La placa devuelve el eco.");
}

void loop() {
  unsigned long ahora = millis();
  if (ahora - marca >= 500) {
    marca = ahora;
    encendido = !encendido;
    digitalWrite(pinTestigo, encendido ? HIGH : LOW);
  }
  while (Serial.available()) {
    char c = (char)Serial.read();
    if (c == '\n' || c == '\r') {
      if (n > 0) {
        linea[n] = '\0';
        Serial.print("Eco: ");
        Serial.println(linea);
        n = 0;
      }
    } else if (n < 39) {
      linea[n] = c;
      n++;
    }
  }
}

Pasos

  1. No conectes un LED externo a D13: vas a usar el testigo que ya trae la placa.
  2. No unas D13 con GND ni con 5 V mediante un cable.
  3. Conecta solo el cable USB y carga el sketch.
  4. Mira el testigo de la placa: debe cambiar de estado cada medio segundo.
  5. Abre el monitor serie a 9600 baudios y lee la frase de inicio.
  6. Escribe una palabra, pulsa retorno y comprueba que vuelve precedida de Eco.
  7. Mientras llega la respuesta, el testigo no debe congelarse.

  • Cambia el parpadeo a 150 ms para ver más claro que el eco no lo detiene.
  • Devuelve el texto entre corchetes en vez de usar el prefijo Eco.
  • Cuenta las líneas recibidas y escribe ese número al final de cada eco.

Depuración

  • Si el testigo no late, el sketch está escribiendo en otro pin y no en D13.
  • Si puenteas D13 a GND con un cable, apagas el testigo y puedes forzar el pin.
  • Con el monitor a 115200 baudios el eco sale ilegible: el sketch usa 9600.
  • Si el retorno no dispara la respuesta, el monitor no está enviando el salto de línea al pulsar intro.
