EMITIR — Les vencimos

Página para mandar la pantalla a un Chromecast o televisor.
No hay servidor RTMP/HLS ni SDK de Cast.

Tres toques:
1. Chrome: menú → Enviar / Chromecast.
2. Android: panel → Smart View / Enviar pantalla.
3. Mismo Wi-Fi.

El botón «Buscar pantalla» usa Presentation API si el navegador la tiene.
Si falla, siguen valiendo los tres toques. El reproductor deja
disableRemotePlayback en false para que Chrome muestre Enviar en un vídeo local.

La cámara de vista previa funciona en Chrome. El WebView de la app no concede
la cámara. Emitir la pantalla del teléfono es el gesto del sistema, no un
botón silencioso.
