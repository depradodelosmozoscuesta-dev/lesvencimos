# Les Vencimos Audio (`com.lesvc.audiocode`)

App Android que codifica mensajes de texto en tonos duales y los decodifica con el micrófono.
Base funcional para red comunitaria offline.

## Build

```bash
cd android-audiocode
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Publicado en: `https://lesvencimos.com/downloads/lesvencimos-audio-1.0.apk`

## Uso

1. Escribe mensaje + prioridad (0/1)
2. **Codificar y reproducir** → tonos
3. En otro móvil (o el mismo cerca del altavoz): **Grabar y decodificar**
