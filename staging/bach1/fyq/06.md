# Lección 06 · Clasificación de reacciones

Decreto 40/2022, bloque B: clasificación y relación con la sociedad, un caso acotado por tipo.

Las cuatro primeras etiquetas describen el reordenamiento. Ácido-base y redox se suman; no sustituyen. Puede haber dos etiquetas.

1. Síntesis, no redox: CaO + H2O → Ca(OH)2. Apagado de la cal. Ca +2, O −2, H +1.
2. Descomposición, no redox: CaCO3 → CaO + CO2. Horno de cal. C se queda en +4 (carbonato: +4 + 3·(−2) = −2; CO2: +4).
3. Desplazamiento y redox: Fe + CuSO4 → FeSO4 + Cu. Fe 0 → +2, Cu +2 → 0, S del sulfato +6. Sin procedimiento de planta.
4. Doble desplazamiento, no redox: CaSO4 + Na2CO3 → CaCO3 + Na2SO4. Un paso de ablandamiento, sin dosis.
5. Ácido-base, no redox: CaCO3 + 2 HCl → CaCl2 + CO2 + H2O. Antiácido de carbonato de calcio. No es dosis ni consejo médico.
6. Redox y también síntesis: 2 SO2 + O2 → 2 SO3. S +4 → +6 (x + 2·(−2) = 0; x + 3·(−2) = 0). O2 0 → −2. Lluvia ácida, una ecuación, sin concentraciones.

Átomos del ejemplo: 2 S y 6 O a cada lado.
