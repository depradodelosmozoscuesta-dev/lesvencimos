# Lección 13 — Sistemas de referencia

**Decreto 40/2022:** Bloque D. Referencias inerciales y no inerciales. Galileo en una dimensión.
**HTML:** leccion-13-sistemas-referencia.html

Solo una recta. v constante: x = x′ + v t, t = t′, u = u′ + v. Orígenes coinciden en t = 0.
Si el marco acelera, no hay una sola v y Galileo no se aplica.

## Ejemplo

v = 15 m/s, u′ = 1 m/s, t = 4 s. x′ = 4 m, x = 64 m, u = 16 m/s. Cierre 16·4 = 64.

## Claves

1. Andén y tren a velocidad constante: inerciales. Frenar o arrancar: no inercial.
2. v = 12, u′ = −1,5, t = 6: x′ = −9 m, x = 63 m, u = 10,5 m/s.
3. Maleta u′ = 0, v = 8, t = 5: x′ = 0, x = 40 m.
4. v = −4, x′ = 10, t = 3: x = −2 m.
5. Con frenado no existe una v fija para x = v t.
