Lección 30 · D.3 · Distribuciones

Binomial, normal y aproximación

1º Bach CCSS · CyL Decreto 40/2022 · D.3 Distribuciones binomial y normal

Para situarte

Contar éxitos, o medir una variable que no da saltos

La binomial cuenta éxitos en n pruebas idénticas e independientes. La normal modela una continua en forma de campana. Con n grande y np y n(1−p) holgados, la binomial se aproxima por la normal, con corrección de continuidad. La tabla de esta página es corta y redondeada, no la tabla completa.

Objetivos

  • Distinguir variable aleatoria discreta y continua, y citar media y desviación típica como parámetros.
  • Calcular a mano una binomial con n pequeño.
  • Leer una probabilidad normal con la tabla corta de abajo y aproximar una binomial cuando se cumplen las condiciones.

Discreta y continua

Discreta: número de clientes que entran en una hora, número de respuestas «sí». Solo toma valores aislados. Continua: tiempo de espera, ingreso medido con toda la precisión que se quiera; la probabilidad de un punto exacto es cero y se calculan intervalos. Parámetros que usaremos: media μ y desviación típica σ. En una binomial, μ = np y σ = √(np(1−p)).

P(X = k) = C(n, k) · pk · (1 − p)n − k.

n es el número de pruebas; k es el número de éxitos; p es la probabilidad de éxito en cada prueba, constante; C(n, k) cuenta de cuántas maneras se colocan esos k éxitos; 1 − p es la probabilidad de fracaso.

Tabla corta de la normal estándar

Φ(z) = P(Z ≤ z) para Z normal de media 0 y desviación típica 1. Los cuatro valores son redondeos habituales de la tabla estándar, no una tabla completa. No se deben inventar los z que faltan.

Ejemplo 1. Binomial pequeña, fracciones exactas

Tres personas, cada una llega tarde con probabilidad p = 1/5, de forma independiente. X = número de personas que llegan tarde. n = 3.

  1. P(X = 0)
    0) = (4/5)³
    (4/5)³ = 64/125.
  2. P(X = 1)
    1) = C(3,1)·(1/5)·(4/5)²
    1 / 5 = 1/5
    3 · 1 = 3
    3 / 5 = 3/5
    16 / 25 = 16/25
    3 / 5 = 3/5
    3 / 5 = 3/5
    3/5 · 16 = 48/5
    48/5 / 25 = 48/125
    C(3,1)·(1/5)·(4/5)² = 48/125.
  3. P(X = 2)
    2) = C(3,2)·(1/5)²·(4/5)
    1 / 25 = 1/25
    3 · 1 = 3
    3 / 25 = 3/25
    4 / 5 = 4/5
    3 / 25 = 3/25
    3 / 25 = 3/25
    3/25 · 4 = 12/25
    12/25 / 5 = 12/125
    C(3,2)·(1/5)²·(4/5) = 12/125.
  4. P(X = 3)
    3) = (1/5)³
    (1/5)³ = 1/125.
  5. Suma: 64 + 48 = 112
    112 + 12 = 124
    124 + 1 = 125, sobre 125. Cuadra.
  6. μ = np = 3/5 = 0,6. σ² = np(1−p) =3 / 5 = 3/5
    4 / 5 = 4/5
    3 / 5 = 3/5
    3/5 · 4 = 12/5
    12/5 / 5 = 12/25= 0,48. σ = √(12/25) = √12 / 5.

Dejamos σ como √(0,48) o √12 / 5. No hace falta un decimal inventado.

Ejemplo 2. Normal con la tabla corta

Una puntuación de una prueba se modela como normal de media 70 y desviación típica 10.

  1. P(X ≤ 80) = P(Z ≤ (80−70)/10)
    P(Z ≤ (80−70)/10) = P(Z ≤ 1) ≈ 0,8413.
  2. P(X ≥ 90) = P(Z ≥ 2)
    P(Z ≥ 2) = 1 − 0,9772
    1 − 0,9772 = 0,0228.
  3. P(50 ≤ X ≤ 90) = P(−2 ≤ Z ≤ 2)
    1 − 0,9772 = 0,0228
    0,9772 − 0,0228 = 0,9544
    P(−2 ≤ Z ≤ 2) = 0,9544, operando con los redondeos de la tabla.

Z = (X − μ) / σ.

X es la puntuación; μ = 70 es la media del modelo; σ = 10 es la desviación típica; Z es la misma posición medida en número de desviaciones típicas, que es lo que entra en la tabla.

Estas cifras son probabilidades del modelo normal. No son un intervalo de confianza ni un contraste: no hay aquí una muestra de la que estemos infiriendo μ.

Aproximar la binomial

Se usa cuando n es grande y tanto np como n(1−p) son holgados (una regla práctica pide al menos 10 en los dos). Entonces X, discreta, se aproxima por Y normal de media np y varianza np(1−p). Como la normal es continua, P(X ≤ k) se cambia por P(Y ≤ k + 0,5), la corrección de continuidad. P(X ≥ k) se cambia por P(Y ≥ k − 0,5).

Caso que cae en la tabla: n = 25, p = 1/2. Entonces np = 12,5 y n(1−p) = 12,5, justo en la zona donde la regla de 10 empieza a cumplirse. μ = 12,5, σ = √(25/4) = 2,5. Es un n moderado, aceptable como primera aproximación y mejor cerca del centro que en una cola muy fina; con n mucho mayor la aproximación mejora.

  1. P(X ≤ 17) ≈ P(Y ≤ 17,5).
  2. 17,5 − 12,5 = 5
    5 / 2,5 = 2
    Z = 2.
  3. Φ(2) ≈ 0,9772.
  4. El complementario P(X ≥ 18) ≈ P(Y ≥ 17,5) = 1 − 0,9772 = 0,0228. Las dos aproximaciones suman 1, como las probabilidades exactas de «≤ 17» y «≥ 18».

Z = (k + 0,5 − np) / √(np(1−p)).

k es el entero hasta el que se acumula la binomial; 0,5 es la corrección de continuidad; np es la media; la raíz es σ. Aquí k = 17, np = 12,5 y σ = 2,5.

Botón para n ≤ 20

Calcula C(n, k)·pk·(1−p)n−k en esta página. El coeficiente se muestra como entero. La probabilidad en decimal puede ir redondeada a seis cifras.

Pulsa calcular. Prueba de control: n = 4, k = 2, p = 0,5 debe dar C = 6 y probabilidad 0,375000.

Ejercicios

1. Clasifica

Di si es discreta o continua: número de hijos, tiempo de espera en una ventanilla, número de respuestas sí en una encuesta.

Corrección
  1. Número de hijos: discreta. Solo enteros.
  2. Tiempo de espera: continua. Se mide en un intervalo.
  3. Número de síes: discreta. Es un conteo, candidata a binomial si cada persona es una prueba idéntica e independiente.
  4. La media y la desviación típica existen en los tres modelos, pero la binomial tiene además n y p.

Que el tiempo se anote en minutos enteros no lo vuelve discreto en el modelo: el redondeo es del registro. El número de hijos no tiene valores entre 1 y 2.

2. Binomial a mano

n = 3, p = 1/2. Calcula P(X = 2), la media y la varianza.

Corrección
  1. C(3, 2) = 3.
  2. P(X = 2)
    2) = 3 · (1/2)² · (1/2)
    3 · (1/2)² · (1/2) = 3/8.
  3. μ = np = 3/2 = 1,5.
  4. σ² = np(1−p) =3 / 2 = 3/2
    3 / 2 = 3/2
    3/2 · 1 = 3/2
    3/2 / 2 = 3/4.

Con p = 1/2 cada una de las 8 ternas de sí/no pesa 1/8, y hay 3 ternas con exactamente dos éxitos. 3/8 coincide con la fórmula. No hace falta el botón.

3. Tabla corta

X normal de media 100 y desviación típica 15. Calcula P(X ≤ 115) y P(X ≥ 130) con la tabla de la lección.

Corrección
  1. 115 − 100 = 15
    15 / 15 = 1. P ≈ 0,8413.
  2. 130 − 100 = 30
    30 / 15 = 2.
  3. P(X ≥ 130) = 1 − 0,9772
    1 − 0,9772 = 0,0228.
  4. No hay fila para otros z: no se interpola a ojo un valor que la tabla no da.

115 está exactamente a una desviación de 100, y 130 a dos. Por eso estos dos enunciados se pueden cerrar con la tabla corta. Un 110 no cae en ninguna fila.

4. Corrección de continuidad

n = 25, p = 1/2. Aproxima P(X ≥ 18).

Corrección
  1. μ = 12,5, σ = 2,5. np y n(1−p) valen 12,5, así que la regla práctica de 10 se cumple, con n solo moderado.
  2. P(X ≥ 18) ≈ P(Y ≥ 17,5).
  3. 17,5 − 12,5 = 5
    5 / 2,5 = 2
    Z = 2.
  4. Probabilidad aproximada 1 − 0,9772 = 0,0228.

El 0,5 se resta porque la desigualdad es «mayor o igual que 18»: el bloque del entero 18 empieza en 17,5. Sin la corrección,18 − 12,5 = 5,5
5,5 / 2,5 = 2,2
Z = 2,2, y 2,2 no está en la tabla corta; además sería una aproximación peor.

Cierre

Binomial a mano solo con n pequeño y la suma de probabilidades igual a 1 como control. Normal solo con los z de la tabla corta, diciendo que son redondeos. La aproximación exige n grande y np y n(1−p) holgados, y la corrección de continuidad mueve el borde medio unidad.
