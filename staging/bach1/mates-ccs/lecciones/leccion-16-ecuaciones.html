Lección 16 · C.3 · Igualdad y desigualdad

Ecuaciones polinómicas y con radicales

Decreto 40/2022 CyL · primer curso · antes de segundo

Para situarte

Toda candidata vuelve a la ecuación de partida

Al elevar al cuadrado, o al cancelar un factor, puedes fabricar números que no eran solución. El álgebra propone; la sustitución en la ecuación original dispone.

Objetivos

  • Resolver ecuaciones polinómicas de grado 1 y 2, y una cúbica que se factoriza con una raíz entera.
  • Resolver ecuaciones con una raíz cuadrada, escribiendo antes el dominio.
  • Comprobar cada candidata en la ecuación original y descartar las soluciones extrañas.
  • Separar un descarte algebraico (no cumple la ecuación) de un descarte de contexto (cumple, pero la magnitud no puede ser negativa).

Grado 2, una cúbica factorizable y una raíz

El apartado C.3 del primer curso incluye ecuaciones polinómicas y con radicales. Las racionales, exponenciales y logarítmicas llegan en la lección siguiente; aquí el polinomio llega hasta grado 2, más una cúbica que se deja factorizar del todo, y el radical es una raíz cuadrada aislada en un miembro.

En grado 2, la ecuación ax2 + bx + c = 0, con a ≠ 0, se intenta factorizar. Si no se ve el producto, el discriminante decide cuántas soluciones reales hay.

x = [−b ± √(b2 − 4ac)] / (2a)

a, b y c son los coeficientes del polinomio ya igualado a cero, en ese orden; b2 − 4ac es el discriminante; si es positivo hay dos raíces reales, si es cero hay una raíz doble, si es negativo no hay solución real; el ± fabrica las dos candidatas; 2a es el denominador y no se omite.

Esas raíces de un polinomio, si el discriminante no es negativo, cumplen la ecuación. No son extrañas. Pueden sobrar después por el contexto: un precio negativo no se vende, aunque sea raíz del ingreso. Eso se dice aparte, cuando ya consta que sí resuelve la ecuación.

Una cúbica con coeficientes enteros se tantea con los divisores del término independiente. Si x = r anula el polinomio, se divide por (x − r) y queda un cuadrática, que ya sabes resolver. El tanteo no es la solución: es el modo de empezar la factorización. Las tres raíces, si salen reales, se comprueban en el polinomio original.

Con un radical, el orden cambia. Primero el dominio: lo de dentro de la raíz ha de ser mayor o igual que cero, y si la raíz está sola igualada a una expresión, esa expresión ha de ser mayor o igual que cero, porque una raíz cuadrada no da un negativo. Después se eleva al cuadrado. Elevar al cuadrado puede colar soluciones de la ecuación con el signo cambiado. Por eso cada candidata se sustituye en la ecuación de antes de elevar.

√(A) = B   exige   A ≥ 0 y B ≥ 0; luego A = B2

A es la expresión de dentro de la raíz; B es el otro miembro, que debe ser no negativo; A = B2 es una ecuación nueva, necesaria pero no siempre suficiente; cualquier solución de A = B2 que deje B negativo, o A negativo, es extraña y se descarta.

Ejemplo 1. Un ingreso cuadrático, dos precios válidos

En la lección del modelo quedó planteado, sin resolver, el ingreso I(p) = 20p − p2 igual a 96 euros, con el precio p entre 0 y 20 euros. Ahora sí se resuelve.

  1. 20p − p2 = 96. Se pasa todo a un miembro: −p2 + 20p − 96 = 0.
  2. Se multiplica por −1: p2 − 20p + 96 = 0.
  3. Discriminante: 400 − 384 = 16. √16 = 4.
  4. p = (20 ± 4) / 2. Entonces p = 24 / 2 = 12 o p = 16 / 2 = 8.
  5. Las dos están entre 0 y 20. Comprobación: si p = 12, se venden 20 − 12 = 8 unidades y el ingreso es 12 · 8 = 96. Si p = 8, se venden 12 y el ingreso es 8 · 12 = 96.

p2 − 20p + 96 = 0

p es el precio en euros; 20 era la ordenada de la demanda q = 20 − p; 96 es el ingreso pedido; el coeficiente de p2 es 1 después de cambiar el signo; 8 y 12 son las dos soluciones, las dos válidas en el dominio del modelo.

No hay solución extraña: no hemos elevado al cuadrado ni cancelado un denominador. Hay dos soluciones de contexto distinto (precio alto con poca venta, precio bajo con más venta) y las dos responden a la ecuación. Elegir entre ellas ya no es álgebra: es el criterio del puesto.

Cómo se parte una cúbica, antes del segundo ejemplo

Resuelve x3 − 4x2 − x + 4 = 0. Los divisores enteros de 4 son ±1, ±2 y ±4.

  1. Prueba 1 : 1 = 1
    1 − 4 = −3
    −3 − 1 = −4
    −4 + 4 = 0
    x = 0. Es raíz. Hay un factor (x − 1).
  2. Divide. Con Ruffini, baja el 1, multiplica por 1 y suma: coeficientes 1, −4, −1, 4 pasan a 1, −3, −4, 0.
  3. El cociente es x2 − 3x − 4. Se factoriza: (x − 4)(x + 1), porque −4 · 1 = −4 y −4 + 1 = −3.
  4. Ecuación factorizada: (x − 1)(x − 4)(x + 1) = 0. Candidatas: x = 1, x = 4, x = −1.
  5. Las tres anulan el polinomio: para x = 4,
    64 − 64 = 0
    0 − 4 = −4
    −4 + 4 = 0; para x = −1,
    −1 − 4 = −5
    −5 + 1 = −4
    −4 + 4 = 0. No se descarta ninguna por el álgebra.

(x − 1)(x − 4)(x + 1) = 0

x es la incógnita; 1, 4 y −1 son las raíces; cada paréntesis es un factor que se anula en una de ellas; el producto es el polinomio de partida, así que anular el producto equivale a anular el polinomio.

Si un enunciado añadiera «x es un número de años a partir de hoy, x ≥ 0», entonces x = −1 se apartaría por el contexto, no porque sea extraña. Cumple la ecuación. Conviene escribir las dos frases por separado.

Ejemplo 2. Una raíz que fabrica una candidata falsa

Se busca x tal que √(2x + 3) = x. Puede ser un índice que se iguala a la propia variable; lo que importa es la ecuación.

  1. Dominio: 2x + 3 ≥ 0, así x ≥ −3/2, y además el miembro derecho x ≥ 0. En conjunto, x ≥ 0.
  2. Se eleva al cuadrado: 2x + 3 = x2. Ordena: x2 − 2x − 3 = 0.
  3. Factoriza: (x − 3)(x + 1) = 0. Candidatas x = 3 y x = −1.
  4. x = −1 no cumple x ≥ 0. Sustituir de todos modos: −2 + 3 = 1
    √1 = 1, y el otro miembro es −1. 1 ≠ −1. Extraña.
  5. x = 3 está en el dominio.6 + 3 = 9
    √9 = 3, que coincide con el miembro derecho. Es la única solución.

√(2x + 3) = x

x es la incógnita; 2x + 3 es el radicando, que ha de ser no negativo; el miembro derecho x ha de ser no negativo porque es igual a una raíz cuadrada; 3 es la solución que sobrevive; −1 es la candidata que crea el cuadrado y que la comprobación elimina.

Fíjate en el contraste con la cúbica. Allí −1 era solución de verdad. Aquí −1 es un resto de haber elevado al cuadrado: la ecuación x2 = 2x + 3 también la cumplen los casos en los que x es el opuesto de la raíz. La raíz cuadrada se queda solo con el no negativo.

Ejercicios

1. Grado 2 que factoriza

Resuelve x2 − 5x + 6 = 0 y comprueba las dos raíces sustituyendo.

Corrección
  1. Se buscan dos números de producto 6 y suma −5: −2 y −3.
  2. (x − 2)(x − 3) = 0. Entonces x = 2 o x = 3.
  3. Si x = 2:
    4 − 10 = −6
    −6 + 6 = 0. Si x = 3:
    9 − 15 = −6
    −6 + 6 = 0.
  4. Las dos valen. No hay extrañas.

En un polinomio igualado a cero, factorizar no amplía el conjunto de soluciones: el producto es cero exactamente cuando lo es alguno de los factores. La sustitución aquí es una revisión de la aritmética, no un filtro de soluciones fantasma.

2. Cúbica con factor común

Resuelve x3 − 4x = 0. No hace falta Ruffini: hay una x común. Di si alguna raíz es extraña.

Corrección
  1. x3 − 4x = x(x2 − 4)
    x(x2 − 4) = x(x − 2)(x + 2).
  2. Las soluciones son x = 0, x = 2 y x = −2.
  3. Comprobación: 0 − 0 = 0; 8 − 8 = 0; −8 − (−8) = 0.
  4. Ninguna es extraña. Sacar factor común x no es cancelar x: si cancelaras, perderías precisamente la solución x = 0.

Cancelar x en los dos miembros de x3 = 4x exigiría decir x ≠ 0 y luego acordarse de mirar ese caso aparte. Factorizar y dejar el factor escrito no pierde la raíz cero. Las tres soluciones cumplen el polinomio.

3. Radical con una candidata fuera

Resuelve √(x + 7) = x − 5. Escribe el dominio, las candidatas y la que sobrevive.

Corrección
  1. Radicando: x + 7 ≥ 0, x ≥ −7. Miembro derecho: x − 5 ≥ 0, x ≥ 5. Dominio de la ecuación: x ≥ 5.
  2. Al cuadrado: x + 7 = (x − 5)2
    (x − 5)2 = x2 − 10x + 25. Entonces x2 − 11x + 18 = 0.
  3. Discriminante 121 − 72 = 49. x = (11 ± 7) / 2. Así x = 9 o x = 2.
  4. x = 2 no cumple x ≥ 5. Además 2 + 7 = 9
    √9 = 3 y 2 − 5 = −3: 3 ≠ −3. Se descarta.
  5. x = 9: √16 = 4 y 9 − 5 = 4. Es la solución.

x = 2 resuelve la ecuación cuadrática obtenida al elevar, no la ecuación con la raíz. El miembro derecho queda negativo y una raíz cuadrada no lo es. Por eso el dominio se escribe antes: ya avisa de que 2 no puede entrar.

4. Las dos candidatas, y solo una vale

Resuelve √(3x + 1) = x − 1. Comprueba las dos candidatas en la ecuación original.

Corrección
  1. 3x + 1 ≥ 0 da x ≥ −1/3, y x − 1 ≥ 0 da x ≥ 1. Dominio: x ≥ 1.
  2. (x − 1)2 = 3x + 1 → x2 − 2x + 1 − 3x − 1 = 0 → x2 − 5x = 0 → x(x − 5) = 0.
  3. Candidatas: x = 0 y x = 5. x = 0 no está en x ≥ 1.
  4. x = 0: √1 = 1 y 0 − 1 = −1. No coincide. Extraña.
  5. x = 5: √(15 + 1) = √16 = 4 y 5 − 1 = 4. Solución única.

El producto x(x − 5) = 0 tiene dos ceros, pero uno de ellos no respeta que la raíz sea igual a un número no negativo. Sustituir x = 0 no es un trámite: es la prueba de que esa raíz del cuadrado no lo es de la ecuación inicial.

Cierre

En un polinomio, factoriza, resuelve y sustituye para cazar un error de cuenta. En un radical, escribe el dominio, eleva al cuadrado y vuelve a la ecuación de partida: lo que no encaja es extraño, aunque haya salido de una cuadrática impecable. Un negativo que sí encaja en el polinomio solo se va si el contexto lo prohíbe.
