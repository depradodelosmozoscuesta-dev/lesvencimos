Lección 17 · C.3 · Igualdad

Ecuaciones racionales, exponenciales y logarítmicas

1º Bach CCSS · CyL Decreto 40/2022 · C.3 Igualdad y desigualdad

Para situarte

El dominio es parte de la solución

En 1.º de CCSS las ecuaciones racionales, exponenciales y logarítmicas se resuelven a mano y se filtran: una candidata que anula un denominador o deja un logaritmo sin argumento positivo no es solución.

Objetivos

  • Resolver ecuaciones racionales sencillas, exponenciales y logarítmicas.
  • Escribir el dominio antes de operar y tachar las candidatas que no pertenecen a él.
  • Sustituir cada superviviente en la ecuación original.

Tres filtros

Una ecuación racional tiene la incógnita en algún denominador. Ese denominador no puede ser cero. Una ecuación logarítmica exige argumento positivo en cada logaritmo, y la base, si aparece, cumple a > 0 y a ≠ 1. Una exponencial aexpresión con esa misma base está definida en todo ℝ; ahí no se excluye dominio, se comprueba el resultado.

loga(M) = b ⇔ M = ab, con a > 0, a ≠ 1, M > 0.

a es la base; M es el argumento, que ha de ser positivo; b es el exponente al que se eleva a para recuperar M.

loga(M) + loga(N) = loga(M·N), solo si M > 0 y N > 0.

M y N son argumentos de la misma base a. No basta con que el producto sea positivo: si uno de los dos es negativo, la suma de logaritmos no estaba definida.

au = av ⇒ u = v, cuando a > 0 y a ≠ 1.

a es la base común; u y v son los exponentes. Se igualan porque la exponencial de esa base es inyectiva.

Ejemplo 1. Racional, con comprobación

Un reparto queda modelado por (x + 1) / (x − 2) = 3.

  1. Dominio: x − 2 ≠ 0, así que x ≠ 2.
  2. Con x ≠ 2 se multiplica por el denominador: x + 1 = 3(x − 2).
  3. x + 1 = 3x − 6 → 7 = 2x → x = 7/2 = 3,5.
  4. 3,5 ≠ 2. Sustitución: 3,5 + 1 = 4,5
    3,5 − 2 = 1,5
    4,5 / 1,5 = 3. Sirve.

(x + 1) / (x − 2) = 3, x ≠ 2.

x es la incógnita del reparto; 2 es el valor prohibido del denominador; 3 es el cociente que fija el enunciado; 1 es el término independiente del numerador.

Ejemplo 2. Logaritmos y una raíz que no existe

Se busca un precio x, en euros, con log(x) + log(x − 3) = log(10). Todos los logaritmos van en la misma base válida; no hace falta nombrar cuál.

  1. Dominio: x > 0 y x − 3 > 0, luego x > 3.
  2. log[x(x − 3)] = log(10). Por inyectividad, x(x − 3) = 10.
  3. x² − 3x − 10 = 0 se factoriza (x − 5)(x + 2) = 0. Candidatas: x = 5 y x = −2.
  4. x = −2 no cumple x > 3. x = 5 sí: log(5) + log(2)
    5 sí: log(5) + log(2) = log(10).

x² − 3x − 10 = 0, y solo vale la raíz con x > 3.

x es el precio; 3 es lo que se resta en el segundo argumento; 10 es el número que queda al quitar el logaritmo de la derecha, no un logaritmo.

log(−2) no es un número real. La raíz negativa no es una solución aproximada: es una candidata inválida.

Ejercicios

1. Racional

Resuelve (x + 4) / (x − 1) = 2.

Corrección
  1. Dominio: x ≠ 1.
  2. x + 4 = 2(x − 1)
    2(x − 1) = 2x − 2.
  3. 4 + 2 = 2x − x, así x = 6.
  4. 6 ≠ 1. Comprobación: (10) / (5) = 2.

Multiplicar por el denominador puede colar una raíz ajena. Aquí la candidata es 6, el denominador vale 5 y la sustitución devuelve exactamente 2.

2. Misma base

Resuelve 5x − 1 = 125.

Corrección
  1. 125 = 5³ y la base 5 es válida.
  2. 5x − 1 = 5³ implica x − 1 = 3.
  3. x = 4.
  4. Comprobación: 53 = 125.

Igualar exponentes solo vale si los dos lados son potencias de la misma base positiva distinta de 1. 125 ya es potencia de 5; no hace falta cambiar a logaritmos.

3. Suma de logaritmos

Resuelve log2(x + 1) + log2(x − 1) = 3.

Corrección
  1. Dominio: x + 1 > 0 y x − 1 > 0, luego x > 1.
  2. log2(x² − 1) = 3, así x² − 1 = 2³ = 8.
  3. x² = 9, candidatas x = 3 y x = −3.
  4. Solo x = 3 cumple x > 1. log2(4) + log2(2) = 2 + 1
    2 + 1 = 3.

x = −3 hace negativos los dos argumentos. Aunque el producto sea positivo, la suma de logaritmos no existía, así que no es solución.

4. La candidata cae fuera

Resuelve (x² − 9) / (x − 3) = 6.

Corrección
  1. Dominio: x ≠ 3.
  2. x² − 9 = (x − 3)(x + 3). Para x ≠ 3 la ecuación es x + 3 = 6, luego x = 3.
  3. x = 3 está fuera del dominio y no hay otra candidata.
  4. Sustituir x = 3 da 0/0, que no es un número. Solución: conjunto vacío.

Cancelar x − 3 solo es lícito fuera de ese punto. La ecuación simplificada señala justo el punto prohibido, así que no queda ninguna solución.

Cierre

Orden fijo: dominio, transformación, candidatas, filtro y sustitución. Si nadie sobrevive, el conjunto solución está vacío; no se rescata la candidata prohibida.
