Lección 19 · C.3 · Sistemas lineales

Sistemas lineales y método de Gauss

1º Bach CCSS · CyL Decreto 40/2022 · C.3 Sistemas lineales con tres incógnitas

Para situarte

Gauss ordena, no adivina

Un sistema lineal con tres incógnitas se escribe como matriz ampliada y se triangulariza. Al final hay una solución, ninguna, o infinitas.

Objetivos

  • Traducir un sistema lineal a matriz ampliada.
  • Resolver un sistema 3×3 por Gauss, con solución entera, dejando cada fila escrita.
  • Reconocer en pocas cuentas un sistema incompatible y uno indeterminado.

Operaciones permitidas

Se puede permutar filas, multiplicar una fila por un número distinto de cero y sumar a una fila un múltiplo de otra. El sistema nuevo tiene exactamente las mismas soluciones. Se busca un escalón: un 1 (o un pivote claro) y ceros debajo.

Fila nueva = fila − k · otra fila.

k es el número que anula la entrada que quieres limpiar; se elige como «entrada a borrar dividida entre el pivote».

Ejemplo 1. Un 3×3 con solución (1, 2, −1)

Sistema, ya comprobado al final:

x + y + z = 2;   2x + y − z = 5;   x − y + 2z = −3.

x, y, z son las tres incógnitas. Los coeficientes de la segunda ecuación son 2, 1 y −1; el término independiente es 5. En la tercera, el coeficiente de y es −1 y el de z es 2.
  1. Matriz ampliada de partida: 
    1   1   1  |  2
2   1  −1  |  5
1  −1   2  | −3
  2. F2 ← F2 − 2·F1. Coeficientes:
    2−2 = 0
    1−2 = −1
    −1−2 = −3. Independiente: 5−4=1. F3 ← F3 − F1: 0, −1−1=−2, 2−1=1, −3−2=−5. 
    1   1   1  |  2
0  −1  −3  |  1
0  −2   1  | −5
  3. F2 ← −1·F2, para dejar pivote 1: 
    1   1   1  |  2
0   1   3  | −1
0  −2   1  | −5
  4. F3 ← F3 + 2·F2. Columna de y: −2+2=0. Columna de z: 1+6=7. Independiente: 2 · (−1) = −2
    −5 + −2 = −7. 
    1   1   1  |  2
0   1   3  | −1
0   0   7  | −7
  5. 7z = −7, así z = −1. Segunda fila: y + 3·(−1) = −1 → y − 3 = −1 → y = 2. Primera: x + 2 + (−1) = 2 → x + 1 = 2 → x = 1.
  6. Comprobación. Eq1 : 1 = 1
    1 + 2 = 3
    3 − 1 = 2. Eq2:
    2 · 1 = 2
    2 + 2 = 4
    4 − −1 = 5. Eq3:
    1 − 2 = −1
    2 · (−1) = −2
    −1 + −2 = −3.

Ejemplo 2. Sin solución, y otro con infinitas

Incompatible, en dos ecuaciones que ya delatan el caso:

x + y = 3;   2x + 2y = 7.

x e y son incógnitas. La segunda fila es el doble de la primera en los coeficientes, pero 7 no es el doble de 3.
  1. F2 ← F2 − 2·F1 deja 0x + 0y = 7 − 6 = 1.
  2. 0 = 1 es imposible. No hay solución.

Indeterminado, ahora con tres incógnitas y una fila que se anula:

x + y + z = 3;   2x + 2y + 2z = 6;   x + z = 2.

La segunda ecuación es el doble de la primera, término independiente incluido (6 = 2·3). No aporta información nueva.
  1. F2 − 2·F1 es la fila cero, compatible.
  2. De la tercera, z = 2 − x. De la primera: x + y + (2 − x) = 3 → y = 1.
  3. x queda libre. Hay infinitas soluciones: (x, 1, 2 − x), con x real. Dos de ellas: (0, 1, 2) y (1, 1, 1).

Ejercicios

1. Suma y resta

Resuelve x + y = 7, x − y = 1.

Corrección
  1. Sumando las dos ecuaciones: 2x = 8, x = 4.
  2. Restando: 2y = 6, y = 3. O bien y = 7 − x = 3.
  3. Comprobación: 4 + 3 = 7 y 4 − 3 = 1.

Dos ecuaciones con dos incógnitas y coeficientes de y opuestos se resuelven sumando. No hace falta Gauss; el método es el mismo tipo de combinación de filas.

2. Gauss corto

Resuelve por Gauss: x + z = 3, y + z = 1, x + y + z = 3.

Corrección
  1. Matriz: filas (1 0 1 | 3), (0 1 1 | 1), (1 1 1 | 3).
  2. F3 ← F3 − F1 queda (0 1 0 | 0).
  3. F3 ← F3 − F2 queda (0 0 −1 | −1), así z = 1.
  4. y + 1 = 1 → y = 0. x + 1 = 3 → x = 2. Comprobación:
    2+1 = 3
    0+1 = 1
    2 + 0 = 2
    2 + 1 = 3.

El pivote de z salió −1, no 1. Se puede dividir la fila entre −1 o despejar directamente: −z = −1 da el mismo z = 1.

3. Incompatible

Estudia x + 2y = 4, 2x + 4y = 5.

Corrección
  1. F2 − 2·F1: coeficientes 0 y 0.
  2. Independiente: 5 − 8 = −3.
  3. Queda 0 = −3. Ninguna solución.

Los coeficientes son proporcionales (razón 2) y los términos independientes no (5 no es 8). Esa es la señal de incompatibilidad, y la fila cero con independiente distinto de cero lo confirma.

4. Una libre

Estudia x + 2y = 4, 2x + 4y = 8.

Corrección
  1. F2 − 2·F1 es 0 = 0, compatible y redundante.
  2. Queda una sola condición: x + 2y = 4.
  3. x = 4 − 2y, con y libre. Infinitas soluciones. Por ejemplo y = 0 da (4, 0); y = 1 da (2, 1).

Aquí el término independiente también se duplica (8 = 2·4), así que la segunda ecuación no añade nada. No hay una única pareja (x, y).

Cierre

Gauss termina en tres desenlaces: un pivote por incógnita (solución única), una fila 0 = c con c ≠ 0 (ninguna) o una fila 0 = 0 que deja una incógnita libre (infinitas). Sustituye la terna en las tres ecuaciones de partida antes de darla por buena.
