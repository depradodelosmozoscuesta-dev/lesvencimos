Lección 10 · B.2 · Cambio

Límites desde tabla, gráfica y expresión

Decreto 40/2022 CyL · primer curso · antes de segundo

Para situarte

Acercarse no es llegar

Un límite pregunta qué valor se acerca la función cuando x se acerca a un sitio. La función puede no estar definida justo ahí, y aun así el límite puede existir.

Objetivos

  • Estimar un límite leyendo una tabla de valores cercanos.
  • Leer un límite en una gráfica, incluido un hueco y un salto.
  • Calcular un límite sencillo a partir de la expresión, simplificando o reescribiendo.
  • Distinguir límite por la izquierda, por la derecha y límite a largo plazo, cuando x crece sin tope.

Tres sitios donde mirar el mismo límite

En el sentido de la medida, bloque B.2 del primer curso, el límite se estima o se calcula desde una tabla, un gráfico o una expresión algebraica. No hace falta la definición formal con distancias: hace falta ver hacia dónde va la función y comprobar que los tres lenguajes cuentan la misma historia.

Si x se acerca a un número a, escribimos el límite de f(x) cuando x tiende a a. Nos importa el comportamiento al lado de a, no el cartel que haya puesto alguien exactamente en a. Por eso una función puede tener límite 4 en x = 2 y, a la vez, no valer 4 en ese punto: o no está definida, o está definida con otro valor.

lim (x → a) f(x) = L

x es la variable que se mueve; a es el número al que x se acerca; f(x) es el valor de la función en esos vecinos; L es el número al que esos valores se arriman. L no tiene por qué ser f(a).

Hay tres lecturas útiles en ciencias sociales:

  • Tabla: eliges x cada vez más pegados a a, por los dos lados, y miras si f(x) se estabiliza en el mismo sitio.
  • Gráfica: sigues la curva hacia la recta vertical x = a. Si los dos lados llegan a la misma altura, esa altura es el límite. Un punto vacío o un punto relleno aislado no cambia esa altura.
  • Expresión: si la fórmula se atasca (por ejemplo, 0/0), la reescribes. Si cerca de a coincide con una expresión más simple, el límite es el valor de esa expresión simple.

Cuando los dos lados no se ponen de acuerdo, el límite (a secas) no existe. Aun así puedes hablar del límite por la izquierda, x → a−, y por la derecha, x → a+. Una tarifa que cambia de golpe al cumplir una edad es el caso típico: a la izquierda del corte vale una cosa y a la derecha otra.

También miramos qué pasa cuando x se hace muy grande, x → ∞. No es «x igual a infinito». Es: si x sigue creciendo, ¿la función se acerca a alguna altura estable? En una proporción de polinomios del mismo grado, esa altura es el cociente de los coeficientes principales.

(3x + 1) / (x + 2) = 3 − 5 / (x + 2)

x es la variable, por ejemplo un número de años o de unidades; 3 es el cociente de los coeficientes de x; 5 es lo que hay que restar para que la igualdad sea exacta, porque 3(x + 2) − 5 = 3x + 1; x + 2 es el denominador original, que crece y hace pequeño el segundo término.

Ejemplo 1. Tabla, álgebra y un hueco

Sea f(x) = (x2 − 4) / (x − 2), definida para todo x distinto de 2. En x = 2 el denominador es cero y el numerador también: la fórmula, tal cual, no da un número. Mira vecinos.

x1,91,992,012,1
f(x)3,93,994,014,1

Comprueba uno: si x = 1,9, numerador 1,92 − 4 = 3,61 − 4 = −0,39 y denominador −0,1, así que f(1,9) = 3,9. Los cuatro valores se arriman a 4, por la izquierda y por la derecha. La estimación del límite es 4.

  1. Factoriza el numerador: x2 − 4 = (x − 2)(x + 2).
  2. Para x ≠ 2 se cancela el factor común: f(x) = x + 2.
  3. x + 2, cuando x se acerca a 2, se acerca a 4. El límite es 4.
  4. f(2) sigue sin existir. El límite no rellena el hueco por sí solo; solo dice a qué altura está el hueco.

lim (x → 2) (x2 − 4) / (x − 2) = 4

x es la variable; 2 es el punto donde el denominador original se anula; x2 − 4 es el numerador, diferencia de cuadrados; 4 es el límite, que coincide con 2 + 2, el valor de la expresión ya simplificada.

El esquema representa la recta y = x + 2 y deja vacío el punto de abscisa 2. La altura de ese hueco es el límite, 4. Quien lee solo el punto vacío y dice «no hay límite» confunde «no hay función» con «no hay límite». El lienzo de debajo está a escala para marcar ese punto.

Ejemplo 2. Un salto y un límite a largo plazo

Una cuota de acceso, en euros, depende de las horas x ya usadas: T(x) = 3 si x < 2 y T(x) = 5 si x ≥ 2. No es una fórmula rota: es una tarifa a trozos, definida también en 2, donde vale 5.

  1. Por la izquierda de 2, x es menor que 2, así que T(x) = 3. El límite por la izquierda es 3.
  2. Por la derecha, T(x) = 5. El límite por la derecha es 5.
  3. 3 ≠ 5, luego no existe el límite cuando x tiende a 2. Da igual que T(2) = 5: el valor del punto no reconcilia los dos lados.

lim (x → 2−) T(x) = 3   y   lim (x → 2+) T(x) = 5

x son las horas usadas; 2 es el corte de la tarifa; T(x) es la cuota en euros; 3 es la cuota del tramo bajo; 5 es la cuota del tramo alto, que también es T(2).

Otro encargo, ahora de largo plazo. La proporción (3x + 1) / (x + 2) se reescribe como 3 − 5 / (x + 2). Cuando x crece, 5 / (x + 2) se hace pequeño y la proporción se acerca a 3. Tabla exacta:

x8184898
(3x+1)/(x+2)2,52,752,92,95

25/10 = 2,5
55/20 = 2,75
145/50 = 2,9
295/100 = 2,95. Van hacia 3 y no lo pasan. El límite cuando x tiende a infinito es 3. No hay una x en la que la expresión valga exactamente 3, porque 5 / (x + 2) nunca es cero.

Marca el límite en el lienzo

La gráfica de debajo es la del ejemplo 1: recta con hueco en (2, 4). Con el dedo o el ratón, marca el hueco y escribe al lado, a mano, la altura del límite. Restaurar vuelve a dejar solo la gráfica.

Ejercicios

1. Otra tabla que se atasca

g(x) = (x2 − 1) / (x − 1), con x ≠ 1. Calcula g(0,9), g(0,99), g(1,01) y g(1,1). Estima el límite cuando x tiende a 1 y confírmalo simplificando.

Corrección
  1. 0,81 − 1 = −0,19
    0,90 − 1 = −0,10
    (−0,19) / (−0,10) = 1,9
    g(0,9) = 1,9.
  2. 0,9801 − 1 = −0,0199
    (−0,0199) / (−0,0100) = 1,99
    g(0,99) = 1,99.
  3. 1,0201 − 1 = 0,0201
    0,0201 / 0,0100 = 2,01
    g(1,01) = 2,01.1,21 − 1 = 0,21
    0,21 / 0,10 = 2,1
    g(1,1) = 2,1.
  4. La tabla se acerca a 2. Como x2 − 1 = (x − 1)(x + 1), para x ≠ 1 se tiene g(x) = x + 1, y el límite es 2.

0/0 no es un número y tampoco es el límite. Es la señal de que la fórmula original no sirve en ese punto y hay que reescribirla en un entorno donde el factor común no es cero.

2. Una expresión que no se atasca

Calcula el límite de 5x + 2 cuando x tiende a 0. Después di cuánto vale la función en 0 y si los dos números coinciden.

Corrección
  1. 5x + 2 es un polinomio: cerca de 0 se comporta como su valor en 0.
  2. El límite es 5 · 0 = 0
    0 + 2 = 2.
  3. La función en 0 también vale 2. Coinciden.

No toda pregunta de límite esconde un hueco. Si la expresión está definida y es un polinomio, el límite en a es sustituir a. El caso interesante del ejemplo 1 era precisamente el que no deja sustituir.

3. Dos lados que no casan

f(x) = x + 1 si x < 0, y f(x) = 2 − x si x ≥ 0. Halla el límite por la izquierda en 0, el límite por la derecha en 0, f(0) y di si existe el límite.

Corrección
  1. Por la izquierda se usa x + 1, que tiende a 1.
  2. Por la derecha se usa 2 − x, que tiende a 2.
  3. f(0) = 2 − 0
    2 − 0 = 2.
  4. Como 1 ≠ 2, el límite cuando x tiende a 0 no existe.

El valor f(0) solo informa del lado en el que ha quedado incluido el corte. Un límite de dos lados exige el mismo número a izquierda y derecha. Aquí la gráfica da un salto de altura 1.

4. Cuando x crece

Estudia (2x − 4) / (x + 1) cuando x tiende a infinito. Reescribe la fracción y comprueba con x = 5, x = 11 y x = 29.

Corrección
  1. 2(x + 1) − 6 = 2x − 4, luego (2x − 4) / (x + 1) = 2 − 6 / (x + 1).
  2. Cuando x crece, 6 / (x + 1) tiende a 0. El límite es 2.
  3. x = 5:
    6 / 6 = 1. x = 11:
    18 / 12 = 1,5. x = 29:
    54 / 30 = 1,8. Se acercan a 2 por debajo.

El término con x en el numerador y el término con x en el denominador mandan cuando x es grande. El −4 y el +1 se quedan pequeños en comparación, pero la reescritura exacta evita el gesto vago de «tachamos los números sueltos».

Cierre

Tabla para estimar, gráfica para ver el hueco o el salto, álgebra para cerrar el número. Si los dos lados discrepan, dilo: el límite no existe, y escribe los laterales. Si x se va a infinito, busca la altura a la que la expresión se aplana.
