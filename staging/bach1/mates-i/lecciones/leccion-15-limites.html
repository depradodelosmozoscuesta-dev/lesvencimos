Lección 15 · Matemáticas I

Límites a partir de una tabla, una gráfica y una expresión

Saber del curso (Decreto 40/2022, BOCyL): límites, estimación y cálculo a partir de una tabla, un gráfico o una expresión algebraica.

Objetivos

  • Estimar un límite con una tabla de valores cercanos.
  • Leer el mismo límite en una gráfica.
  • Calcular limx→1 (x2 − 1)/(x − 1) y obtener 2.

Explicación

Qué se mira

El límite de f cuando x tiende a a es el valor al que se acercan los resultados f(x) cuando x se acerca a a, sin exigir que x llegue a valer a. Se escribe limx→a f(x).

lim es «límite». La flecha x→a se lee «x tiende a a»: x se acerca, no tiene por qué sustituirse.

Tres vías

Se puede estimar con una tabla (números cada vez más próximos), con una gráfica (hacia qué altura va el punto) o con el álgebra (simplificar la expresión donde esté definida).

Una frase sobre 1/x

Cuando x tiende a 0 por la derecha, 1/x se hace mayor que cualquier número fijo: tiende a +∞.

+∞ no es un número real al que se llegue. Aquí solo nombra que 1/x crece sin tope al acercarnos a 0 por valores positivos.

Ejemplo 1 · Tabla y álgebra de (x2 − 1)/(x − 1)

La expresión no se puede sustituir en x = 1: el numerador 1 − 1 = 0 y el denominador también es 0. Para x ≠ 1 se factoriza x2 − 1 = (x − 1)(x + 1), y el cociente vale x + 1.

x0,90,990,9991,0011,011,1
(x2 − 1)/(x − 1)1,91,991,9992,0012,012,1

Cada valor es x + 1: 0,9 + 1 = 1,9; 0,99 + 1 = 1,99; 1,001 + 1 = 2,001; 1,1 + 1 = 2,1. Al tender x a 1, x + 1 tiende a 2. Por eso

limx→1 (x2 − 1)/(x − 1) = 2.

Ejemplo 2 · Un límite que sí se puede sustituir

limx→2 (3x + 1). La expresión 3x + 1 no se rompe en x = 2.

  1. En el punto: 3 · 2 = 6
    6 + 1 = 7.
  2. Por la izquierda,x = 1,9:
    3 · 1,9 = 5,7
    5,7 + 1 = 6,7.
  3. Por la derecha,x = 2,1:
    3 · 2,1 = 6,3
    6,3 + 1 = 7,3.

Los valores se acercan a 7, que es el resultado de sustituir. El límite es 7.

Error típico

Sustituir x = 1 en (x2 − 1)/(x − 1) y decir que 0/0 es 0, o que es 1. Cero entre cero no es un número: la expresión no está definida en x = 1. El límite no pide el valor en el punto; pide a qué se acerca, y aquí se acerca a 2.

Figura

La gráfica de y = x + 1, con un hueco en (1, 2): ahí la expresión original no está definida, pero el punto hueco está a altura 2.

Práctica · acércate a 1

Escribe un x distinto de 1. Verás el valor de la expresión, que coincide con x + 1, y el punto sobre la recta. En x = 1 el programa no divide.

Cuando x se acerca a 1, x + 1 se acerca a 2. En x = 1 la fracción original no está definida.

Se guarda solo en este navegador (bach1-mates-i-L15).

Por qué funciona

Por qué: se puede simplificar lejos de 1

Para cualquier x distinto de 1, (x − 1) no es cero y se cancela en (x − 1)(x + 1)/(x − 1). Queda x + 1, que en x = 0,9 vale 1,9 y en x = 1,1 vale 2,1.

Por qué: el límite es 2 aunque no haya valor en 1

El hueco está justo a altura 2. Acercarse por 0,999 o por 1,001 da 1,999 y 2,001. La altura límite es 2; el hueco solo dice que f(1) no existe.

Por qué: 1/x se dispara al acercarse a 0 por la derecha


Si x = 0,1
1/x = 10.
Si x = 0,01
1/x = 100. Cada vez que x positivo se hace diez veces menor, 1/x se hace diez veces mayor. No se acerca a un número real.

Cierre

Tabla, gráfica y álgebra cuentan la misma historia: (x2 − 1)/(x − 1) se acerca a 2 cuando x se acerca a 1. Y, en una frase, 1/x tiende a +∞ cuando x tiende a 0 por la derecha.

Reto

Otra tabla, el mismo límite

Calcula (x2 − 1)/(x − 1) en x = 1,01 y en x = 0,999 sin usar la tabla de la lección. Di a qué entero se están pegando.

  • Puedes simplificar antes de sustituir, porque ninguno de esos x es 1.
  • Comprueba que la suma x + 1 coincide con el cociente.
