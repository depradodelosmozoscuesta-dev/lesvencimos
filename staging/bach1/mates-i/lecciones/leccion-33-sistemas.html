Lección 33 · Sentido algebraico

Sistemas no lineales y regiones en el plano

1º Bachillerato Matemáticas I · Ciencias y Tecnología

Saberes (Decreto 40/2022): sistemas de ecuaciones no lineales y sistemas de inecuaciones lineales (sentido algebraico).

Objetivos

  1. Resolver un sistema no lineal sencillo (recta y parábola) y comprobar las dos soluciones.
  2. Representar un sistema de inecuaciones lineales de dos variables como intersección de semiplanos.
  3. Decidir si un punto es solución probando las desigualdades, sin usar Gauss.

Explicación

Recta y parábola

Un sistema no lineal de este curso puede ser una recta y una parábola. Se despeja la variable que está en las dos y se sustituye. Pueden salir dos puntos, uno (tangencia) o ninguno. En el ejemplo de hoy salen dos, y los dos se comprueban.

y = x2 e y = 2x + 3 llevan a x2 = 2x + 3, o sea x2 − 2x − 3 = 0.

Semiplanos

Cada inecuación lineal en x e y es un semiplano. El sistema es la región común. La recta x + y = 4 es el borde: x + y ≤ 4 es el lado que contiene al origen, porque 0 + 0 ≤ 4. x ≥ 0 es el semiplano de la derecha del eje vertical, y ≥ 0 el de encima del eje horizontal. No hace falta el método de Gauss: son dos variables y el dibujo cierra el sistema.

Glosas de esta lección

Sistema Varias condiciones a la vez. Una solución las cumple todas.

Semiplano Una de las dos regiones en que una recta parte el plano, borde incluido o no según ≤ o <.

Sustituir Poner una expresión en la otra ecuación para quedar con una sola incógnita.

Ejemplo 1 · Recta y parábola, dos soluciones

y = x2, y = 2x + 3.

  1. x2 − 2x − 3 = 0.
  2. (x − 3)(x + 1) = x2 − 2x − 3, porque −3 + 1 = −2 y (−3)·1 = −3.
  3. x = 3 o x = −1.
  4. Si x = 3, y = 9. Si x = −1, y = 1. También por la recta: 2 · 3 = 6
    6 + 3 = 9 y 2 · (−1) = −2
    −2 + 3 = 1.
  5. Comprueba en la parábola: 32 = 9 y (−1)2 = 1. Las dos soluciones son (3, 9) y (−1, 1).

Ejemplo 2 · Región, tres semiplanos

x ≥ 0, y ≥ 0, x + y ≤ 4.

  1. El primer cuadrante corta la franja x + y ≤ 4 en el triángulo de vértices (0, 0), (4, 0) y (0, 4).
  2. (0, 0): 0 ≥ 0, 0 ≥ 0, 0 ≤ 4. Vértice, entra.
  3. (1, 1): 1 + 1 = 2 ≤ 4. Interior, entra.
  4. (3, 3): 3 + 3 = 6 ≤ 4 es falso. Fuera, aunque las dos coordenadas sean positivas.
  5. (4, 0): 4 + 0 = 4 ≤ 4. Está en el borde y entra.

Error típico

Quedarse solo con (3, 9) porque la abscisa es positiva, o sombrear el semiplano x + y ≥ 4.

Corrección: (−1)2 = 1 y 2 · (−1) = −2
−2 + 3 = 1, así que (−1, 1) también es solución del sistema de ecuaciones. En las inecuaciones, el origen cumple x + y ≤ 4; el lado que contiene a (0, 0) es el bueno. (3, 3) suma 6 y se queda fuera.

Práctica

Arriba, la parábola y la recta con los dos cortes. Abajo, la región. Mueve el punto y mira si cae dentro. Escribe las dos soluciones del sistema de ecuaciones.

Comprueba

Comprueba · (3, 9)

Por qué: 32 = 9 y 2 · 3 = 6
6 + 3 = 9. No se deja el resultado pelado de una sola ecuación: hay que sustituir la solución en las dos, la parábola y la recta, porque un punto de una curva puede no estar en la otra. (3, 9) cumple las dos. El otro corte, (−1, 1), también vale: (−1)2 = 1 y 2 · (−1) = −2
−2 + 3 = 1. Las dos ecuaciones dan 1, así que esa pareja está en la parábola y en la recta. El sistema no pedía x positiva, y por eso no se tira.

Comprueba · (−1, 1)

Por qué: (−1)2 = 1 y 2 · (−1) = −2
−2 + 3 = 1. No se tira por ser negativa la abscisa: el sistema no pedía x > 0.

Comprueba · (1, 1) y (3, 3)

Por qué: 1 + 1 = 2 ≤ 4, así que (1, 1) está en los tres semiplanos. 3 + 3 = 6 > 4, así que (3, 3) no.

Cierre

En la recta y la parábola, sustituir deja una ecuación de segundo grado: aquí dos puntos, los dos válidos. En las inecuaciones lineales, la solución es la región común de los semiplanos, comprobada con puntos.

Reto

Un punto del borde

Comprueba si (2, 2) cumple las tres inecuaciones. Después di si (2, 2) es solución del sistema de ecuaciones de la parábola y la recta: calcula 22 y 2·2 + 3.
