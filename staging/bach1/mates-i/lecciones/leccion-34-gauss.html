El método de Gauss con tres incógnitas

1º Bachillerato Matemáticas I · Ciencias y Tecnología

Saberes (Decreto 40/2022): resolución de sistemas de ecuaciones lineales con tres incógnitas mediante el método de Gauss (sentido algebraico).

Objetivos

  1. Triangular un sistema 3×3 con el método de Gauss y leer la solución por remontado.
  2. Comprobar la solución en las tres ecuaciones de partida.
  3. Reconocer, en un sistema pequeño aparte, qué significa una fila 0 = 1 y una fila 0 = 0.

Explicación

El sistema de esta lección

x + y + z = 6
2x − y + z = 3
x + 2y − z = 2

La matriz ampliada junta los coeficientes y el término independiente:

Triangular

Se anulan los coeficientes de debajo del pivote. El pivote es el coeficiente con el que se elimina. Conviene que sea 1, o al menos distinto de cero: si el pivote natural es cero o incómodo, se intercambian filas. Eso es pivotar.

  1. F2 ← F2 − 2·F1. Coeficientes:
    2−2 = 0
    −1−2 = −3
    1−2 = −1, término 3−12 = −9. Queda 0, −3, −1 | −9.
  2. F3 ← F3 − F1. Coeficientes: 0,
    2−1 = 1
    −1−1 = −2, término 2−6 = −4. Queda 0, 1, −2 | −4.
  3. Pivotar: se intercambian la segunda y la tercera fila para que el pivote de la columna y sea 1, no −3.
    1   1   1   |   6
    0   1   −2   |   −4
    0   −3   −1   |   −9
  4. F3 ← F3 + 3·F2. Columna y: −3 + 3 = 0. Columna z: 3 · (−2) = −6
    −1 + −6 = −7. Término: 3 · (−4) = −12
    −9 + −12 = −21.
    1   1   1   |   6
    0   1   −2   |   −4
    0   0   −7   |   −21

Remontar

  1. −7z = −21, z = 3.
  2. y − 2z = −4, y − 6 = −4, y = 2.
  3. x + y + z = 6, x + 2 + 3 = 6, x = 1.

Solución única: x = 1, y = 2, z = 3.

Comprobación en las tres ecuaciones

  • 1 + 2 = 3
    3 + 3 = 6.
  • 2 · 1 = 2
    2 − 2 = 0
    0 + 3 = 3.
  • 2 · 2 = 4
    1 + 4 = 5
    5 − 3 = 2.

Qué dirían otras filas

Una fila 0 = 1 (todo coeficiente cero y término distinto de cero) hace el sistema incompatible: no hay solución. Ejemplo aparte, ya comprobado: x + y = 1 y x + y = 2. Al restar, 0 = 1. No existe un par que valga 1 y 2 a la vez.

Una fila 0 = 0 no aporta condición: sobra, y puede haber infinitas soluciones. Ejemplo aparte: x + y = 3 y 2x + 2y = 6. La segunda es el doble de la primera; al restar 2·F1 queda 0 = 0. Las soluciones son x = t, y = 3 − t. Comprueba: t + (3 − t) = 3 y 2t + 2(3 − t) = 6.

Glosas de esta lección

Matriz ampliada Coeficientes y términos independientes en una tabla. Cada fila es una ecuación.

Pivote Coeficiente que se usa para anular los de debajo en su columna. Si estorba, se cambia la fila.

0 = 1 Fila imposible. El sistema no tiene solución.

0 = 0 Fila redundante. No añade información; puede quedar un parámetro libre.

Ejemplo 2 · Los dos avisos, en sistemas de dos ecuaciones

  1. x + y = 1, x + y = 2. Resta: 0 = 1. Incompatible.
  2. x + y = 3, 2x + 2y = 6. F2 − 2·F1: 0 = 0. Para cada t, (t, 3 − t) es solución. Con t = 1: (1, 2), y 1 + 2 = 3, 2 + 4 = 6.

Error típico

Operar los coeficientes y olvidar el término independiente, o no remontar y dar por solución la última fila sola.

Corrección: F2 − 2·F1 cambia también el 3:
2 · 6 = 12
3 − 12 = −9, no 3. Y −7z = −21 da z
−21 da z = 3, pero y y x salen después: y = 2, x = 1. Si solo se dice «z = 3» faltan las otras dos incógnitas. La comprobación 1 + 2 = 3
3 + 3 = 6 caza ese descuido.

Práctica

Avanza los pasos de la triangularización. El dibujo marca la fila en la que estás. Copia la solución y sustitúyela en el editor.

Sistema de partida.

Comprueba

Comprueba · 1 + 2 + 3

Por qué: 1 + 2 = 3
3 + 3 = 6. La primera ecuación se cumple con la solución remontada, y hay que comprobarla en el sistema de partida, no solo en la triangular: al remontar se puede arrastrar un signo. x = 1, y = 2 y z = 3 salen de −7z = −21 y de las filas de encima; volver a x + y + z = 6 confirma que ese remontado no ha cambiado el problema. Si la suma no fuera 6, la triangular y el sistema original se habrían separado.

Comprueba · 2x − y + z

Por qué: 2 − 2 = 0
0 + 3 = 3. La segunda también. El menos de y no se pierde: −y con y = 2 es −2.

Comprueba · la fila −7z = −21

Por qué: −21/−7 = 3, y al sustituir y = 2, x = 1 la tercera ecuación da 1 + 4 = 5
5 − 3 = 2. El pivote −7 no es cero: hay solución única.

Cierre

Gauss triangulariza, pivotando si hace falta, y se remonta. Este sistema da x = 1, y = 2, z = 3, y las tres ecuaciones lo confirman. 0 = 1 es imposible; 0 = 0 es una fila que no informa.

Reto

Sin mirar la triangular

Sustituye x = 1, y = 2, z = 3 otra vez, pero en desorden: empieza por la tercera ecuación. Después explica en una frase por qué x + y = 1 junto con x + y = 3 no se podría remontar.
