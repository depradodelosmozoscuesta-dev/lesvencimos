El logaritmo como exponente

Sentido numérico: logaritmos, su comprensión y su uso para simplificar y resolver problemas. Decreto 40/2022, Castilla y León.

Objetivos

  • Leer un logaritmo como el exponente que hay que poner a la base.
  • Usar el producto, el cociente y la potencia de logaritmos sin romper la definición.
  • Cambiar de base cuando las dos bases se entienden en una tercera.
  • Resolver un problema corto cuya incógnita es un exponente, y comprobarlo con la potencia inversa.

Explicación

El decreto pide comprender el logaritmo y usarlo para simplificar y resolver problemas. Aquí el logaritmo no es una tecla: es el nombre del exponente. Si la base está clara y el argumento es una potencia de esa base, el resultado es un entero y se puede revisar multiplicando.

Definición

logb a = c significa, por definición, que bc = a. Hace falta b > 0, b ≠ 1 y a > 0. No se define el logaritmo de 0 ni el de un negativo en los reales. Ejemplos directos: log2 8 = 3 porque 23 = 8; log2 32 = 5 porque 25 = 32; log3 81 = 4 porque 34 = 81; log9 81 = 2 porque 92 = 81.

En este curso, log sin base escrita significa logaritmo decimal, base 10, y ln significa logaritmo neperiano, base e. No hace falta el valor decimal de e para los ejercicios de esta lección: usaremos identidades exactas. Así log 100 = 2 porque 102 = 100, log 1000 = 3 porque 103 = 1000, y log 10 = 1. También ln e = 1 y ln 1 = 0, porque e1 = e y cualquier base positiva distinta de 1 elevada a 0 vale 1, así que logb 1 = 0.

Propiedades que salen de la definición

Si los logaritmos existen, el logaritmo de un producto es la suma de logaritmos: logb(xy) = logb x + logb y. La razón es que los exponentes se suman cuando las bases iguales se multiplican. El logaritmo de un cociente es la resta: logb(x/y) = logb x − logb y. El logaritmo de una potencia es el exponente por el logaritmo: logb(xn) = n logb x.

Estas igualdades no se extienden a una suma dentro del logaritmo. logb(x + y) no es logb x + logb y. El error está más abajo, con números.

Cambio de base

Si c es otra base válida, logb a = logc a / logc b. En particular logb a = ln a / ln b = log a / log b. No es una fórmula para decorar: sirve cuando conoces los logaritmos en una base y quieres otra. Comprobación con enteros: log9 81 = log3 81 / log3 9
log3 81 / log3 9 = 4 / 2
4 / 2 = 2, y ya sabíamos que 92 = 81.

Un problema

Una cantidad se duplica cada hora, de forma exacta, a partir de 1 unidad. Se pregunta cuántas horas hacen falta para llegar a 64 unidades. La ecuación es 2n = 64. Por definición, n = log2 64. Como 64 = 26, n = 6. Comprobación: 26 = 64. No hay dato experimental inventado: es el modelo «se duplica», traducido a un exponente.

Glosa de los símbolos de esta lección

logb a
Logaritmo en base b de a: el exponente c tal que bc = a. Exige a > 0, b > 0 y b ≠ 1.
log
En este curso, logaritmo decimal: log a = log10 a. Así log 100 = 2.
ln
Logaritmo neperiano: ln a = loge a. ln e = 1 y ln 1 = 0.
e
Base del neperiano, real positivo distinto de 1. Aquí no se sustituye por un decimal.
bc
La potencia que define al logaritmo: si logb a = c, entonces bc = a.

Ejemplo 1, paso a paso

log2 8 + log2 32

  1. log2 8 = 3, porque 23 = 8.
  2. log2 32 = 5, porque 25 = 32.
  3. Suma: 3 + 5 = 8.
  4. Por la propiedad del producto, esa suma es log2(8 · 32) = log2 256.
  5. 8 · 32 = 256 y 28 = 256, así que log2 256 = 8. Cuadra.

Resultado: 8.

Ejemplo 2, paso a paso

log2 48 − log2 3, y un cambio de base

  1. Propiedad del cociente: log2 48 − log2 3 = log2(48 / 3).
  2. 48 / 3 = 16.
  3. 16 = 24, luego log2 16 = 4.
  4. Cambio de base aparte, para fijar la fórmula: log9 81 = log3 81 / log3 9.
  5. log3 81 = 4 porque 34 = 81. log3 9 = 2 porque 32 = 9. Cociente 4 / 2 = 2, y 92 = 81.

Resultados: la resta vale 4 y log9 81 vale 2.

Error típico, corregido

Se reparte el logaritmo sobre una suma: log2(4 + 4) = log2 4 + log2 4. El lado izquierdo es log2 8 = 3, porque 4 + 4 = 8 y 23 = 8. El lado derecho es 2 + 2 = 4, porque log2 4 = 2. 3 ≠ 4.

La suma de logaritmos corresponde a un producto, no a una suma: log2 4 + log2 4 = log2(4 · 4)
log2(4 · 4) = log2 16
log2 16 = 4. El 4 del lado derecho sí cuadra con el producto.

En la vida real

Contar duplicaciones, no «la mitad del número»

Pasar de 1 a 64 duplicando no son 32 pasos «porque 64 es el doble de 32». Son 6, porque cada paso multiplica por 2 y 26 = 64. El logaritmo cuenta los pasos. Lo mismo vale para cualquier base exacta: si algo se multiplica por 10, log 1000 = 3 dice que han hecho falta tres factores de 10.

Comprueba

Calcula log2 16.

Respuesta: 4, porque 24 = 16.

Por qué: la definición pide el exponente.2 · 2 = 4
4 · 2 = 8
8 · 2 = 16, así que el exponente es 4 y no hace falta una cifra decimal.

Calcula log3 9 + log3 3.

Respuesta: 2 + 1 = 3, que es log3 27.

Por qué: 32 = 9 y 31 = 3. La suma de logaritmos es el logaritmo del producto: 9 · 3 = 27
27 = 33.

¿Cuánto valen log 10 y ln 1?

Respuesta: log 10 = 1 y ln 1 = 0.

Por qué: 101 = 10, y cualquier base válida elevada a 0 vale 1, luego el logaritmo de 1 es 0 también en base e.
