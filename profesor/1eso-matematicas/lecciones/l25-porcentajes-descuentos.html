Porcentajes: cálculo y problemas

Etiquetas de rebajas · % de · aumentos · descuentos encadenados

🏷️💥

El símbolo % significa «por ciento» = de cada 100. Descuento 20 % → pagas el 80 % (×0,8). ¡Ojo con encadenar % sobre bases distintas!

🎛️ Situación

Controles independientes: precio, porcentaje y (si aplica) segundo descuento. Elige el modo; la etiqueta de tienda se actualiza sola.

Truco mnemotécnico

% = por ciento = de cada 100. Descuento p % → ×(1 − p/100). Encadenados: ¡paso a paso!

📖 Glosario rápido

% por ciento
De cada 100. Ejemplo: 25 % = 25/100 = 1/4.
p% de N
(p/100)×N. El 15 % de 240 = 0,15×240 = 36.
Descuento / aumento
Dto p % → ×(1−p/100). Aumento p % → ×(1+p/100).
Base del %
Siempre pregunta: ¿% de qué? El segundo descuento actúa sobre el precio ya rebajado.
