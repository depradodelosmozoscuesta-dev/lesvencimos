La recta de los enteros

Termómetro, ascensor y fichas para ver negativos, opuestos y orden

🌡️🛗

En Ávila hace frío bajo cero y el garaje está en la planta −1. Los enteros viven en una recta: a la derecha crecen, a la izquierda bajan. El 0 es el origen (planta baja / punto de congelación).

🎛️ Elige a y b (independientes)

Cambiar a no mueve b. Rango −12…12 (legible en la recta).

a, b = enteros que colocas − = menos / negativo + = más / positivo |a| = valor absoluto < / > = menor / mayor

🌡️ Termómetro (°C) — invierno en CyL
—
Bajo 0 °C = negativo (hielo). Por encima de 0 = positivo (deshielo).

📖 Glosario de símbolos y letras

a, b
Enteros que eliges (controles independientes).
− (menos)
Signo negativo o la operación «restar». En −5 se lee «menos cinco» o «cinco negativo».
+ (más)
Signo positivo (a veces se omite: +3 = 3) o la operación «sumar».
0
Origen: ni positivo ni negativo. Planta baja / 0 °C.
−a (opuesto)
El número simétrico respecto al 0. Opuesto de 4 → −4; de −4 → 4.
|a| (valor absoluto)
Distancia de a al 0 (siempre ≥ 0). |−7| = 7.
< / >
«Menor que» / «mayor que». Quien está más a la derecha en la recta es mayor: −10 < −3.
ℤ (enteros)
…, −2, −1, 0, 1, 2, … Naturales + cero + negativos.
