Truco mnemotécnico

«% = por ciento = de cada 100. Decimal → %: ×100. % → decimal: ÷100.»

📖 Letras y símbolos (en español)

% «por ciento»
Significa de cada 100. Ejemplo: 25 % = 25 de cada 100 = 25/100 = 1/4.
Fracción a/b
Parte de un todo. Para pasar a decimal: divide a ÷ b. Para %: (a÷b)×100.
Decimal (coma ,)
En España: 0,25. De decimal a %: multiplica por 100 (0,25 → 25 %).
p% = p/100
Definición. 100 % = el todo (1). 50 % = la mitad.
Atajos mentales
10 % = ÷10; 5 % = mitad del 10 %; 25 % = ÷4; 50 % = ÷2; 75 % = 50 %+25 %.
Error típico
Escribir 0,5 % cuando querías 50 % (confundir el decimal con el porcentaje).
