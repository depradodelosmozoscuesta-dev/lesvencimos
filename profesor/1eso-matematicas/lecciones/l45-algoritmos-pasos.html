Lección 45 · UD14 Pensamiento computacional

Algoritmos: interpretar y modificar

Pasos claros · probar · depurar · pedir ayuda sin drama

🧩

Un algoritmo es una lista finita de pasos claros (como una receta o el camino al instituto). Aquí verás las instrucciones en tarjetas numeradas — no un lío de flechas. Prueba con números, encuentra el fallo si lo hay, y cámbialo para un objetivo nuevo. Si te atascas: revisa el paso o pregunta; depurar es normal.

Taller de algoritmos (tarjetas)

Controles independientes: entradas a, b (y c), paso activo. Las tarjetas son el diagrama — claras, no spaghetti.

Lee las tarjetas · elige entradas · ejecuta paso a paso.

Letras y símbolos (en español)

Algoritmo = secuencia finita de pasos claros para una tarea.
Entrada = datos que das al empezar (a, b, c…).
Salida = resultado que escribe al terminar.
SI … ENTONCES … SI NO … = decisión (condicional).
MIENTRAS / REPETIR HASTA = repetición con condición de parada.
Depurar = probar con un ejemplo, ver dónde falla, corregir el paso (no a la persona).
«Entrada clara · pasos numerados · prueba con un ejemplo · si falla, mira el paso · pide ayuda si hace falta.»
Vida real: receta de cocina, protocolo de evacuación del centro, pasos para pagar con QR, camino al instituto en tu provincia.
Cuando un paso no cuadra, prueba con un ejemplo o pregunta: «¿me miras el paso 3?». Depurar juntos es normal; no hace falta acertar a la primera.
Error típico: pasos ambiguos («hazlo bien») · bucles sin final · asumir datos no leídos.
