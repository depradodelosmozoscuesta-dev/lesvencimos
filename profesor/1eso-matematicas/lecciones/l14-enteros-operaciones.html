Saltos en la recta

Sumar, restar, multiplicar y dividir enteros · operaciones inversas

🦘

Imagina un saltamontes en la recta: sumar es saltar a la derecha (o a la izquierda si sumas negativo). Restar es sumar el opuesto: a − b = a + (−b). En producto y división, la regla de signos decide el resultado.

🎛️ Elige a, b y la operación (independientes)

Cada control mueve solo su valor. Cambiar a no reescala b.

a, b = enteros (−9…9) + suma · − resta × producto · ÷ división −b = opuesto de b

🦘 La operación como movimiento

Para + y −: partes de a y saltas |b| unidades. Naranja = salto a la derecha; rosa = a la izquierda.

📏 Recta de saltos (−18…18)

✖️➗ Regla de signos (producto / división)

Signos iguales → resultado positivo. Signos distintos → resultado negativo.

(+)×(+) → +
Dos positivos: resultado positivo.
(−)×(−) → +
Dos negativos: ¡también positivo!
(+)×(−) → −
Distintos: resultado negativo.
(−)×(+) → −
Distintos: resultado negativo.
Truco mnemotécnico

«Restar es sumar el opuesto. Amigos (+ + / − −) → + ; enemigos → −.»

↩️ Comprueba con la inversa

Toda operación tiene una inversa que te devuelve al punto de partida.

📖 Glosario de símbolos y letras

a, b
Los dos enteros de la operación (controles independientes).
+
«Más / sumar». En la recta: salto en el sentido del segundo sumando.
−
«Menos / restar» o signo negativo. a − b = a + (−b).
×
«Por / multiplicar».
÷
«Dividido entre». Si b = 0, no se puede dividir.
−b
Opuesto de b: el «espejo» respecto al 0.
=
«Vale lo mismo».
Inversa
Operación que deshace la anterior: sumar 5 se deshace restando 5; ×(−3) se deshace ÷(−3).
