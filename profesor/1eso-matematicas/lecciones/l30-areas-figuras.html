Lección 30 · UD9 Medida en el plano

Áreas de figuras planas elementales

Deducción desde el rectángulo + aplicación · A, b, h, L, B glosadas

▭

El rectángulo es la base: A = b × h. El triángulo es medio rectángulo; el paralelogramo se «endereza» a rectángulo; el trapecio usa la media de las dos bases. El dibujo muestra la deducción (rectángulo fantasma), no un charco de color sin significado.

Controles independientes: mover la base no encoge la altura en pantalla (escalas X e Y separadas). La altura es siempre la perpendicular a la base — no el lado oblicuo.

Cálculo

—
Perímetro ≠ área: el perímetro es el contorno (u); el área es la superficie (u²). Si mezclas m y cm, convierte antes.

Letras y símbolos (léelos siempre en español)

A = área → superficie interior de la figura (unidades cuadradas: cm², m²…).
b = base → lado sobre el que «apoyas» la figura.
h = altura → segmento perpendicular a la base (no un lado inclinado).
L = lado del cuadrado (A = L × L = L²).
B = base mayor del trapecio · b = base menor.
P = perímetro → longitud del contorno (no confundir con A).
Rectángulo / paralelogramo: A = b × h. Triángulo: A = ½ × b × h. Trapecio: A = ½ × (B + b) × h.
🧠 Truco: «Todo nace del rectángulo. Triángulo = mitad. Paralelogramo = mismo b×h. Trapecio = media de bases × altura.»
