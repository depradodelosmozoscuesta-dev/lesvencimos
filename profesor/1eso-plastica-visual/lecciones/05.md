# Lección 05 — El lenguaje visual como comunicación

**Curso:** 1º ESO Educación Plástica, Visual y Audiovisual · Jorge
**Bloque / viñetas:** 1º ESO EPVA · Decreto 39/2022 CyL · B1

---

## Objetivos

1. Imagen como **comunicación**.
2. Informar / expresar / persuadir.
3. Leer en 3 pasos.
4. Pictograma o cartel mínimo.

## Explicación

**Lenguaje visual** = formas, colores, símbolos, composición.

3 pasos: qué veo · qué me dice · a quién / para qué.

## Práctica

Señal o anuncio + pictograma propio.

## Glosario

| Término | Significado |
|---------|-------------|
| **Lenguaje visual** | Sistema de signos e imágenes |
| **Mensaje visual** | Lo que transmite la imagen |
| **Informar / expresar / persuadir** | Dato / emoción / convencer |
| **Pictograma** | Dibujo simplificado |

## Mini quiz

**Pregunta:** Un pictograma de «salida de emergencia» busca sobre todo…

A) Expresar la tristeza del diseñador.
B) Persuadirte para comprar un producto.
C) Informar con claridad una acción o dirección.
D) Contar una novela sin palabras.

**Respuesta correcta:** C

*Porqué:* La señalética prioriza informar con claridad.
