Lección 05 · Bloque B · Lenguaje visual

El lenguaje visual como comunicación

1º ESO EPVA · Decreto 39/2022 CyL · B1

Hoja 1 · Objetivos

Objetivos

  1. Entender la imagen como comunicación.
  2. Distinguir si informa, expresa o persuade.
  3. Leer un mensaje visual en 3 pasos.
  4. Crear un pictograma o cartel mínimo en papel.

Hoja 2 · Explicación

La imagen habla

El lenguaje visual comunica con formas, colores, símbolos y composición.

  • Informar — dato claro (señal, pictograma).
  • Expresar — sentimiento o visión personal.
  • Persuadir — intentar que hagas o pienses algo (anuncio).

Leer un mensaje (3 pasos)

  1. Qué veo
  2. Qué me dice
  3. A quién / para qué

Hoja 3 · Práctica y glosario

Práctica

  1. Señal, anuncio o portada → 3 pasos.
  2. Pictograma (baño, silencio, reciclaje): máx. 3 formas.

Glosario

  • Lenguaje visual — sistema de signos e imágenes.
  • Mensaje visual — lo que transmite la imagen.
  • Informar / expresar / persuadir — dato / emoción / convencer.
  • Pictograma — dibujo simplificado de una idea.
