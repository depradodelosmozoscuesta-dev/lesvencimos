## Explicación

Las rocas no están «fijas para siempre». Procesos geológicos las transforman:

- Magma **enfría** → ígnea  
- Ígnea (u otras) se **rompe/erosiona** → sedimentos → **sedimentaria**  
- Con **presión y temperatura** → **metamórfica**  
- Si **funde** → magma otra vez  

### Mnemónico

**«Enfría · Rompe · Enterra · Aprieta · Funde»**

### Más ejemplos de caminos

1. Magma → granito (ígnea) → erosión → arena → arenisca (sedimentaria).
2. Caliza (sedimentaria) → mármol (metamórfica).
3. Pizarra (metamórfica) → (en profundidad, con fusión) → magma → basálto/ígnea otra vez.

No hay un único círculo obligatorio: hay **muchas rutas**.

### El ciclo (animación mental)

Magma → ígnea → erosión → sedimentos → sedimentaria → presión/calor → metamórfica → fusión → magma.

Las flechas del interactivo muestran que el cambio es lento (tiempo geológico) y que hay **rutas alternativas**, no un único círculo rígido.

## Errores frecuentes

- Pensar que el ciclo es un círculo único obligatorio (hay muchos caminos).
- Olvidar el magma como nodo.
