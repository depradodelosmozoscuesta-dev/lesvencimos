## Explicación

### Objetivos de las Ciencias Sociales (idea 1º ESO)

1. **Entender el mundo** — dónde ocurren las cosas (Geografía) y cuándo/por qué cambiaron (Historia).  
2. **Pensar con pruebas** — fuentes, datos, mapas; no solo opiniones.  
3. **Convivir mejor** — ciudadanía, respeto, cuidado del planeta (puente al bloque C).

### Términos que ya has usado (y debes dominar)

| Término | Recuerdo rápido |
|---|---|
| Espacio | Dónde |
| Tiempo | Cuándo / duración |
| Escala | Relación mapa/realidad (L01) |
| Fuente | De dónde sale el dato (L09) |
| Causa / efecto | Por qué / qué pasó después |
| Ecosistema | Red de vida + medio (L08) |
| Clima / tiempo | Habitual / hoy (L05) |

### Estrategias (procedimientos)

Observar → preguntar → localizar en el mapa → buscar fuente → contrastar → explicar con vocabulario preciso → comunicar (oral, mural, plataforma).

### Plataformas digitales

Entornos del colegio (aula virtual), mapas TIG, carpetas compartidas… Sirven para **organizar y compartir** conocimiento con **normas de uso seguro** (L09).  
No sustituyen siempre al cuaderno ni al museo: se complementan.

## Ejemplos resueltos

**1.** «El Duero es un océano» — error de término (es río).  
**2.** Subir un mapa sin citar escala/fuente — mal procedimiento.  
**3.** Usar la plataforma solo para copiar-pegar sin leer — no cumple el objetivo de pensar con pruebas.

## Errores frecuentes

- Creer que CC.SS. es «solo memorizar fechas» (en 1º hay mucho mapa y reto actual).
- Usar términos de oídas («como un clima tropical en León») sin contraste.
- Tratar la plataforma como red social sin reglas.
