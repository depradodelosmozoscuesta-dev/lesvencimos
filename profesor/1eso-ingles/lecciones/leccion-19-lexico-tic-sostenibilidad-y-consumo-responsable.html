Léxico: TIC, sostenibilidad y consumo responsable

1º ESO Inglés · CyL Decreto 39/2022 · bloque A · léxico: TIC; sostenibilidad y consumo responsable

Objetivos

  1. Nombrar TIC básicas: phone, laptop, tablet, computer, internet, email, password, app, message, screen.
  2. Usar léxico de sostenibilidad: recycle, reuse, save water/energy, turn off, rubbish/bin, plastic, planet.
  3. Hablar de consumo responsable: buy less, use a bottle, walk or bus (opciones de aula).
  4. Escribir 6 frases que mezclen una TIC segura y una acción sostenible.

Explicación

El decreto une TIC con sostenibilidad y consumo responsable. Set A1–A2 de aula.

TIC

  • *phone, smartphone, laptop, tablet, computer*
  • *internet, Wi‑Fi, email, message, app*
  • *password, screen, keyboard*
  • *search, download* (verbos básicos)
  • *screen time* (tiempo de pantalla)

Seguridad de aula: *Don't share your password. Ask before you download.*

Sostenibilidad y consumo

  • *recycle, reuse*
  • *save water / save energy*
  • *turn off the lights / the tap*
  • *bin / rubbish*
  • *plastic, paper, glass*
  • *planet, environment* (palabra larga: se glosa)
  • *buy less, use a bottle again*

Frases

  • *I send a message on my phone.*
  • *We recycle paper at school.*
  • *Turn off the lights. Save energy.*

Mnemónico

«Phone + password privado. Recycle, reuse, save water. Turn off the lights.»

Glosas de esta lección

  • phone / laptop / tablet. teléfono / portátil / tableta.
  • password. contraseña (no se comparte).
  • app / message / email. aplicación / mensaje / correo.
  • screen time. tiempo de pantalla.
  • recycle / reuse. reciclar / reutilizar.
  • save water / energy. ahorrar agua / energía.
  • turn off. apagar (luces, grifo: turn off the tap).
  • bin / rubbish. papelera / basura.
  • plastic / paper / glass. plástico / papel / vidrio.

Ejemplos resueltos

Ejemplo 1 — Burgos · TIC

I use a laptop at school. I send a message on my phone. I don't share my password.

Ejemplo 2 — Reciclar

We recycle paper and plastic. There is a bin in every classroom.

Ejemplo 3 — Ahorrar

Turn off the lights. Save water. Use your bottle again.

En la vida real

Castilla y León

  • Normas de pantalla en el aula de Burgos: password y screen time.
  • Puntos de reciclaje del centro: paper / plastic / glass.
  • Cartel: *Turn off the lights. Save energy.*
  • Pareja: una frase TIC segura + una sostenible.
