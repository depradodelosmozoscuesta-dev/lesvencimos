Recursos de aprendizaje y búsqueda

1º ESO Inglés · CyL Decreto 39/2022 · bloque A · recursos para el aprendizaje y estrategias básicas de búsqueda

Objetivos

  1. Nombrar recursos: dictionary, library, reference book, digital resource, app.
  2. Usar una estrategia simple de búsqueda (palabra → ejemplo → anotar).
  3. Distinguir diccionario bilingüe y monolingüe sencillo.
  4. Elegir biblioteca/libro de consulta frente a «adivinar sin mirar» cuando hace falta.

Explicación

El decreto lista diccionarios (cualquier soporte), libros de consulta, bibliotecas, recursos digitales, herramientas y apps. No nombra marcas: trabajamos tipos y una estrategia.

Tipos de recurso

RecursoPara qué
Dictionary (papel o digital)Significado, ejemplo, categoría
Bilingual ES↔ENPuente rápido 1º
Monolingual (EN sencillo)Definición en inglés muy fácil
LibraryLibros, revistas, espacio de consulta
Reference bookGramática/consulta de aula
App / digital resourcePráctica guiada, audio, flashcards

Estrategia de búsqueda (básica)

  1. ¿Qué necesito? (palabra / dato)
  2. Busco en el recurso adecuado.
  3. Leo el ejemplo, no solo la glosa.
  4. Anoto en el cuaderno (analógico) o lista digital.

Cuidado

*Library* = biblioteca. No es *librería* (bookshop). Eso se retoma en L30 (falsos amigos).

Mnemónico

«Look it up. Dictionary + example. Library ≠ bookshop. App ayuda, no sustituye pensar.»

Glosas de esta lección

  • dictionary. diccionario (papel o digital).
  • bilingual dictionary. diccionario ES↔EN.
  • monolingual dictionary. definiciones en inglés sencillo.
  • library. biblioteca (lugar de consulta/préstamo).
  • reference book. libro de consulta (gramática, atlas…).
  • digital resource. recurso digital de aprendizaje.
  • app. aplicación móvil o web educativa.
  • look it up. búscalo (en el diccionario/recurso).
  • search. buscar información con un plan.
  • example sentence. frase de ejemplo: léela siempre.
