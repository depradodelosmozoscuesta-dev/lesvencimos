Lección 39 · Cierre · proyecto A+B+C

Proyecto integrador del curso

1º ESO Inglés · CyL Decreto 39/2022 · integración · proyecto que combina comunicación, plurilingüismo e interculturalidad (sin volcado nuevo de gramática)

Objetivos

  1. Planificar un producto breve que integre bloques A, B y C.
  2. Reutilizar lengua ya vista (A1–A2): sin volcado nuevo de gramática.
  3. Incluir una estrategia plurilingüe (B: paraphrase, cognate check, diary line…).
  4. Incluir un elemento intercultural (C: costumbre, mapa, cortesía, diversidad…).

Explicación

L39 no es un tema gramatical nuevo. Es el proyecto integrador del curso: un producto que demuestra comunicación (A) + plurilingüismo (B) + interculturalidad (C).

Productos posibles (elige uno)

  • Mini-presentación oral (1–2 min) + cartel
  • Mini-podcast / audio (offline)
  • Dossier de 2 páginas (texto + dibujo)
  • Mural de grupo + guion hablado

Checklist mínimo

BloqueEvidencia en el producto
AMensaje claro: saludo, info, gusto, pasado simple… (del curso)
BEstrategia: *How do you say…?*, cognado/falso amigo, línea de diario *I can…*
CCultura/respeto: costumbre, mapa, please, diversity, *That's not OK*…

Pasos del proyecto

  1. Choose topic (travel, school day, festival, exchange…).
  2. Plan (quién hace qué).
  3. Draft in English A1–A2.
  4. Check (peer + glossary).
  5. Present / share.
  6. Reflect (puente a L40).

Gramática nueva fuera de temario = fuera de L39.

Mnemónico

«A mensaje · B estrategia · C cultura/respeto. Elige producto. Reutiliza el curso. Sin grammar dump.»

Glosas de esta lección

  • project / product. proyecto / producto final.
  • integrate / integration. integrar / integración de bloques.
  • checklist. lista de comprobación.
  • draft / check / present. borrador / revisar / presentar.
  • communication (A). bloque A: comunicar con claridad.
  • plurilingualism (B). bloque B: estrategias y comparación entre lenguas.
  • interculturality (C). bloque C: cultura, respeto, diversidad.
  • I can…. puedo… (autoeval breve, L28).
  • peer check. revisión entre iguales.
  • no new grammar dump. sin volcar gramática nueva fuera de curso.

Ejemplos resueltos

Ejemplo 1 — A

Hello! We present our school day in Valladolid. Yesterday we visited a museum.

Ejemplo 2 — B

Cognate: animal. False friend: library = biblioteca. How do you say «horario»?

Ejemplo 3 — C

In Ireland some schools wear uniform. We respect different accents.
