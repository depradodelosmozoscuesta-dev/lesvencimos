Léxico: identificación personal y relaciones

1º ESO Inglés · CyL Decreto 39/2022 · bloque A · léxico de uso común: identificación personal y relaciones interpersonales

Objetivos

  1. Usar léxico de identificación: name, age, boy/girl, student.
  2. Nombrar relaciones: mother, father, parents, sister, brother, family, friend, classmate.
  3. Decir I've got… / This is my… para presentar relaciones.
  4. Completar una mini ficha personal en inglés A1–A2 sin inventar datos sensibles de verdad si no quieres.

Explicación

El decreto pide léxico de uso común de identificación personal y relaciones interpersonales. No lista palabras cerradas: aquí va un set A1–A2 de aula. Si hace falta ampliar, se anota en dudas.

Identificación

  • *name, surname* (nombre, apellido)
  • *age* — *I'm 12. I'm twelve years old.*
  • *boy / girl / student*
  • *My name is… I'm from…* (repaso útil de L04)

Relaciones

  • *mother, father, parents*
  • *sister, brother*
  • *family*
  • *friend, best friend*
  • *classmate* (compañero/a de clase; no es lo mismo que *friend*)
  • *neighbour* (vecino/a)
  • *only child* (hijo/a único/a)

Frases modelo

  • *This is my sister.*
  • *I've got one brother.*
  • *She's my classmate and my friend.*

Mnemónico

«Name + age. Parents = mother + father. Classmate ≠ friend siempre.»

Glosas de esta lección

  • name / surname. nombre / apellido.
  • age. edad: I'm 12.
  • parents. padre y madre juntos.
  • sister / brother. hermana / hermano.
  • friend. amigo/a.
  • classmate. compañero/a de clase.
  • neighbour. vecino/a.
  • only child. hijo/a único/a.
  • I've got…. tengo (relación/persona): I've got two sisters.

Ejemplos resueltos

Ejemplo 1 — Ficha Soria

My name is Hugo. I'm 12. I've got one sister. This is my friend Lucía. She's my classmate.

Ejemplo 2 — Familia

These are my parents. I haven't got a brother. I'm an only child.

Ejemplo 3 — Vecino

My neighbour is friendly. He's not my classmate.

En la vida real

Castilla y León

  • Primera semana en Soria: ficha *My name / age / I've got…*.
  • Presentar a un compañero en Burgos: *This is my classmate.*
  • Mapa familiar simple: parents, sister/brother, without datos privados de más.
  • Pareja: adivinar si la frase habla de *friend* o *classmate*.
