# viajero-pradera

Outfit demo **Viajero de la pradera** (Arte Ropa / VitaInk).

- Estilo: aventura pintada (BOTW-like), legible en móvil
- Iluminación: día
- Capas: camisola lino, mangas cortas, pantalón corto verde pradera, botas de cuero, capa corta (opcional)
- Solo ropa (sin piel / cara / cuerpo)
- Anclas: ver `placement.json` y `docs/ANCLAJES.md`
- Generado: 2026-09-18 02:29 Europe/Madrid (pintura procedural RGBA; GenerateImage no disponible en este executor)

Colores: lino `#F5E6C8`/`#E8D4A8`, pantalón `#7CB342`–`#558B2F`, botas `#5D4037`/`#8D6E63`.
