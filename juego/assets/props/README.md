# VitaInk art props (lote 1) / Props interactuables VitaInk

**Package root:** `/workspace/vitaink-art-props/`  
**Copy target (RCV):** `web/vitaink/sprites/props/` inside Red-ciudadano-valladolid.

## Qué incluye
PNG RGBA (alpha), estilo aventura pintada inspirado en Breath of the Wild, siluetas claras, sin personajes.

| ID | ES | lighting |
|---|---|---|
| `prop_chest_closed` | Cofre cerrado | day |
| `prop_chest_open` | Cofre abierto | day |
| `prop_shrine_tower` | Santuario / torre mirada | day |
| `prop_campfire_day` | Fogata | day |
| `prop_campfire_night` | Fogata glow | night |
| `prop_grass_cuttable` | Hierba cortable | day |
| `prop_ore_shiny_day` | Mineral brilloso | day |
| `prop_ore_shiny_night` | Mineral glow | night |
| `prop_sign_wood` | Cartel de madera | day |
| `prop_bridge_short` | Puente corto | day |
| `prop_door_ruin` | Puerta de ruina | day |

Escala coherente con avatares Mari (~512×768 front). Paleta compartida: `vitaink-sprites-mari/world/palette.json`.
