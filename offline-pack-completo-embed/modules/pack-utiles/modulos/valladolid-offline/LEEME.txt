VALLADOLID OFFLINE — Les vencimos
═══════════════════════════════════
Mapa vectorial detallado (calles + POI) del área
metro de Valladolid. Sin internet al abrir.
YA INCLUIDO en Completo / pack-útiles (sin descargar).

Contenido
  ABRE-AQUI.html   → abre el mapa (file://)
  mapa.html        → igual
  data.geojson     → calles / ríos / ferrocarril / POI (OSM)
  vendor/          → Leaflet 1.9.4 (sin CDN)

Cobertura
  Bbox meta ≈ lat 41.52–41.78, lon −4.95–−4.55
  (~16 600 features OSM; núcleo ciudad + anillo metro)
  Zooms útiles ≈ 10–16

UX
  Capas (calles / agua / rail / POI / lugares)
  Búsqueda calles+POI con sugerencias
  Filtros: farmacias, salud, gasolineras, supers, colegios, turismo
  Botón GPS del aparato

Techo de datos
  No hay extracto OSM más denso en el repo.
  Restaurantes/bares casi no vienen en este extracto
  (filtro original orientado a servicios esenciales).
  Sin tiles raster OSM (solo GeoJSON + Leaflet).
