Quitar

Irse es borrar una carpeta. No prometemos cero rastro: la papelera, una copia en un pendrive o «datos de navegación» de otro origen pueden quedar. Eso no lo controlamos nosotros.

No hay cuenta que cancelar. No hay ficha en un servidor nuestro.

Cascarón (la vía buena)

  • Borra la carpeta app/modules/ (los packs).
  • Borra app/data/ (progreso, pastillas, notas).
  • O borra la carpeta app/ entera.

En la propia app, «Quitar» borra un pack. Pregunta antes de borrar los datos de ese pack.

HTML suelto / file://

  • Borra el ZIP y la carpeta descomprimida.
  • En el navegador: ajustes → borrar datos de este origen (file:// o el que hayas usado).

PWA (icono instalado)

  • Desinstala el icono.
  • Chrome / Edge: borrar datos de lesvencimos.com/app/.

APK

  • Ajustes del teléfono → Aplicaciones → Les vencimos → Desinstalar.
  • Hoy el APK no escribe una carpeta nativa aparte. Si más adelante el puente Capacitor guarda en Documentos, borra también esa carpeta.

Qué no desaparece solo

  • Un ZIP que copiaste a un pendrive.
  • Una captura o una nota que pegaste fuera.
  • El GET del ZIP que vio GitHub Pages / Cloudflare: ven que se bajó un fichero, no el contenido de tus pastillas.
