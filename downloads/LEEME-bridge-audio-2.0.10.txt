Android cubre sin cambios HTML:
  · getUserMedia → RECORD_AUDIO + WebChromeClient.onPermissionRequest
  · <input type=file accept=audio/*> → onShowFileChooser (SAF OPEN_DOCUMENT)
  · Clic en <a download> con blob:/data: → auto LvBridge.saveAudioBase64
    (Music/LesVencimos o Documents/LesVencimos vía MediaStore)

APIs window.LvBridge (también útiles si Web las cablea):

  hasMicPermission() → boolean
  requestMicPermission() → void
      evento: lv:mic-permission  detail={granted:bool, permission:"RECORD_AUDIO"}

  pickAudioFile() → void
  openDocument(mimeCsv) → void   // ej. "audio/*" o "audio/*,.mp3"
      evento: lv:audio-picked
      detail={ok, name, mime, uri, url, bytes, cachePath}
      url = https://appassets.androidplatform.net/user-audio/<name>
            (reproducible en <audio src>)

  saveAudioBase64(base64OrDataUrl, fileName, mime) → JSON string
      {ok, uri, name, mime, bytes, relativePath, folder, url, cachePath}
      evento: lv:audio-saved (mismo detail)
      Carpeta: Music/LesVencimos/ (fallback Documents/LesVencimos/)

  listSavedRecordings() → JSON array [{uri,name,mime,bytes,added},…]
  getUserMediaFolder() → "LesVencimos"

  startRecording() / stopRecording()
      No-op nativo (HTML usa MediaRecorder). startRecording pide mic.
